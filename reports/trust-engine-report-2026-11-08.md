# 可信度引擎交付报告（trust-v1.0）
> 日期：2026-11-08 ｜ 目标：解决**法规时效性、幻觉、数据权威性、更新机制**四大生产级难题
> 结论：四层防线全部建成并回归通过 —— trust 测试 **24/24**、冒烟 **19/19**、全量 e2e **73/73**

---

## 1. 问题诊断（动手前的真实缺口）

| 靶点 | 原有机制 | 缺口 |
|---|---|---|
| **时效性** | 到期雷达 `expiry_scan.py`（独立工具） | 问答链路**不感知**到期日；`expiry_date` 误把「截至 YYYY-MM-DD」当到期；解释层元条目被误设硬闸 |
| **幻觉** | 13 条 SYSTEM_PROMPT 约束 + 引用 ID 校验 | 只校验**引用 ID 存在**，不校验**生成文本里的数字/文号是否真的出自出处**——伪造 37.5% 可长驱直入 |
| **权威性** | A/B1/B2 三层徽章 | 无「法律>行政法规>部门规章>规范性文件」效力层级；无新旧冲突（后法优于前法）提示 |
| **更新机制** | 手动五步重建链 | 无官方信源变更巡检；无「时效+来源」双通道 |

## 2. 建成的四层防线（`app/trust.py`，纯函数、可单测）

### L1 时效性（Timeliness）
- **到期硬闸**：`expiry_state()` → expired/expiring/valid/unknown；expired + status「已废止」→ **gate=block**，不得作现行依据
- **核验衰减**：`freshness_factor()` 30 天内 1.0 → 180 天 0.4 线性衰减，计入信任分
- **复核期限**：>180 天未核验强制提示回查原文
- **数据治理**：`enrich_kb.py` 到期日改为只信「显式字段 + 时效性/核心条款语境」，并补「YYYY-MM-DD 到期/届满」模式；排除「截至」误匹配

### L2 权威性（Authority）
- **效力层级**：`authority_rank()` 法律=1 → 行政法规/司法解释=2 → 部门规章=3 → 规范性文件=5 → 解释层=6
- **冲突裁决**：`conflict_scan()` 检测同名不同文号（doc_no_conflict）、一废一现（status_conflict）、百分比口径分歧（rate_divergence），提示「后法优于前法、上位法优于下位法」

### L3 幻觉检测（Grounding）—— 核心创新
- **逐断言抽取**：`extract_claims()` 抽出百分比/金额/文号/条号/法规名
- **三档溯源**：
  - `grounded` 在被引条目中找到
  - `kb_grounded` 在知识库其他条目中找到（引用遗漏，可补引）
  - **`ungrounded` 全库找不到 = 疑似幻觉，gate=block，必须人工复核**
- 实测：伪造「37.5%」「财税〔2019〕99 号」→ 精确捕获并触发硬闸 ✅

### L4 聚合（Aggregate）
- **信任分** = 0.40×溯源覆盖率 + 0.25×新鲜度 + 0.20×权威级 + 0.15×无冲突
- **三级 gate**：`allow`（可引用）/ `warn`（须附限制）/ `block`（硬闸，不得作申报或合同依据）

## 3. 接入点（端到端生效）

| 位置 | 机制 |
|---|---|
| `server.py ask_local` | 本地回答出口自动跑 trust_report；block 时**置顶红条**，warn 时并入「可信度与时效提示」 |
| `POST /api/trust-check` | **LLM 生成文本事后溯源**：前端在流式输出完成后自动调用 |
| `app.js` | LLM 答案下方渲染**溯源状态条**（✅/⚠️/🛑 + 溯源率 + 信任分）+ 未溯源项警示 |
| `update_watch.py` | 官方信源**可达性+内容指纹**巡检，报告 `reports/source-watch-YYYY-MM-DD.md` |

### 实测样例
```
输入文本: "一般纳税人适用 13% 税率，另有 37.5% 的特殊加计抵减，
          依据财税〔2019〕99 号和《增值税法》第四十二条。"
结果:     gate=block | coverage=0.0
          ungrounded: ['37.5%', '财税〔2019〕99号']   ← 伪造项精确捕获

```

## 5. 边界（不承诺 100%）

1. **ungrounded ≠ 证伪**：是「知识库中找不到」，须人工复核；新出台但未入库的真文号也会落入此档
2. **来源变更 ≠ 法规变更**：页面改版会触发指纹变化，须人工打开确认
3. **覆盖率是启发式**：年份等通用数字已停用过滤，但极短实体（「512」）可能漏检
4. **冲突只提示不裁决**：自动裁决涉及法律判断，保留给人（提示后法/上位法原则）
