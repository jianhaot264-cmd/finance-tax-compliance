## 1. 触发后的 24 小时动作清单

1. **锁定文本**：下载主席令 + 法律全文 + 总局配套公告，存 `knowledge-base/` 之外的 `sources/` 目录（不入库，仅留证）。
2. **比对差异**：按本图逐条比对「现行表述 vs 新法条文」，标出**实质变化 / 文字调整 / 无变化**三类。
3. **先改「依据」再改「结论」**：文号、施行日、条款号优先；结论段落最后改，避免半成品。
4. **同步 6 处**：`build_kb.py` FILES（若新增文件）→ `00-index.md` → `static/index.html` → `e2e-test.py` → `README.md` → `server.py` 规则 refs。

6. **单进程重启 + 五件套验证**：`/api/meta` → 引用零悬空 → `--smoke` → 全量 e2e → `eval_kb.py` 对比基线。

## 4. 通用改写 SOP（两条法律共用）

```
① 取文本 → ② 差异表（实质/文字/无变化）→ ③ 改依据 → ④ 改结论 → ⑤ 改规则 →
⑥ 重建五步链 → ⑦ 单进程重启 → ⑧ 引用校验 → ⑨ smoke 19 → ⑩ 全量 e2e 73 →
⑪ eval 175 题对比基线 → ⑫ 更新交接单/报告/备份
```

**验收硬指标**（任一不达标即回滚）：
1. `/api/meta` 条目数、文件数、规则数与 `kb.json` 一致；
2. 引用 ID **零悬空**（`server.RULES` 的 refs/basis 全部能在 `ENTRY_MAP` 找到）；
3. `e2e-test.py --smoke` 19/19；
4. `e2e-test.py` 全量 ≥ 73/73；
5. `eval_kb.py`：Recall@5(v5) ≥ 0.90、弃答 1.0、角色 ≥ 0.97、规则命中 ≥ 0.94；
6. 状态统计：新增/变更条目的「时效性」不再出现「草案阶段」；
7. 全库搜旧表述（「15 日」「清税前置」「暂行条例」）无残留（历史留痕段除外）。
