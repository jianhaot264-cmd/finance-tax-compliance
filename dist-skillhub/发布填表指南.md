```
面向中国中小企业的财税合规自查助手。三个硬能力：① 问财税问题给答案并附法条出处，检索不到就明说「无权威依据」，不编造；② 涉税金额由本地确定性引擎按算式给出，大模型被禁止产出数值——算式和分步过程都能看；③ 上传发票/流水/合同自动做三流一致核对，按错误/预警/提示分级出报告。

覆盖 18 个税种、472 条结构化知识条目、645 条经官方双源逐条核验的逐字法条（条数/条号/逐字任一不符即拒绝入库）。纯 Python 标准库实现，零第三方依赖，离线可跑。

⚠️ 仅用于辅助合规自查，不构成专业税务或法律意见。
```

### 描述
```
【解决什么问题】
中小企业财务常有三件事说不清：做得对不对、数字算得对不准、依据在哪。
- 问 AI 不知真假 → 每条结论挂法条编号+适用日期+地区口径+政策快照时间，无源即弃答
- 税额算错算不清 → 计算类强制走本地引擎，输出代入数值的算式与分步，LLM 不碰数值
- 稽查说不清业务真实性 → 发票/流水/合同三流一致核对，C1价税合计 C2税额勾稽 C3合同-发票-资金 C4税负率预警

【能力范围】
- 增值税+附加：一般计税/简易/差额/留抵/小微免征，城建7·5·1%、教育费附加3%、地方教育2%
- 个税：综合所得累计预扣、年终奖单独计税、经营所得五级
- 企业所得税：小微5%、基本25%、6项扣除限额速查
- 印花税13税目、契税住房分档
- 另含三流核对、合规清单生成、法条溯源核查

【怎么用】
python run.py  →  http://127.0.0.1:8777
首次运行自动建索引（3-5秒），仅需 Python 3.9+，无需 pip install。

【不适用】
正式申报出具、复议代理、涉税鉴证、司法鉴定、跨境筹划。重大事项请咨询主管税务机关或专业机构。
```

## 三、发布前必读的两点

### 1. 数据授权
包内法条均可溯源至官方发布页（政府网 / 司法部国家行政法规库 / 财政部 / 税务总局官网），逐条带来源链接与核验日期。**已清理全部第三方商业数据库的具名引用**（原 `build_v5.py`、`server.py`、`kb.json` 等 17 个文件中的相关表述已改为中性的「官方双源核验」）。若审核要求补充授权说明，可据 `knowledge/corpus/manifest.json` 中的双源链接逐条核验。

### 2. 免责声明
SKILL.md、README.md、包内界面首页**三处均有**：「本工具仅用于辅助合规自查，不构成专业税务/法律意见」。这是财税类工具的合规底线，请勿删除。
