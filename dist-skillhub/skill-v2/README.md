# 财税合规助手（中小企业版）· v2.0.0

面向中国中小企业的**财税合规自查方法论与口径速查** Skill。

## 这个 Skill 是什么

一份给 AI Agent 读的**工作方法**：遇到财税问题时怎么问、怎么算、怎么给依据、
什么时候必须弃答、什么情况下必须转介专业人士。不包含可执行程序、数据库或
法规全文数据库。

三条原则：

1. **结论可溯源** —— 挂法规编号 / 适用日期 / 地区口径 / 核对时点；检索不到权威依据时明确弃答，不编造。
2. **数值由确定性计算给出** —— 先列算式再给结果，禁止模型直接吐数字；条件不全先追问。
3. **核对只列差异与证据** —— 不下定性结论，不代替专业判断。

## 适用与不适用

**适用**：日常财税自查、税额复核、发票与流水勾稽、申报前准备、政策口径查询。

**不适用**：正式纳税申报出具、税务行政复议代理、涉税鉴证、司法会计鉴定、
跨境税务安排设计、争议事项定性。

## 免责声明

本 Skill 仅用于辅助合规自查，**不构成专业税务意见或法律意见**。
税收法规持续修订，速查口径存在核对时点；实际适用请以官方最新发布原文为准，
重大事项请咨询主管税务机关或具备资质的专业机构。
