# 常见财税口径速查（补充）

> 仅作初步定位使用。**实际适用必须核对官方最新发布原文**，并确认纳税人身份、
> 所属期、地区口径与行业特别规定。本文件不构成专业税务或法律意见。

## 一、计算题的标准输出格式

任何涉税金额计算，都按以下结构输出，缺一项即视为不完整：

```
【条件】纳税人类型 / 计税口径 / 所属期 / 适用政策
【算式】代入数值的公式
【分步】每一步的中间结果
【结果】最终金额（含单位、四舍五入规则）
【依据】法规名称 + 条款编号 + 适用日期 + 地区口径
【提示】以官方最新发布为准；条件不全时先追问，不假设
```

条件缺失时**必须先问清楚**，典型缺项：

- 一般纳税人还是小规模纳税人；
- 金额是含税价还是不含税价；
- 属于哪个所属期（政策可能按年度调整）；
- 是否适用行业或地区特别规定。

## 二、主要税种定位

| 税种 | 计算主线 | 常见易错点 |
|---|---|---|
| 增值税（一般计税） | 销项 − 进项 | 含税价换算、不得抵扣项目、差额计税适用条件 |
| 增值税（简易计税） | 销售额 × 征收率 | 征收率与税率混用、免征政策的适用门槛 |
| 城建税及附加 | 实缴增值税/消费税 × 税率 | 纳税人所在地决定城建税 7%/5%/1%；留抵退税对计税依据的影响 |
| 企业所得税 | 应纳税所得额 × 适用税率 | 纳税调整项、限额扣除、小型微利企业条件判定 |
| 个人所得税（工资薪金） | 累计预扣法 | 累计减除费用、专项附加扣除的填报口径 |
| 个人所得税（经营所得） | 五级超额累进 | 应纳税所得额口径与费用扣除 |
| 印花税 | 应税凭证金额 × 税目税率 | 分别列明与未分别列明、税目归属 |
| 契税 | 计税依据 × 适用税率 | 住房套数与面积分档、地区差别税率 |

## 三、企业所得税常见扣除限额

> 下列为**常见口径**，实际比例可能已被后续公告调整，须核对现行文件。

| 项目 | 常见限额 | 超出部分处理 |
|---|---|---|
| 职工福利费 | 工资薪金总额 14% | 不得扣除 |
| 工会经费 | 工资薪金总额 2% | 不得扣除 |
| 职工教育经费 | 工资薪金总额 **8%**（财税〔2018〕51 号，条例原文为 2.5%） | 准予结转以后年度 |
| 业务招待费 | 发生额 60%，且 ≤ 营业收入 5‰ | 不得扣除 |
| 广告费和业务宣传费 | 一般行业营业收入 15% | 准予结转以后年度 |
| 公益性捐赠 | 年度利润总额 12% | 准予结转以后年度 |

**易错提示**：限额的「基数」各不相同（工资薪金总额 / 营业收入 / 利润总额），
不要混用；行业特别规定（如化妆品、医药）需单独核对。

## 四、发票与凭证核对要点

1. 票面要素是否齐全：购买方信息、纳税人识别号、品名、金额、税率、税额；
2. 价税合计 = 不含税金额 + 税额（建议容差 ±0.10 元）；
3. 税额 = 不含税金额 × 税率（考虑票面税率与业务适用税率是否一致）；
4. 发票品名与合同标的、实际业务是否对应；
5. 合同方 / 开票方 / 收款方 / 付款方是否一致；
6. 扣除凭证是否属于税法规定的有效凭证类型；
7. 差异项应列清单并说明**需要补充什么证据**，由用户或专业人士判断处理。

## 五、申报前自查清单

- [ ] 收入：开票汇总、未开票收入、视同销售事项
- [ ] 进项：勾选记录、不得抵扣项目转出、异常凭证处理状态
- [ ] 成本费用：扣除凭证齐备性、限额扣除项目计算表
- [ ] 往来：股东借款、关联交易、长期挂账科目
- [ ] 资产：折旧摊销台账、资产处置
- [ ] 优惠：适用条件复核、留存备查资料
- [ ] 时间：申报期限、税款缴纳期限、资料归档期限

## 六、回答的溯源四要素

无论政策查询还是税额计算，结尾都要给出：

| 要素 | 说明 |
|---|---|
| 法规名称与条款编号 | 精确到「第 X 条」，写明法律 / 行政法规 / 公告层级 |
| 适用日期 | 该口径生效或修订的日期 |
| 地区口径 | 全国 / 某省 / 某行业特别规定 |
| 核对时点 | 提示「以官方最新发布原文为准」 |

检索不到权威依据时，明确回答「未检索到权威依据」，并给出建议核实的
官方渠道（政府网、司法部国家行政法规库、财政部、国家税务总局官网），
**不得凭印象补全**。
