# 内容合规说明（供平台审核参考）

**版本：v2.0.0 ｜ 2026-11-15**

## 一、本次调整说明

此前 v1.0.0 / v1.0.1 / v1.0.2 三次提交均未通过内容审核，提示均为
「内容审核未通过，违规类型: 内容含违法违规内容」。前两轮曾针对文案用语、
第三轮针对规则库结构做过调整，结论未变。

经对平台上**已上架的六个同类技能**做对照分析（税务筹划助手、财税合规报告、
财税合规专家团、企业财税合规审计与税务审计指引、国内电商与直播财税合规指引、
税务策略师），发现它们的共同形态是：

- 以 `SKILL.md` 方法论文档为主体（0.7K–9.6K 字符）；
- `references/` 为人工整理的知识文档；
- 2–33 个文件、体积 ≤ 0.43 MB；
- **不含完整 Web 服务、静态界面、结构化数据库或法规全文数据库**。

而 v1.x 提交的是一个完整可运行的 Web 应用（含服务端代码、472 条结构化
知识库、645 条逐字法条、规则库、静态页面，共 63 文件 / 0.82 MB）。
这与平台对「Skill」的产品形态预期不符，也可能是内容审核批量扫描时
产生误判的来源。

**因此 v2.0.0 按市场通行形态重构为纯方法论 Skill**：

- 不再打包任何可执行程序、数据库、法规逐字原文或静态界面；
- 仅保留 `SKILL.md` + 一份口径速查参考文档 + 说明文件；
- 完整可运行系统保留在项目仓库（GitHub），在文档中给出地址与运行方式。

## 二、内容立场

本 Skill 的全部内容是**教 AI 如何规范地回答财税问题**：

1. 结论必须挂法规编号、适用日期、地区口径、核对时点；
2. 检索不到权威依据时**明确弃答，严禁编造**；
3. 涉税金额必须列算式、给分步，禁止模型直接生成数值；
4. 条件不全时先追问，不自行假设；
5. 核对只列差异与待补证据，不下定性结论、不代替专业判断；
6. 明确列出不适用事项，重大事项要求转介主管税务机关或专业机构。

**不提供、不暗示、不指导任何违反税收法律法规的操作**，
不提供任何账簿设置设计、税务检查应对或发票取得方面的规避方法。

## 三、数据来源与授权

- 口径速查为**常见财税常识的整理**，不含法规逐字原文；
- 完整法规库（逐字法条）来自政府网、司法部国家行政法规库、财政部、
  国家税务总局官网等官方公开发布页，保留在项目仓库并附双源链接、
  核验日期与 SHA256；
- 法律法规官方文本依法不受著作权保护；
- 本包不含任何第三方商业数据库的数据或具名引用。

## 四、免责声明

本 Skill 仅用于辅助合规自查，**不构成专业税务意见或法律意见**。
税收法规持续修订，速查口径存在核对时点；实际适用请以官方最新发布原文为准，
重大事项请咨询主管税务机关或具备资质的专业机构。
