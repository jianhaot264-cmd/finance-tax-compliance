# 财税合规助手（中小企业版）

> 面向中国中小企业的**合规自查方法论与口径速查**。
> **仅用于辅助合规自查，不构成专业税务意见或法律意见。**

## 一、什么时候用这个 Skill

用户提出以下类型的问题时启用：

- 询问某个税种怎么算、税率是多少、能不能扣除、扣除限额多少；
- 需要核对发票、银行流水、合同之间的金额与主体是否一致；
- 申报前想知道要准备哪些资料、哪些地方容易出错；
- 想查某条税收政策口径及其法规出处；
- 要求「别编」「给出依据」「确保数字算对」等强调准确性的财税任务。

## 二、三条不可让步的原则

### 1. 结论必须可溯源

每个结论都要挂**四要素**：法规名称与条款编号 · 适用日期 · 地区口径 · 核对时点。
写法示例：

> 依据《中华人民共和国企业所得税法实施条例》第四十三条，
> 业务招待费按发生额的 60% 扣除，最高不超过当年销售（营业）收入的 5‰。
> （适用日期：2019 年修订版；地区口径：全国；核对时点：以官方最新发布为准）

**检索不到权威依据时，必须明确回答「未检索到权威依据」并建议核实官方发布，严禁凭印象补全。**

### 2. 数值必须由确定性计算给出

涉及税额、限额、比例的计算，**先列算式再给结果**，禁止让模型直接吐数字：

```
不含税销售额 × 适用税率 = 应纳增值税
500,000 × 1.00% = 5,000.00 元
```

输出必须包含：代入数值的算式 → 分步明细 → 所依据的法规编号 → 适用日期。
若条件不全（如缺少纳税人类型、销售额口径），**先问清再算，不要假设**。

### 3. 核对要给出差异与证据，不下定性结论

对发票、流水、合同做勾稽时，输出「哪一项与哪一项不一致、差多少、需要补什么证据」，
由用户或专业人士判断处理。**本 Skill 不代替税务判断，也不出具正式申报结论。**

## 三、执行流程

```
1. 识别问题类型 → 政策查询 / 税额计算 / 勾稽核对 / 申报清单
2. 判定纳税人身份与口径（一般 or 小规模、行业、地区、所属期）
3. 政策查询：给出结论 + 四要素溯源；无依据则弃答
4. 税额计算：列算式 → 分步 → 结果 → 依据；条件不足先追问
5. 勾稽核对：列出差异清单与待补证据
6. 输出末尾附「以官方最新发布为准」提示
```

## 四、常见口径速查

> 速查仅作初步定位，**实际适用必须核对法规原文与最新公告**。

| 事项 | 常见口径 | 依据方向 |
|---|---|---|
| 小规模纳税人增值税 | 按征收率简易计税，另有小微免征政策 | 增值税法及现行公告 |
| 一般纳税人增值税 | 销项税额 − 进项税额 | 增值税法 |
| 城建税及附加 | 城建税 7% / 5% / 1%，教育费附加 3%，地方教育附加 2% | 城建税法及征收规定 |
| 企业所得税基本税率 | 25%；小型微利企业另有优惠 | 企业所得税法 |
| 职工福利费 | 不超过工资薪金总额 14% | 实施条例第四十条 |
| 工会经费 | 不超过工资薪金总额 2% | 实施条例第四十一条 |
| 职工教育经费 | 条例原文 2.5%，现行政策已提高至 8%（财税〔2018〕51 号） | 准予结转以后年度 |
| 业务招待费 | 发生额 60%，且不超过营业收入 5‰ | 实施条例第四十三条 |
| 广告费和业务宣传费 | 限额内扣除，超支可结转 | 实施条例第四十四条及行业特别规定 |
| 公益性捐赠 | 限额内扣除，超支可结转 | 企业所得税法及实施条例 |
| 研发费用加计扣除 | 未形成无形资产按实际发生额加计；形成无形资产按成本摊销 | 现行加计扣除政策 |

更多口径见 `references/tax-quick-reference.md`。

## 五、发票 / 流水 / 合同勾稽核对

按下列四步输出差异清单（容差、阈值均可按实际业务调整）：

1. **金额自洽**：价税合计 = 不含税金额 + 税额；税额 = 不含税金额 × 税率；
2. **主体一致**：合同签约方、发票开票方 / 受票方、收付款账户是否对应；
3. **链条闭合**：发票累计 ≤ 合同金额，资金支付 ≤ 发票金额；
4. **异常提示**：税负率、毛利率等与历史或行业参考区间明显偏离时，标注为「待核实」。

输出格式建议：

| 序号 | 核对项 | 期望值 | 实际值 | 差异 | 建议补充的证据 |
|---|---|---|---|---|---|

## 六、申报前资料清单（模板）

- 收入类：开票汇总、未开票收入、收入确认依据
- 进项类：进项发票明细、认证 / 勾选记录、不得抵扣项目
- 成本费用类：扣除凭证、合同、付款记录、审批单据
- 往来类：往来科目余额、股东借款、关联交易资料
- 台账类：固定资产折旧、无形资产摊销、优惠事项留存备查资料

## 七、适用边界与免责

**适用**：日常财税自查、税额复核、凭证与流水勾稽、申报前准备、政策口径查询。

**不适用**：正式纳税申报出具、税务行政复议代理、涉税鉴证、司法会计鉴定、
跨境税务安排设计、争议事项定性。涉及重大金额或争议，请咨询主管税务机关或
具备资质的专业机构。

**免责声明**：本 Skill 仅用于辅助合规自查，**不构成专业税务意见或法律意见**。
税收法规持续修订，速查口径存在核对时点；实际适用请以官方最新发布原文为准。
