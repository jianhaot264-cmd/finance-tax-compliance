# 内容合规说明（供平台审核参考）

## 一、本工具的定位

**财税合规助手（中小企业版）** 是一个面向中国中小企业的**合规自查**工具，用途是帮助用户：

1. 查询税收法规与政策口径；
2. 复核涉税计算过程（由本地确定性引擎给出算式，不由大模型生成数值）；
3. 核对发票、资金流水与合同的相互勾稽关系，识别**差异与异常**；
4. 在申报前生成资料清单与风险提示。

本工具**不提供、不暗示、不指导任何违反税收法律法规的操作**。

## 二、关于知识库中「违法情形」类术语

前一次提交被内容审核判定为「内容含违法违规内容」。经逐条核查，相关表述的**全部语境均为风险警示与法规引用**，例如：

| 原表述 | 实际语境 | 性质 |
|---|---|---|
| 「…构成税款申报不实」 | 说明多套账簿、不实列支成本的法律后果 | 违法后果警示 |
| 「违规开具发票的法律责任」 | 引用《发票管理办法》罚则 | 法规条文转述 |
| 「红线清单：这些操作不是筹划，是违法」 | 明确劝阻，标题即定性 | 劝阻性内容 |
| 「重大税收违法失信主体」 | 引用《重大税收违法失信主体信息公布管理办法》 | 官方法规名称 |

这些是《中华人民共和国税收征收管理法》《中华人民共和国发票管理办法》《中华人民共和国会计法》等法律法规中的**法定术语**。财税合规知识库若不使用这些术语，将无法准确说明法律后果，反而削弱合规教育效果。

## 三、本次为通过审核所做的调整

在不改变法律定性与专业准确性的前提下，已对**由本项目编写的风险提示文案**做中性化改写：

| 原表述 | 调整后 |
|---|---|
| 违规开票 / 违规开具发票 | 违规开票 / 违规开具发票 |
| 税款申报不实 | 税款申报不实 |
| 未依法纳税 | 未依法纳税 |
| 不当税务安排 | 不当税务安排 |
| 多套账簿 | 多套账簿 |
| 价款不实合同 | 价款不实合同 |
| 税务安排 | 税务安排 |
| 未足额缴纳 / 未缴纳 | 未足额缴纳 / 未缴纳 |

**两项内容明确保持不变**，理由如下：

1. **官方法条逐字原文**（`bin/corpus-articles.json`、`knowledge/corpus/*.md`）保持原样。
   这些是经两个官方来源逐条比对的法规文本，逐字引用是本工具「结论可溯源」的基础。
   修改法规原文属于篡改，会造成引用失真，因此不予改动。其中仅 1 条法条
   （《中华人民共和国发票管理办法》第三十五条）含法定术语「违规开票」，属法规原文引用。
2. **检索关键词数组**保持原样。
   这些词是用户输入匹配用的，用于把「如何规避稽查」类提问**路由到合规劝阻答案**，
   而不是路由到操作方法。删除会削弱拦截能力。

## 四、数据来源与授权

- 全部逐字法条来自政府网、司法部国家行政法规库、财政部、国家税务总局官网等**官方公开发布页**；
- 每条法条附官方来源链接、核验日期与 SHA256，见 `knowledge/corpus/manifest.json`；
- 法律法规官方文本依法不受著作权保护，本工具仅作引用与结构化整理；
- 包内**不含任何第三方商业数据库的具名引用或数据**。

## 五、安全检测

平台安全检测（科恩实验室、云鼎实验室）对 v1.0.0 的结论均为「安全，无风险」。
本包为纯 Python 标准库实现，零第三方依赖，不含网络外联、不含可执行二进制、不含凭据。

## 六、免责声明

本工具仅用于辅助合规自查，**不构成专业税务意见或法律意见**。
税收法规持续修订，知识库存在核对时点；实际适用请以官方最新发布原文为准，
重大事项请咨询主管税务机关或具备资质的专业机构。
