# 财税合规助手（中小企业版）

> 中国中小企业财税合规问答与自查工具。**仅用于辅助合规自查，不构成专业税务/法律意见。**

## 这个技能解决什么问题

中小企业财务最常见的三个痛点是：**不确定自己做得对不对、不确定数字算得对不对、出了问题说不清依据在哪**。本技能针对这三点：

| 痛点 | 本技能的做法 |
|---|---|
| 问 AI 得到的答案不知真假 | 每条结论挂**法条编号 + 适用日期 + 地区口径 + 政策快照时间**；检索不到就明说「未检索到权威依据」，不编造 |
| 税额算错、算不清过程 | 计算类问题**强制走本地确定性引擎**，输出代入数值的算式和分步明细；**LLM 被禁止产出数值结果** |
| 稽查时说不清业务真实性 | 上传发票 / 银行流水 / 合同，自动做**三流一致核对**，出可视化报告并按错误/预警/提示分级 |

## 核心能力

### 1. 确定性算税（与生成式回答严格分离）

| 税种 | 覆盖范围 |
|---|---|
| 增值税 + 附加 | 一般计税（销项−进项）、简易计税、差额计税、留抵、小微免征；城建税 7/5/1%、教育费附加 3%、地方教育附加 2% |
| 个人所得税 | 综合所得累计预扣、年终奖单独计税、经营所得五级超额累进 |
| 企业所得税 | 小型微利 5%、基本税率 25%、6 项扣除限额速查 |
| 印花税 + 契税 | 13 个税目（含分别列明/从高适用）、契税住房分档 |

每个结果都带：**代入数值的算式 + 分步明细 + 法条编号 + 适用日期 + 地区口径 + 政策快照时间**。

### 2. 答案可溯源

- 检索必然返回出处原文片段，无源时明确弃答
- 四层可信度防线：时效（到期/废止硬闸）→ 权威层级 → 幻觉检测（逐数字/文号/条号溯源）→ 聚合评级
- 逐字法条来自 **645 条经官方双源逐条比对**的原文（条数、条号连续性、逐字一致性任一不符即拒绝入库）

### 3. 三流一致核对

上传发票 / 银行流水 / 合同（CSV / XLSX / JSON），自动校验：

- **C1** 价税合计 = 不含税金额 + 税额（容差 ±0.10 元）
- **C2** 税额 = 不含税金额 × 税率
- **C3** 合同—发票—资金勾稽（发票 ≤ 合同、资金 ≤ 发票）
- **C4** 增值税税负率行业区间预警

### 4. 合规清单生成

按企业类型（一般纳税人 / 小规模 / 个体户 / 小微企业）+ 税种，生成申报时间线、资料清单、高中风险点。

## 知识库规模

- **472 条**结构化条目，三层质量分级（A 层 318 条双官方信源可直接引用）
- **645 条**逐字法条，覆盖 **18 个税种**（14 部法律 + 4 部暂行条例）
- **30 张**概念卡，**30 个**业务事项结构化条目
- 覆盖：18 税种 + 征管稽查 + 发票 + 社保非税 + 跨境 + 粤港澳大湾区 + 计税方法 + 复议诉讼 + 税收协定 + 会计准则 + 行业专项

## 怎么用

### 启动服务

```bash
python run.py          # 默认 http://127.0.0.1:8777
python run.py 9000     # 指定端口
```

首次运行会自动构建本地索引（约 3–5 秒），之后直接复用。**仅需 Python 3.9+ 标准库，无需 pip install。**

### 直接调 API

```bash
# 问一个财税问题
curl -X POST http://127.0.0.1:8777/api/ask \
  -H "Content-Type: application/json" \
  -d '{"q":"小规模纳税人月销50万要交多少增值税？"}'

# 查知识库条目
curl "http://127.0.0.1:8777/api/search?q=研发费用加计扣除"
```

### 主要端点

| 端点 | 说明 |
|---|---|
| `POST /api/ask` | 问答（计算类自动路由确定性引擎） |
| `POST /api/trust-check` | 对 LLM 生成文本做事后溯源核查 |
| `POST /api/reconcile` | 三流一致核对 |
| `POST /api/checklist` | 合规检查清单生成 |
| `GET /api/search` | 知识库检索 |
| `GET /api/kb` | 知识库全量 |
| `GET /api/health` | 健康检查 |

### 浏览器界面

启动后访问 `http://127.0.0.1:8777` 可直接使用带界面的问答、检索、核对功能。

## 适用与不适用

**适用**：中小企业日常财税自查、算税复核、发票与流水勾稽、申报前检查、财税知识查询、法条溯源。

**不适用**：正式纳税申报出具、税务行政复议代理、涉税鉴证、司法会计鉴定、跨境税务筹划。涉及重大金额或争议事项，请咨询主管税务机关或专业机构。

## 技术特性

- **零第三方依赖**：Python 3.12 纯标准库 + 原生前端，无供应链风险
- **离线可用**：知识库与计算引擎全部本地运行，不联网也能用
- **数据可核验**：每条法条带官方来源链接与核验日期，可自行复核

## 免责声明

本技能仅用于辅助合规自查，**不构成专业税务意见或法律意见**。税收法规会持续修订，知识库存在核对时点；实际适用请以官方最新发布原文为准，重大事项请咨询主管税务机关或专业机构。
