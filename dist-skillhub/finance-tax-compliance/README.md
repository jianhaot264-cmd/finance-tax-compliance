# 财税合规助手（中小企业版）

面向中国中小企业的财税合规自查工具。**仅用于辅助合规自查，不构成专业税务/法律意见。**

## 快速开始

```bash
python run.py          # 默认 http://127.0.0.1:8777
python run.py 9000     # 指定端口
```

首次运行自动构建本地索引（约 3–5 秒），之后直接复用。
**仅需 Python 3.9+ 标准库，无需 pip install。**

## 目录说明

| 路径 | 内容 |
|---|---|
| `SKILL.md` | 技能说明（SkillHub 元信息） |
| `run.py` | 启动入口（自动建索引 + 起服务） |
| `bin/` | 运行时模块与数据 |
| `bin/kb.json` | 知识库 472 条结构化条目 |
| `bin/corpus-articles.json` | 645 条逐字法条（官方双源核验） |
| `bin/concepts.json` | 30 张概念卡 |
| `bin/server.py` | HTTP 服务（零依赖） |
| `bin/tax_calc/` | 确定性算税引擎 |
| `bin/reconcile/` | 三流一致核对 |
| `bin/static/` | 浏览器界面 |
| `knowledge/corpus/` | 逐字条文 md 原件（含双源链接、时效、SHA256） |

## 核心能力

1. **确定性算税** — 计算类问题强制走本地引擎，输出算式与分步明细，LLM 不产出数值
2. **答案可溯源** — 每条结论挂法条编号 / 适用日期 / 地区口径 / 政策快照时间
3. **三流一致核对** — 发票 / 流水 / 合同勾稽，输出分级问题报告
4. **合规清单生成** — 按企业类型 + 税种生成申报时间线与风险点

## 主要 API

| 端点 | 方法 | 说明 |
|---|---|---|
| `/api/ask` | POST | 问答（计算类自动路由确定性引擎） |
| `/api/trust-check` | POST | 对生成文本做事后溯源核查 |
| `/api/reconcile` | POST | 三流一致核对 |
| `/api/checklist` | POST | 合规检查清单 |
| `/api/search` | GET | 知识库检索（`?q=关键词`） |
| `/api/kb` | GET | 知识库全量 |
| `/api/health` | GET | 健康检查 |

```bash
curl -X POST http://127.0.0.1:8777/api/ask \
  -H "Content-Type: application/json" \
  -d '{"q":"小规模纳税人月销50万要交多少增值税？"}'
```

## 知识库

- 472 条结构化条目，A 层 318 条（双官方信源，可直接引用）
- 645 条逐字法条，覆盖 18 个税种（14 部法律 + 4 部暂行条例）
- 30 张概念卡 + 30 个业务事项结构化条目

## 技术特性

- **零第三方依赖**：Python 标准库 + 原生前端
- **离线可用**：知识库与计算引擎全部本地运行
- **数据可核验**：法条带官方来源链接与核验日期

## 适用与不适用

**适用**：中小企业财税自查、算税复核、发票与流水勾稽、申报前检查、法条溯源。

**不适用**：正式申报出具、复议代理、涉税鉴证、司法鉴定、跨境筹划。重大事项请咨询主管税务机关或专业机构。

## 免责声明

本工具仅用于辅助合规自查，不构成专业税务意见或法律意见。税收法规持续修订，知识库存在核对时点；实际适用请以官方最新发布原文为准。
