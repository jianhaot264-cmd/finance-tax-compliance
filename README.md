## 一、核心能力（三大护城河）

### 1. 确定性计算 vs 生成式回答严格分离（P0 红线）

| 税种 | 覆盖 | 产出 |
|---|---|---|
| **增值税 + 附加税** | 一般计税（销项−进项）/ 简易计税 / 差额 / 留抵 / 小微免征 + 城建 7/5/1% + 教育费附加 3% + 地方教育 2% | 算式 + 分步 + 法条 |
| **个人所得税** | 综合所得累计预扣 / 年终奖单独计税 / 经营所得五级 | 算式 + 速算扣除数 |
| **企业所得税** | 小型微利 5% / 基本 25% / 扣除比例速查（6 项限额） | 算式 + 三条件判定 |
| **印花税 + 契税** | 13 税目（含分别列明/从高）+ 契税 2024 住房分档 | 算式 + 税目依据 |

- 计算类问题**强制路由本地引擎**，LLM 只做解释，**禁止产出数值结果**
- 每个结果含：代入数值的算式、分步明细、法条编号、适用日期、地区口径、政策快照时间
- 税率表内置在 `app/tax_calc/` 且带法条依据，改动须同步 `SNAPSHOT`

### 2. 答案可溯源（RAG + 可信度引擎）

- **检索必回出处原文片段**，无源时明确回答「未检索到权威依据」，严禁编造
- **可信度四层防线** `app/trust.py`：
  - L1 时效：到期/废止**硬闸** + 核验 30→180 天衰减
  - L2 权威：效力层级（法律→解释层）+ 新旧冲突提示
  - L3 幻觉：生成文本**逐数字/文号/条号溯源**，未溯源项触发 block
  - L4 聚合：信任分 + allow/warn/block 三级
- **每个回答自动挂载溯源四要素**：法条编号 · 适用日期 · 地区口径 · 政策快照时间

## 二、产品化功能（P1）

### 三流一致自动核对

输入发票 / 银行流水 / 合同的结构化文件（CSV / XLSX / JSON，一期），自动核对：

- **C1** 价税合计 = 不含税金额 + 税额（容差 ±0.10 元）
- **C2** 税额 = 不含税金额 × 税率
- **C3** 合同—发票—资金勾稽（发票 ≤ 合同、资金 ≤ 发票）
- **C4** 增值税税负率行业参考区间预警

产出 **可视化 HTML 核对报告**（问题分级：错误 / 预警 / 提示）。

### 合规检查清单生成

按企业类型（一般纳税人 / 小规模 / 个体户 / 小微企业）+ 税种生成：**申报时间线 + 资料清单 + 高中风险点**。
