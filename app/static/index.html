财税合规智能体 · 专家团工作台

面向中小企业与财税从业者的法规问答、检索与合规参考工具。知识库 — 条结构化条目（含 30 张概念解读卡），核验日期 —；支持「标准答复」与「六段式深度解读」，全部结论强制附出处与时效状态。

专家团分诊

问题按关键词路由到对应角色，再由主理人汇编为「结论 → 依据 → 风险提示」三段式输出。

五道准确性防线

  1. 强制引用：答案必须附法规名称、文号与知识库条目；
  2. 时效过滤：草案 / 修订中 / 已到期文件不作为现行依据；
  3. 双源交叉：入库前核对官方信源与文号；
  4. 不确定即承认：知识库未收录时明确说明，不猜测补全；
  5. 高风险转介：虚开、偷税、失信等事项强制提示专业人士介入。

运行架构

  • 前端：零框架单页应用，经 WorkBuddy Cloud SDK 免密钥流式调用云端大模型（默认 Hy4 限时免费档，可切换）；
  • 后端：Python 标准库服务（端口 8777），负责专家团分诊、知识库检索注入与本地兜底；
  • 知识库：50 个 Markdown 主题文件（法规 + 逐字法条 + 30 张概念卡 + 关联边界 + 场景路径 + 计税/社保/非税/消费税/财产税/出口退税/数电票/复议诉讼/协定逐国税率/会计进阶/行业/立法跟踪/到期预警）→ build_kb.py → enrich_kb.py → build_concepts.py → build_v5.py → kb.json + concepts.json + SQLite（10 类表）+ CSV 主数据表；
  • 检索与编排：五路召回（BM25 全字段/标题、精确文号、FTS5 中文全文、字面 gram）+ RRF 融合 + 可解释重排 + 置信度弃答；五阶段编排（分诊→检索→精编→引用校验→赵审计复核），每次回答落 query_log 留痕；
  • 评测：188 题 Golden QA（自动 109 + 手工 79），eval_kb.py 量化 Recall@5、MRR、引用正确率、弃答正确率、角色分诊、规则命中、要点覆盖率与禁用表述规避率；
  • 兜底：云端断网 / 配额用尽 / 服务异常时自动回退本地精编答案库，并显示回退原因。
  • 深度解读：六段式（定义→辨析→因果→条件→易混淆→局限）+ 概念面板 + 证据链 + 五阶段实时进度；每段强制挂法规条目引用。
