## 云端大模型

- 应用 `wbapp_3mW42GQGReTlPlSIBoAs1f`；默认 **Hy4 限时免费档 `hy4free`**（0.00x），输入框左侧下拉按「免费 / 低价 / 标准 / 旗舰」分组，共 32 个模型；
- 调用链路：前端经 WorkBuddy Cloud SDK **免密钥流式**（`stream: true`，`messages[0]` 为 system）→ 后端 `/api/llm-context` 注入知识库上下文 → 模型只依据知识库作答；
- 自动兜底：断网 / 配额用尽 / 限流 / 服务异常 → 回退本地精编答案，并在气泡内显示回退原因；**429 限流时先自动切换另一个免费档（Hy3）或最低价模型重试一次**，成功后消息标注实际模型；手动「停止」保留已输出内容；
- `static/cloud-config.js` 的 publishableKey 仅标识应用，**请勿写入任何私密密钥**；历史自备 Key 方案保留在 `config.json`。

## 知识库更新

1. 修改 `..\knowledge-base\` 下的 md（遵循 `00-index.md` 元数据规范）；
2. 依次执行 `build_kb.py` → `enrich_kb.py` → `build_concepts.py` → **`import_corpus.py`** → `build_v5.py` → `audit_kb.py` → `build_coverage_matrix.py`（顺序不可颠倒；`import_corpus.py` 必须在 `build_v5.py` 之前，否则 L0 逐字条文不会入库）；
3. 改过检索/规则时执行 `eval_kb.py` 对比 legacy 基线，再跑 `e2e-test.py --smoke` 与全量；
4. 重启 `server.py` 生效（前端会自动读取新的分类、条目与概念卡）。

## 边界与免责

输出仅为合规参考，不构成税务师 / 律师专业意见；所有结论以官方发布原文为准。知识库未覆盖的问题会如实说明而非硬答；标注「待核验 / 草案 / 已到期」的字段在复核前不得作为现行依据引用。**“全覆盖”是覆盖税种与主题框架，不等于收录全部部门公告与地方细则**——具体个案仍需按 `SOURCES-CHANNELS.md` 的 SOP 回查原文。
