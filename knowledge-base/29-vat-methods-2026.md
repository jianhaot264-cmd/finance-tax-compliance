# 增值税计税方法与预缴（2026 生产版）

> 覆盖：计税方法（一般/简易）、差额扣除、预缴、含税换算、进项划分与 36 个月锁定。
> 本文件为 **A 层**：每条 10 字段 + 至少 2 个官方信源 + 核验日期。核验日期 2026-11-07。
> ⚠️ 2026-01-01 起《增值税暂行条例》废止，**36 号文不再作为独立依据**；简易计税与差额征税已纳入「增值税优惠事项」，依据变为《增值税法》+ 实施条例（国务院令第 826 号）+ 财政部 税务总局公告 2026 年第 10 号。

## 29.4 差额扣除（12 项）：从含税销售额中扣除后计税

| 字段 | 内容 |
|---|---|
| 文号 | 财政部 税务总局公告 2026 年第 10 号 **第四条**；原政策口径见财税〔2016〕36 号附件 2 第一条第（三）项（**2026 起不再单独作为依据**） |
| 发文机关 | 财政部、国家税务总局 |
| 效力层级 | 部门规范性文件（属增值税优惠事项） |
| 公布/施行 | 2026-01-01 至 2027-12-31 |
| 时效性 | 现行有效（2027-12-31 到期组） |
| 适用范围 | 发生列举应税交易的纳税人（一般纳税人与小规模纳税人分别适用） |
| 核心条款 | 公告列 **12 项**允许从含税销售额中扣除相关价款后计算销项税额或应纳税额；已确认的口径包括：① 金融商品转让按卖出价扣除买入价；② 经纪代理服务扣除代收的政府性基金/行政事业性收费；③ 融资租赁与融资性售后回租扣除借款利息、发行债券利息（及车辆购置税）；④ 航空运输代收的机场建设费与代收转付票款不计入销售额；⑤ 客运场站扣除支付给承运方运费；⑥ 旅游服务扣除住宿、餐饮、交通、签证、门票及接团费用；⑦ 建筑服务简易计税扣除分包款；⑧ 房地产开发企业一般计税扣除受让土地时向政府支付的土地价款；⑨ 转让 2016-04-30 前取得土地使用权按全额减原价；⑩ 一般纳税人销售 2016-04-30 前取得（不含自建）不动产、小规模销售取得（不含自建）不动产，扣除购置原价或作价；⑪ 金融机构贴现、转贴现按实际持有期间利息收入为销售额；⑫ 银行业金融机构、金融资产管理公司处置抵债不动产差额征税（10 号公告第五条，已纳入优惠事项） |

| 发文机关 | 国务院 |

| 时效性 | 现行有效 |
| 适用范围 | 采用销售额与税额合并定价的纳税人；以人民币以外货币结算的纳税人 |
| 核心条款 | ① **一般计税**：销售额＝含税销售额÷（1＋税率）；**简易计税**：销售额＝含税销售额÷（1＋征收率）；② 「全部价款」**不包括**代收的：政府性基金或行政事业性收费、受托加工应征消费税消费品所产生的消费税、车辆购置税与车船税、以委托方名义开票代收的款项；③ 外币结算可选销售额发生当日或当月 1 日的人民币汇率中间价，**确定后 12 个月内不得变更** |

## 29.12 常见误区辨析（差额 / 简易 / 预缴 / 免税）

| 字段 | 内容 |
|---|---|
| 文号 | 综合：增值税法第十一条、第二十六条；实施条例第十五条、第四十五条；财政部 税务总局公告 2026 年第 10 号 |
| 发文机关 | 全国人大常委会；国务院；财政部、税务总局 |
| 效力层级 | 法律 + 行政法规 + 规范性文件 |
| 公布/施行 | 均 2026-01-01 起 |
| 时效性 | 现行有效 |
| 适用范围 | 全部增值税纳税人 |
| 核心条款 | ① **差额征税**解决「销售额是多少」，**简易计税**解决「用哪个征收率」，二者可叠加（如建筑简易＋分包差额），也可分离；② **预缴**是征收管理环节，不等于纳税申报，预缴后仍需申报；③ **免税**是销项不征且对应进项不得抵扣，**简易计税**是销项按征收率征且对应进项不得抵扣，二者进项处理相似但性质不同；④ **小规模 3% 减按 1%** 只适用于小规模纳税人，一般纳税人不得适用；⑤ 兼营优惠项目**未单独核算即不得享受**（2026 年新增强制要求） |
| 合规要点 | 混淆上述四组概念是中小企业最高频的算税错误来源；建议在账套中按「计税方法 × 是否差额 × 是否预缴」三维打标，申报前逐项核对 |
