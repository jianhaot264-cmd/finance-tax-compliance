# 会计准则进阶：金融工具（CAS22–24）、长期股权投资（CAS2）、合并报表（CAS33）

> 覆盖：三套会计制度选择、金融工具三分类与预期信用损失、金融资产转移、套期会计、长期股权投资成本法/权益法、合并报表控制三要素，以及对应的**税会差异**。
> 本文件为 **A 层**：每条 10 字段 + 至少 2 个官方信源 + 核验日期 2026-11-07。
> ⚠️ 会计与税法**两条线**：会计按准则确认、计量、列报；企业所得税按**法人**、按**历史成本**、按**实际发生**扣除。会计利润 ≠ 应纳税所得额，凡本文件涉及「税会差异」处，均须在汇算清缴时通过纳税调整表体现。

## 43.2 CAS22 金融资产三分类：业务模式 + SPPI 两个维度

| 字段 | 内容 |
|---|---|
| 文号 | 《企业会计准则第 22 号——金融工具确认和计量》（财会〔2017〕7 号）关于金融资产分类的规定 |
| 发文机关 | 财政部 |
| 效力层级 | 具体会计准则（规范性文件） |
| 公布/施行 | 2017-03-31 发布；按 43.1 三档施行（非上市企业 2021-01-01） |
| 时效性 | 现行有效 |
| 适用范围 | 企业持有的债权投资、权益投资、衍生工具等各类金融资产 |
| 核心条款 | ① **两个分类维度**：**业务模式**（收取合同现金流量 / 收取并出售 / 其他）+ **合同现金流量特征**（是否仅为对本金和以未偿付本金为基础的利息的支付，即 **SPPI 测试**）；② **三分类**：同时满足「SPPI + 收取合同现金流量」→ **以摊余成本计量（AC）**；满足「SPPI + 收取并出售」→ **以公允价值计量且变动计入其他综合收益（FVOCI，债权类）**；其他 → **以公允价值计量且变动计入当期损益（FVTPL）**；③ **权益工具**：默认 FVTPL；**非交易性权益工具**可在初始确认时**不可撤销地指定**为 FVOCI，其公允价值变动计入其他综合收益，**终止确认时不得转入损益**（只能转留存收益）；④ 衍生工具一般直接归 FVTPL；⑤ 分类一经确定不得随意变更，仅在业务模式改变时按准则重分类 |
| 合规要点 | ① 分类不是「管理层想怎么分就怎么分」，须有**业务模式文档 + SPPI 测试底稿**；② 权益工具指定 FVOCI 是**不可撤销**选择，且处置时**不能把累计公允价值变动转入投资收益**——这一点直接影响利润表与税务口径；③ 「其他权益工具投资」与「其他债权投资」名称相近但处理完全不同：前者是权益、后者是债权且有减值；④ 分类错误会导致后续计量、减值、披露连锁错误，是审计高频调整事项 |
| 信源 | ① https://kjs.mof.gov.cn/zhengcefabu/201704/t20170406_2575699.htm（财政部：CAS22 修订通知与准则正文）<br>② https://m.mof.gov.cn/czxw/201704/t20170406_2575623.htm（财政部：金融工具准则修订说明，「四分类改三分类」「已发生损失改预期损失」） |
| 核验 | 2026-11-07 联网核验：三分类与 SPPI、权益工具不可撤销指定 FVOCI 三处口径与财政部修订说明一致 |

## 43.3 CAS22 预期信用损失：三阶段模型与「减值的会计 ≠ 税前扣除」

| 字段 | 内容 |
|---|---|
| 文号 | 《企业会计准则第 22 号——金融工具确认和计量》（财会〔2017〕7 号）关于金融工具减值的规定 |
| 发文机关 | 财政部 |
| 效力层级 | 具体会计准则（规范性文件） |
| 公布/施行 | 按 43.1 三档施行（非上市企业 2021-01-01） |
| 时效性 | 现行有效 |
| 适用范围 | 以摊余成本计量的金融资产、以公允价值计量且变动计入其他综合收益的债权类金融资产、租赁应收款、合同资产等 |
| 核心条款 | ① **预期信用损失（ECL）三阶段**：第一阶段——初始确认后信用风险**未显著增加**，按**12 个月**预期信用损失计量；第二阶段——信用风险**显著增加但尚未发生信用减值**，按**整个存续期** ECL 计量；第三阶段——**已发生信用减值**，按整个存续期 ECL 计量，且利息收入按**摊余成本（已扣减值）**计算；② **简化方法**：应收账款、合同资产、租赁应收款可不分阶段，直接按**整个存续期 ECL** 计量（实务常用「准备矩阵/账龄法」）；③ 减值利得可转回，计入当期损益；④ 与旧准则「已发生损失法」的区别：新准则**提前**确认未来违约风险，不以「已发生」为前提 |
| 合规要点 | ① 会计计提的信用减值损失**不得直接税前扣除**——《企业所得税法》第十条第（七）项「未经核定的准备金支出」不得扣除；② 实际发生坏账损失，按**国家税务总局公告 2011 年第 25 号**（企业资产损失所得税税前扣除管理办法）以**专项申报**方式扣除，并留存证据链（法院判决、破产清算、逾期三年以上且有专项报告等）；③ 因此形成**可抵扣暂时性差异**，确认递延所得税资产（以未来很可能取得足够应纳税所得额为限）；④ 「会计计提 ≠ 税务扣除」是汇算清缴最常见的调整之一，A105000 表「资产减值准备金」栏次调增，实际损失年度通过 A105090 表调减 |
| 信源 | ① https://kjs.mof.gov.cn/zhengcefabu/201704/t20170406_2575699.htm（财政部：CAS22 准则正文，预期信用损失法）<br>② https://m.mof.gov.cn/czxw/201704/t20170406_2575623.htm（财政部：修订说明，「已发生损失法改为预期损失法」）<br>③ https://www.gov.cn/gongbao/content/2007/content_609907.htm（中国政府网：《企业所得税法》第十条不得扣除项目） |
| 核验 | 2026-11-07 联网核验：三阶段模型与财政部修订说明一致；税前扣除限制以企业所得税法第十条与 2011 年第 25 号公告为准 |

## 43.4 CAS23 金融资产转移：终止确认的三道门槛

| 字段 | 内容 |
|---|---|
| 文号 | 《企业会计准则第 23 号——金融资产转移》（财会〔2017〕8 号） |
| 发文机关 | 财政部 |
| 效力层级 | 具体会计准则（规范性文件） |
| 公布/施行 | 2017-03-31 发布；按 43.1 三档施行（与 CAS22 同步） |
| 时效性 | 现行有效 |
| 适用范围 | 票据贴现、应收账款保理、资产证券化、债权转让、回购交易等金融资产转移业务 |
| 核心条款 | ① **终止确认三步判断**：第一步，是否**转移**了收取现金流量的合同权利，或承担了「**过手**」义务；第二步，是否转移了**几乎全部风险和报酬**（是→终止确认；否→继续确认；未转移也未保留→第三步）；第三步，是否**放弃了对该金融资产的控制**（是→终止确认；否→按**继续涉入**程度确认相关资产与负债）；② **过手测试**三条件：从该金融资产收到对价的现时权利、不挪用、不延误支付；③ **继续涉入**：按涉入程度确认资产，并确认相应负债；④ 转移**不满足**终止确认条件的，视为**以该金融资产为担保向转入方借款**，确认金融负债 |
| 合规要点 | ① 「卖断」不等于「出表」——**附追索权的保理、附回购条款的转让**通常不满足风险报酬转移，不能终止确认；② 票据贴现：商业承兑汇票贴现若附追索权，一般按**短期借款**处理而非终止确认，与税务「贴现息计入财务费用」的时点会产生差异；③ 终止确认产生的损益在会计上计入当期损益，但**税法按转让所得/损失**以历史成本为计税基础计算，二者可能不同；④ 资产证券化「真实出售」认定须同时看**过手测试 + 风险报酬 + 控制**，不能只看合同名称 |
| 信源 | ① https://kjs.mof.gov.cn/zhengcefabu/201704/t20170406_2575699.htm（财政部：CAS22 修订通知，明确同时执行 CAS23 财会〔2017〕8 号）<br>② https://m.mof.gov.cn/czxw/201704/t20170406_2575623.htm（财政部：金融工具三项准则修订说明） |
| 核验 | 2026-11-07 联网核验：文号与施行安排由财政部通知确认；终止确认三步判断为 CAS23 核心逻辑，与 IFRS 9 趋同 |

## 43.5 CAS24 套期会计：三类套期与「有效性」

| 字段 | 内容 |
|---|---|
| 文号 | 《企业会计准则第 24 号——套期会计》（财会〔2017〕9 号） |
| 发文机关 | 财政部 |
| 效力层级 | 具体会计准则（规范性文件） |
| 公布/施行 | 2017-03-31 发布；按 43.1 三档施行（与 CAS22 同步） |
| 时效性 | 现行有效 |
| 适用范围 | 为管理外汇风险、利率风险、商品价格风险、信用风险等而使用衍生工具进行套期的企业 |
| 核心条款 | ① **三类套期**：**公允价值套期**（对被套期项目公允价值变动风险）、**现金流量套期**（对被套期项目未来现金流量变动风险）、**境外经营净投资套期**；② 适用套期会计须同时满足：套期关系**正式指定并书面记录**、**经济关系**存在、**信用风险不主导**公允价值变动、**套期比率**合理；③ 会计处理：公允价值套期——套期工具与被套期项目的公允价值变动**均计入当期损益**；现金流量套期——有效部分计入**其他综合收益**，无效部分计入当期损益，被套期项目影响损益时**转出**；④ 新准则取消「80%–125% 定量有效性测试」的硬门槛，改为**定性 + 定量结合**的经济关系评估 |
| 合规要点 | ① 套期会计是**可选**的，但一旦指定须有**书面文档**（风险管理目标、策略、套期关系、有效性评估方法），否则不得适用；② 税务上**不承认套期会计的递延效果**：套期工具的浮盈浮亏一般在实际处置/交割时计入应纳税所得额，现金流量套期计入其他综合收益的部分**不产生当期纳税义务**；③ 因此「会计损益」与「应纳税所得额」在套期期间可能大幅背离，须建立**台账**逐笔跟踪；④ 投机性衍生工具不得适用套期会计，其公允价值变动计入当期损益 |
| 信源 | ① https://kjs.mof.gov.cn/zhengcefabu/201704/t20170406_2575699.htm（财政部：CAS22 修订通知，明确同时执行 CAS24 财会〔2017〕9 号）<br>② https://m.mof.gov.cn/czxw/201704/t20170406_2575623.htm（财政部：修订说明，「使套期会计更如实反映风险管理活动」） |
| 核验 | 2026-11-07 联网核验：文号与「三类套期」表述以财政部修订说明与准则文本为准；税务处理按历史成本与实际实现原则推导，无专门套期税务文件 |

## 43.6 CAS2 长期股权投资：范围、成本法与权益法

| 字段 | 内容 |
|---|---|
| 文号 | 《企业会计准则第 2 号——长期股权投资》（财会〔2014〕14 号） |
| 发文机关 | 财政部 |
| 效力层级 | 具体会计准则（规范性文件） |
| 公布/施行 | 2014-03-13 发布，**2014-07-01 施行**（所有执行企业会计准则的企业） |
| 时效性 | 现行有效 |
| 适用范围 | 对被投资单位实施**控制**（子公司）、**共同控制**（合营企业）、**重大影响**（联营企业）的权益性投资 |
| 核心条款 | ① **范围三分**：控制、共同控制、重大影响；**不具有控制/共同控制/重大影响**的权益性投资，改按 **CAS22 金融资产**处理（2014 年修订的核心变化）；② **成本法**：适用于**对子公司的投资**（个别财务报表），按初始投资成本计量，被投资单位宣告分派现金股利时确认投资收益；③ **权益法**：适用于**合营企业、联营企业**，按应享有/分担的被投资单位**净损益、其他综合收益、其他权益变动**调整长期股权投资账面价值，并确认投资收益/其他综合收益；④ **权益法下**：投资方与联营/合营企业之间的**未实现内部交易损益**按持股比例抵销（顺流、逆流均抵销；构成业务的除外；资产减值损失不抵销）；⑤ 初始投资成本小于应享有可辨认净资产公允价值份额的差额，计入**营业外收入** |
| 合规要点 | ① 「控制/共同控制/重大影响」的判断依据分别是 **CAS33、CAS40、CAS2**，不是「持股 50%/20%」的机械标准；② 权益法确认的投资收益是**会计利润**，税法在**被投资方作出利润分配决定**时才确认股息收入（实施条例第十七条），二者存在**时间性差异**；③ 权益法下确认的「其他综合收益」「其他权益变动」**不影响当期损益**，也不影响应纳税所得额；④ 转让股权时，**计税基础是历史成本**，不是权益法调整后的账面价值，须做纳税调整；⑤ 不具有控制/共同控制/重大影响的投资，**不得再按长期股权投资核算**（2014 年后属准则适用错误） |

## 43.8 金融工具的四个税会差异：公允价值、减值、利息、股息

| 时效性 | 现行有效 |
| 适用范围 | 企业持有金融资产（交易性金融资产、债权投资、其他债权投资、其他权益工具投资等）的税务处理 |
