# 12 会计、审计与代理记账

> 核验日期：2026-11-05 ｜ 信源：财政部（法规库、会计司）、中国政府网、全国人大常委会 2026 年度立法工作计划
> 定位：会计核算是税务申报的基础，本主题覆盖会计法律、准则、档案、内控与代理记账资质。会计与税务差异（如收入确认、税前扣除）在实务中须分别处理。

---

## 12.1 《中华人民共和国会计法》（2024 年修正）

| 字段 | 内容 |
|---|---|
| 发文机关 | 全国人大常委会 |
| 效力层级 | 法律 |
| 公布/施行 | 1985 年制定；1993、1999、2017 年修正；**2024-06-28 第十四届全国人大常委会第十次会议修正，2024-07-01 施行** |
| 时效性 | 现行有效 |
| 适用范围 | 国家机关、社会团体、公司、企业、事业单位和其他组织 |
| 核心条款 | ① 单位负责人对本单位会计工作和会计资料的真实性、完整性负责；② 必须依法设置会计账簿，不得私设“账外账”；③ 不得伪造、变造会计凭证、会计账簿，不得提供虚假财务会计报告；④ 2024 年修正**大幅提高法律责任**：对单位罚款上限提高，对直接负责的主管人员和其他直接责任人员加大处罚，并强化与刑法衔接；⑤ 会计机构、会计人员对不真实、不合法的原始凭证有权不予受理 |
| 合规要点 | ① 财务造假的法律责任已显著加重，“老板授意、会计执行”不能免责；② 两套账、虚列成本既违反会计法也构成偷税；③ 会计人员应留存书面异议记录，降低个人执业风险 |
| 信源 | 全国人大网 2024-06-28 修正决定；财政部会计司解读 |
| 核验 | 2026-11-05 核验修正与施行日期 |

## 12.2 《企业财务会计报告条例》

| 字段 | 内容 |
|---|---|
| 文号 | 国务院令第 287 号 |
| 发文机关 | 国务院 |
| 效力层级 | 行政法规 |
| 公布/施行 | 2000-06-21 公布，**2001-01-01 施行** |
| 时效性 | 现行有效 |
| 适用范围 | 企业编制、对外提供财务会计报告 |
| 核心条款 | ① 财务会计报告由会计报表、会计报表附注和财务情况说明书组成；② 会计报表包括资产负债表、利润表、现金流量表及相关附表；③ 企业应按规定期限对外提供，上市公司另有规定；④ 编制须以真实、完整的会计账簿记录为依据，不得编造；⑤ 单位负责人对财务会计报告的合法性、真实性负责 |
| 合规要点 | ① 向银行、投资人提供的报表与纳税申报表口径不一致，需能合理解释；② 报表附注中的关联方、或有事项、会计政策变更须充分披露；③ 提供虚假报告可能同时触发行政处罚与刑事责任 |
| 信源 | 中国政府网国务院令第 287 号 |
| 核验 | 2026-11-05 核验文号与施行日期 |

## 12.3 《企业会计准则——基本准则》

| 字段 | 内容 |
|---|---|
| 文号 | 财政部令第 33 号（2006）；财政部令第 76 号修改（2014-07-23） |
| 发文机关 | 财政部 |
| 效力层级 | 部门规章 |
| 公布/施行 | 2006-02-15 发布，2007-01-01 施行；2014 年修改 |
| 时效性 | 现行有效 |
| 适用范围 | 执行企业会计准则的企业 |
| 核心条款 | ① 会计确认、计量和报告以**权责发生制**为基础；② 会计信息质量要求：可靠性、相关性、可理解性、可比性、实质重于形式、重要性、谨慎性、及时性；③ 会计要素：资产、负债、所有者权益、收入、费用、利润；④ 计量属性：历史成本、重置成本、可变现净值、现值、公允价值；⑤ 财务报告目标：向使用者提供决策有用信息并反映管理层受托责任 |
| 合规要点 | ① “实质重于形式”是税务与会计争议的高频点（如名股实债、售后回购）；② 公允价值计量需有可观察输入值或估值技术支撑；③ 会计政策一经选定不得随意变更，变更需披露 |
| 信源 | 财政部令第 76 号；财政部会计司准则汇编 |
| 核验 | 2026-11-05 核验文号与修改日期 |

## 12.4 《小企业会计准则》

| 字段 | 内容 |
|---|---|
| 文号 | 财会〔2011〕17 号 |
| 发文机关 | 财政部 |
| 效力层级 | 部门规范性文件（会计制度） |
| 公布/施行 | 2011-10-18 发布，**2013-01-01 施行** |
| 时效性 | 现行有效 |
| 适用范围 | 符合《中小企业划型标准规定》的小型企业（微型企业参照执行）；股票或债券在市场上公开交易的小企业、金融机构等不适用 |
| 核心条款 | ① 以历史成本计量为主，简化公允价值与减值处理；② 长期股权投资采用成本法；③ 所得税采用**应付税款法**，不确认递延所得税；④ 财务报表至少包括资产负债表、利润表、现金流量表及附注；⑤ 与《企业会计准则》衔接：执行小企业会计准则的企业，公开发行股票或债券时应转执行企业会计准则 |
| 合规要点 | ① 小企业会计准则可显著降低核算成本，但不能与企税税前扣除口径混同；② 享受小型微利企业优惠按税法口径判断，与会计制度选择无关；③ 一旦转执行企业会计准则，不得随意转回 |
| 信源 | 财政部财会〔2011〕17 号原文 |
| 核验 | 2026-11-05 核验文号、施行日与适用范围 |

## 12.5 《代理记账管理办法》

| 字段 | 内容 |
|---|---|
| 文号 | 财政部令第 80 号（2016-02-16 公布）；财政部令第 98 号修改（2019-03-14 公布施行） |
| 发文机关 | 财政部 |
| 效力层级 | 部门规章 |
| 公布/施行 | 2016-05-01 施行；2019-03-14 修改并施行 |
| 时效性 | 现行有效 |
| 适用范围 | 除会计师事务所以外的代理记账机构及其业务 |
| 核心条款 | ① 从事代理记账须经**县级以上财政部门批准**并领取代理记账许可证书；② 机构条件：依法设立的企业、**专职从业人员不少于 3 名**、负责人具有会计师以上职称或从事会计工作不少于 3 年且为专职、有健全的业务内部规范；③ 审批：受理后 10 日内作出决定，批准后 10 日内发证并公示；④ 每年 **4 月 30 日前**向审批机关报送基本情况表与专职从业人员变动情况；⑤ 委托人须提供真实完整原始凭证，代理机构对不当会计处理要求应拒绝；⑥ 无证经营由财政部门依法查处 |
| 合规要点 | ① 选代账机构先查许可证与年度备案，低价“无证代账”风险极高；② 委托合同应明确资料真实性责任、交接手续与档案保管；③ 代账机构帮助企业虚开发票、做两套账，双方均担责 |
| 信源 | 财政部令第 98 号；财政部法规库；中国政府网公报 |
| 核验 | 2026-11-05 核验 3 名专职、10 日审批、4 月 30 日备案等硬指标 |

## 12.6 《会计基础工作规范》

| 字段 | 内容 |
|---|---|
| 文号 | 财会字〔1996〕19 号（2019 年财政部令第 98 号一并修改相关条款） |
| 发文机关 | 财政部 |
| 效力层级 | 部门规范性文件 |
| 公布/施行 | 1996-06-17 发布施行，2019 年修改 |
| 时效性 | 现行有效 |
| 适用范围 | 国家机关、社会团体、企事业单位的会计基础工作 |
| 核心条款 | ① 会计凭证：原始凭证内容须真实完整，记账凭证须连续编号、附件齐全；② 会计账簿：总账、明细账、日记账须按规定设置与登记，错账更正采用划线更正、红字冲销、补充登记；③ 会计报表：数字真实、计算准确、内容完整、编报及时；④ 会计交接：移交清册、监交人、双方签章；⑤ 会计人员回避制度：单位负责人直系亲属不得担任会计机构负责人 |
| 合规要点 | ① 原始凭证缺失是税前扣除被否的最常见原因；② 电子会计凭证须符合真实性、完整性要求并妥善归档；③ 交接不清导致账目断裂，责任难以划分 |
| 信源 | 财政部财会字〔1996〕19 号；财政部令第 98 号修改决定 |

## 12.7 《会计档案管理办法》

| 字段 | 内容 |
|---|---|
| 文号 | 财政部、国家档案局令第 79 号 |
| 发文机关 | 财政部、国家档案局 |
| 效力层级 | 部门联合规章 |
| 公布/施行 | 2015-12-11 公布，**2016-01-01 施行** |
| 时效性 | 现行有效 |
| 适用范围 | 国家机关、社会团体、企事业单位的会计档案管理 |
| 核心条款 | ① 会计档案包括会计凭证、会计账簿、财务会计报告及其他会计资料；② **保管期限**：原始凭证、记账凭证、总账、明细账、日记账等 30 年；月度、季度财务报告 10 年；年度财务报告、会计档案保管清册、销毁清册**永久**；银行对账单、余额调节表 10 年；③ 会计档案一般不得借出，确需借阅须经单位负责人批准；④ 销毁须经单位负责人批准，由档案与会计机构共同监销，未了结债权债务的档案不得销毁；⑤ 电子会计档案须满足可读、可检索、防篡改要求 |
| 合规要点 | ① 稽查追溯期可能跨越多年，30 年保管期意味着凭证不能“到期就扔”；② 销毁前须确认无未了事项，否则可能构成隐匿、故意销毁会计凭证罪；③ 电子档案需有备份与迁移机制，避免系统更换后无法读取 |
| 信源 | 财政部、国家档案局令第 79 号原文 |
| 核验 | 2026-11-05 核验保管期限（30 年/10 年/永久） |

## 12.9 《中华人民共和国注册会计师法》与 2026 年修法计划

| 字段 | 内容 |
|---|---|
| 发文机关 | 全国人大常委会 |
| 效力层级 | 法律 |
| 公布/施行 | 1993-10-31 通过，1994-01-01 施行；2014-08-31 修正 |
| 时效性 | 现行有效；**2026 年列入全国人大常委会立法工作计划“修改”项目** |
| 适用范围 | 注册会计师、会计师事务所及执业行为 |
| 核心条款 | ① 注册会计师须通过全国统一考试并注册，执行业务须加入会计师事务所；② 会计师事务所可从事审计、验资、资产评估、会计咨询等业务；③ 注册会计师对出具的审计报告真实性、合法性负责，不得明知委托人对重要事项作不实表述而不予指明；④ 违规可警告、罚款、暂停执业、吊销证书，构成犯罪的追究刑责 |
| 合规要点 | ① 审计报告不是“背书”，保留意见、无法表示意见会直接影响融资与投标；② 更换事务所不能消除已发现的财务问题；③ 2026 年修法可能调整执业监管与责任条款，需跟踪 |
| 信源 | 全国人大网注册会计师法；全国人大常委会 2026 年度立法工作计划（中国税务报 2026-05 报道） |
| 核验 | 2026-11-05 核验 2014 修正与 2026 年修法计划 |
