## 22.1 企业资产损失所得税税前扣除

| 字段 | 内容 |
|---|---|
| 文号 | **国家税务总局公告 2011 年第 25 号**（《企业资产损失所得税税前扣除管理办法》）＋ **国家税务总局公告 2018 年第 15 号**（资产损失资料留存备查） |
| 发文机关 | 国家税务总局 |
| 效力层级 | 部门规范性文件（公告） |
| 公布/施行 | 25 号公告 2011 年发布施行；15 号公告自 2018 年企业所得税汇算清缴起适用 |
| 时效性 | 现行有效 |
| 适用范围 | 企业所得税查账征收纳税人发生的实际资产损失、法定资产损失 |
| 核心条款 | ① 第六条：以前年度实际资产损失未在当年扣除的，可**追补至损失发生年度扣除，追补期限一般不超过 5 年**；特殊原因（体制转轨遗留、重组上市权属争议、国家政策性任务、政策定性不明）经总局批准可延长；法定资产损失在申报年度扣除；② 多缴税款在追补确认年度应纳税款中抵扣，不足部分向以后年度递延；③ 第九/十条按清单申报与专项申报分类（正常经营转让、存货正常损耗、固定资产正常报废、生产性生物资产正常死亡、按市价买卖证券期货等属清单申报，其余专项申报）；④ 15 号公告：**申报扣除仅需填报 A105090《资产损失税前扣除及纳税调整明细表》，不再报送资料，资料由企业留存备查** |
| 合规要点 | ① 留存备查 ≠ 免于举证，证据链（内部审批、盘点、评估、司法文书、会计处理凭证）须完整；② 追补 5 年是**硬期限**，逾期一般不得扣除；③ 与「不征税收入对应资产折旧不得扣除」（财税〔2011〕70 号，见 `20-20.6`）区分处理 |
| 信源 | 国家税务总局 12366 平台法规库 https://12366.chinatax.gov.cn/bzds/062/062-5-3.html ；国家税务总局青岛市税务局答复 https://qingdao.chinatax.gov.cn/ssfg2019/cjwt/qysds/202004/t20200430_55850.html |
| 核验 | 2026-11-06 12366 法规原文 + 青岛市局答复 + 陕西省局纳税人学堂三源核对 |

## 22.2 亏损结转弥补年限与顺序

| 字段 | 内容 |
|---|---|
| 文号 | **财税〔2018〕76 号**（《关于延长高新技术企业和科技型中小企业亏损结转年限的通知》）＋ 税务总局配套处理公告 ＋ **国家税务总局公告 2025 年第 1 号**（优化企业所得税年度纳税申报表） |
| 发文机关 | 财政部、国家税务总局 |
| 效力层级 | 规范性文件（通知/公告） |
| 公布/施行 | 财税〔2018〕76 号自 **2018-01-01** 起；配套公告 2018-08-23 发布并自 2018-01-01 施行；2025 年第 1 号公告适用于现行申报表 |
| 时效性 | 现行有效 |
| 适用范围 | 一般企业亏损结转 5 年；**高新技术企业、科技型中小企业最长 10 年**；南沙高新技术重点行业企业 13 年（财税〔2022〕40 号，见 `20-20.16`） |
| 核心条款 | ① 当年具备高新或科技型中小企业资格的企业，其**具备资格年度之前 5 个年度**发生的尚未弥补完亏损（无论当时是否具备资格），最长结转年限由 5 年延长至 **10 年**；② 高新技术企业按证书注明有效期所属年度确定资格年度，科技型中小企业按入库登记编号注明年度确定；③ 发生特殊性税务处理的合并/分立重组，承继亏损的结转年限按被合并/被分立企业确定；④ **2025 年第 1 号公告**：弥补顺序按「亏损到期年限优先、到期年限相同则先弥补更早发生的亏损」 |
| 合规要点 | ① 资格年度认定错误会少算可弥补年度，务必按证书/入库编号年度而非取得日期推算；② 查补以前年度所得额后须同步更正以后年度 A106000《企业所得税弥补亏损明细表》，否则后续申报连锁错误；③ 5/10/13 年三档不可混用 |
| 信源 | 国家税务总局政策文件 https://www.chinatax.gov.cn/n810341/n810765/n3359382/n3359434/c3829162/content.html ；中国税务报（河北省税务局转载） http://hebei.chinatax.gov.cn/lfsw/lfs/gzdt/gzdt/202603/t20260309_3642196.html |
| 核验 | 2026-11-06 总局公告原文 + 中国税务报案例双源核对 5/10 年与弥补顺序 |

## 22.3 企业重组特殊性税务处理

| 字段 | 内容 |
|---|---|
| 文号 | **财税〔2009〕59 号**（《关于企业重组业务企业所得税处理若干问题的通知》） |
| 发文机关 | 财政部、国家税务总局 |
| 效力层级 | 规范性文件（通知） |
| 公布/施行 | 2009 年印发，现行有效（后续由财税〔2014〕109 号等文件调整比例条件，本条仅记录基础框架） |
| 时效性 | 现行有效 |
| 适用范围 | 企业法律形式改变、债务重组、股权收购、资产收购、合并、分立 |
| 核心条款 | ① 区分**一般性税务处理**（按公允价值确认资产转让所得/损失）与**特殊性税务处理**（符合条件可递延确认）；② 特殊性处理须同时满足合理商业目的、不以减少/免除/推迟缴税为主要目的、重组后连续 12 个月内不改变重组资产原来的实质性经营活动、取得股权支付的原主要股东 12 个月内不转让所取得股权等条件；③ 合并/分立中尚未弥补完亏损的承继按该文件及财税〔2018〕76 号配套公告处理 |
| 合规要点 | ① 特殊性税务处理**不是免税**，是递延；须做备案/申报并留存商业目的说明；② 股权支付比例、收购比例等具体门槛在后续文件有调整，**个案适用前必须回查现行有效文件**；③ 与亏损弥补年限、资产损失追补交叉，建议由执业税务师出具专项意见 |
| 信源 | 国家税务总局政策文件（财税〔2018〕76 号配套公告明确援引） https://www.chinatax.gov.cn/n810341/n810765/n3359382/n3359434/c3829162/content.html ；国家税务总局 12366 平台 https://12366.chinatax.gov.cn/ |
| 核验 | 2026-11-06 由总局现行公告交叉援引确认文号与框架；**具体比例门槛未逐项核验，不写入结论** |

## 22.4 全年一次性奖金单独计税

| 字段 | 内容 |
|---|---|
| 文号 | **财政部 税务总局公告 2023 年第 30 号**（《关于延续实施全年一次性奖金个人所得税政策的公告》）；基础口径 **财税〔2018〕164 号**、**国税发〔2005〕9 号** |
| 发文机关 | 财政部、国家税务总局 |
| 效力层级 | 规范性文件（公告/通知） |
| 公布/施行 | 2023-08-18 公布；**执行至 2027-12-31** |
| 时效性 | 现行有效 |
| 适用范围 | 居民个人取得符合国税发〔2005〕9 号规定的全年一次性奖金 |
| 核心条款 | ① 2027-12-31 前**不并入当年综合所得**，以奖金收入除以 12 个月所得数额，按按月换算后的综合所得税率表确定税率和速算扣除数，单独计税：应纳税额 = 全年一次性奖金收入 × 适用税率 − 速算扣除数；② 纳税人**也可选择并入当年综合所得**计税；③ 一个纳税年度内只能对一处按此办法计税 |
| 合规要点 | ① 两种计税方式结果差异大，发放前应逐个测算并选择；② 与股权激励单独计税、专项附加扣除可并行，但不得对同一笔收入重复适用；③ 2027-12-31 到期，纳入集中续期预警 |
| 信源 | 财政部税政司 https://szs.mof.gov.cn/zhengcefabu/202308/t20230828_3904328.htm ；国家税务总局广东省税务局 https://guangdong.chinatax.gov.cn/gdsw/fssw_nsrxt_kjxz/2025-10/09/content_0bce2918d5514cbda89f1532a0effcd3.shtml |
| 核验 | 2026-11-06 财政部原文 + 广东省税务局 2025-10 政策汇编 + 上海市税务局转载三源核对 |

## 22.5 上市公司股权激励单独计征个税

| 字段 | 内容 |
|---|---|
| 文号 | **财政部 税务总局公告 2023 年第 25 号**（《关于延续实施上市公司股权激励有关个人所得税政策的公告》）；条件依据 **财税〔2016〕101 号**第四条第（一）项、财税〔2005〕35 号、财税〔2009〕5 号、财税〔2015〕116 号第四条；衔接 **财税〔2018〕164 号** |
| 发文机关 | 财政部、国家税务总局 |
| 效力层级 | 规范性文件（公告/通知） |
| 公布/施行 | 2023-08-18 公布；**执行期 2024-01-01 至 2027-12-31** |
| 时效性 | 现行有效 |
| 适用范围 | 居民个人取得股票期权、股票增值权、限制性股票、股权奖励等符合条件的上市公司股权激励 |
| 核心条款 | ① 2027-12-31 前**不并入当年综合所得**，全额单独适用综合所得税率表计税：应纳税额 = 股权激励收入 × 适用税率 − 速算扣除数；② 一个纳税年度内取得**两次（含）以上**股权激励的，应合并按财税〔2018〕164 号第二条第（一）项计算 |
| 合规要点 | ① 非上市公司股权激励符合条件的可适用财税〔2016〕101 号递延纳税，与上市公司单独计税是两套规则；② 多次授予必须合并计算，勿按单次分别申报；③ 与全年一次性奖金单独计税可并行，但须分别核算 |
| 信源 | 国家税务总局广东省税务局 https://guangdong.chinatax.gov.cn/gdsw/fssw_nsrxt_kjxz/2025-10/09/content_0bce2918d5514cbda89f1532a0effcd3.shtml ；国家税务总局山东省税务局《2023 年以来出台的现行有效税费优惠政策清单》 https://shandong.chinatax.gov.cn/module/download/downfile.jsp?classid=0&filename=1b47d9a7b800421787b8c7da8c727a38.pdf |
| 核验 | 2026-11-06 广东省税务局政策汇编 + 山东省税务局优惠清单双源核对文号与期限 |
