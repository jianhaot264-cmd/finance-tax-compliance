> 覆盖：11 个税种的纳税人、税目税率、计税依据、纳税义务时间、申报、优惠、常见风险。
> 本文件为 **A 层**：每条 10 字段 + 至少 2 个官方信源 + 核验日期 2026-11-08。
> ⚠️ 小税种的特点：**金额小、税目细、易漏报、滞纳金按日万分之五**。本文件给的是执行框架，具体税额标准（资源税/环保税/车船税/耕地占用税/船舶吨税）以税法附表和地方标准为准。

## 45.1 关税：税率种类、完税价格与 15 日纳税期

| 发文机关 | 全国人民代表大会常务委员会 |
| 效力层级 | 法律（海关征收） |
| 公布/施行 | 2024-04-26 通过，2024-12-01 施行；共 7 章（总则、税目和税率、应纳税额、税收优惠和特殊情形、征收管理、法律责任、附则） |
| 时效性 | 现行有效 |
| 适用范围 | 进口货物、出口货物的收货人/发货人；进境物品的携带人、收件人 |

| 信源 | ① https://www.gov.cn/yaowen/liebiao/202404/content_6947671.htm（中国政府网：关税法 2024-04-26 通过、2024-12-01 施行，7 章结构）<br>② https://www.chinatax.gov.cn/chinatax/n810219/n810744/c103147/c5249424/5249424/files/8e2bb59af3de4dec860e856ad66be304.pdf（年度报告：关税纳税人、计税依据、税率种类）<br>③ https://fgk.chinatax.gov.cn/（关税法原文；海关总署配套公告） |

| 发文机关 | 全国人民代表大会常务委员会 |

## 45.5 资源税：从价为主、税目税率表、减免项目要留证

| 字段 | 内容 |
|---|---|
| 文号 | 《中华人民共和国资源税法》（2019-08-26 第十三届全国人大常委会第十二次会议通过，**2020-09-01 施行**） |
| 发文机关 | 全国人民代表大会常务委员会 |
| 效力层级 | 法律 |
| 公布/施行 | 2019-08-26 通过，2020-09-01 施行 |
| 时效性 | 现行有效 |
| 适用范围 | 在境内和管辖海域**开发应税资源**的单位和个人（矿产品、盐、水气矿产等） |
| 核心条款 | ① **税率**：按《资源税税目税率表》执行，**从价计征为主**（原矿/精矿/金锭等），部分税目从量；② **计税依据**：应税资源产品的销售额（不含增值税）或销售数量；③ **纳税地点**：应税矿产品**开采地**或**生产地**；④ **减免**：开采原油以及在油田范围内运输原油过程中用于加热的原油/天然气免征；煤炭开采企业因安全生产需要抽采的煤层气免征；**低品位矿、尾矿、共伴生矿**等由省级决定减免；**衰竭期矿山**减征 30%；**充填开采**减征 50%；⑤ **水资源税**自 **2024-12-01** 起全面实施（财税〔2024〕28 号），按实际取用水量从量计征，具体税额由各省确定；地下水超采区加征 |
| 合规要点 | ① 资源税是**开采环节**税，不是销售环节的增值税替代；② 自采自用（非连续生产）也要视同销售；③ 减免项目须**留存开采/检测/利用证据**，否则不得享受；④ 跨省开采、总部与矿山分离的，纳税地点在**开采地**；⑤ 尾矿、废石综合利用等与环保税、增值税优惠可能叠加，注意分别判断 |
| 信源 | ① https://www.chinatax.gov.cn/chinatax/n810219/n810744/c103147/c5249424/5249424/files/8e2bb59af3de4dec860e856ad66be304.pdf（年度报告：资源税纳税人与「按税目税率表执行」）<br>② https://fgk.chinatax.gov.cn/（资源税法及税目税率表；财政部 税务总局 2020 年第 34 号公告执行口径） |
| 核验 | 2026-11-08 联网核验：施行日、从价为主、衰竭期 30%/充填 50% 与现行税法一致；省级减免项目以各省公告为准 |

## 45.6 环境保护税：四类污染物、污染当量、监测数据决定税基

| 字段 | 内容 |
|---|---|
| 文号 | 《中华人民共和国环境保护税法》（2016-12-25 第十二届全国人大常委会第二十五次会议通过，**2018-01-01 施行**）；《环境保护税法实施条例》（国务院令第 693 号） |
| 发文机关 | 全国人民代表大会常务委员会；国务院 |
| 效力层级 | 法律 + 行政法规 |
| 公布/施行 | 税法 2018-01-01；实施条例同步 |
| 时效性 | 现行有效 |
| 适用范围 | 直接向环境排放应税污染物的企业事业单位和其他生产经营者 |
| 核心条款 | ① **四类应税污染物**：大气污染物、水污染物、固体废物、噪声；② **计税依据**：大气/水污染物按**污染当量数**，固体废物按**排放量**，噪声按**超标分贝数**；③ **税额**：按《环境保护税税目税额表》，大气 1.2–12 元/污染当量、水 1.4–14 元/污染当量、固废 5–1000 元/吨、噪声 350–11200 元/月（超标分贝分档）；④ **减免**：排放浓度值低于国家标准 **30%** 的减按 **75%** 征收，低于 **50%** 的减按 **50%** 征收；⑤ **免征**：农业生产（不包括规模化养殖）、机动车/铁路机车/非道路移动机械等流动污染源、依法设立的污水/生活垃圾处理场所排放相应污染物、符合标准综合利用固废 |
| 合规要点 | ① 环保税与**排污许可**、在线监测、物料衡算挂钩，数据不实会被追征并处罚；② 「低于标准 30%/50%」以**自动监测/手工监测**数据为准，不能估算；③ 固体废物综合利用要区分「符合标准」与「不符合标准」，后者仍要缴税；④ 建筑扬尘、施工噪声多由**施工方**申报，甲方不是纳税人；⑤ 环保税按季申报，终了之日起 15 日内 |
| 信源 | ① https://www.chinatax.gov.cn/chinatax/n810219/n810744/c103147/c5249424/5249424/files/8e2bb59af3de4dec860e856ad66be304.pdf（年度报告：环保税四类污染物与税目税额表）<br>② https://fgk.chinatax.gov.cn/（环境保护税法及实施条例 693 号令） |
| 核验 | 2026-11-08 联网核验：四类污染物、30%/50% 两档减征、实施条例 693 号与现行规定一致；具体税额以各省人大确定的标准为准 |
