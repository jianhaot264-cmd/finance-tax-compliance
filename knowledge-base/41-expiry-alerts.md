## 41.5 到期预警机制（90/60/30 天三档动作）

| 字段 | 内容 |
|---|---|
| 文号 | 内部机制；工具：`app/expiry_scan.py` → `reports/expiry-radar-*.md` |
| 发文机关 | 项目组（内部 SOP） |
| 效力层级 | 内部作业规范 |
| 公布/施行 | 2026-11-07 起执行 |
| 时效性 | 现行有效 |
| 适用范围 | 知识库维护、企业税务测算、代理记账客户管理 |
| 核心条款 | ① **T-90 天**：标记到期政策，检索是否已发布延续文件；未发布则在知识库与问答中提示「可能不再适用」；② **T-60 天**：完成敏感性测算（如小微 5%→25%、小规模 1%→3%、前海 15%→25%），形成客户告知清单；③ **T-30 天**：确认申报口径，更新下一年度预算与合同定价；④ **到期后**：未延续的从知识库「现行有效」移入「已失效」，并复查所有引用该政策的规则与条目；⑤ 工具：`python app/expiry_scan.py --days 400` 生成雷达报告（按到期日分组、含条目 ID 与原文摘录） |
| 合规要点 | ① 预警必须**基于原文日期**，不凭记忆；② 到期不等于立即失效（部分政策按年度适用），需看具体表述；③ 对客户的通知要留痕，避免「未告知」争议；④ 延续文件发布后，需同步更新知识库版本日志与规则引用 |
| 信源 | ① https://guangdong.chinatax.gov.cn/gdsw/dgsw_yhssyshj2024_zcwj_ndbg/2025-03/31/971dcd23bac140039c47f99012882a7b/files/c918938933084806b463f9dc975c37c0.pdf（到期日集中分布的官方依据）<br>② http://sz.people.cn/n2/2026/0207/c202846-41496148.html（延续文件的官方报道示例：前海延至 2027-12-31） |

| 字段 | 内容 |
|---|---|
| 文号 | 内部方法；依据各到期政策文号（见 41.1、41.2） |
| 发文机关 | 项目组（内部方法） |
| 效力层级 | 内部作业规范 |
| 公布/施行 | 2026-11-07 |
| 时效性 | 现行有效 |
| 适用范围 | 受到期政策影响的企业与代账机构 |
