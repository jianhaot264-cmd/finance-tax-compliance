# 消费税税目税率现行汇编（15 税目）

> 覆盖：15 个税目的现行税率、征收环节、计税方法与高频错算点。
> 本文件为 **A 层**：每条 10 字段 + 至少 2 个官方信源 + 核验日期 2026-11-07。
> ⚠️ **生产系统不得硬编码《消费税暂行条例》所附 2008 版税率表**：条例仍有效，但税率已经多次调整（卷烟、成品油、电子烟、超豪华小汽车等），必须以现行公告为准。

## 32.3 酒类（白酒、黄酒、啤酒、其他酒）

| 发文机关 | 国务院；国家税务总局 |
| 效力层级 | 行政法规 + 部门规范性文件 |

| 时效性 | 现行有效 |
| 适用范围 | 生产、委托加工、进口酒类产品的单位和个人 |
| 核心条款 | ① **白酒**：**20% ＋ 0.5 元/500 克（或 500 毫升）** 复合计税；② **黄酒**：**240 元/吨** 从量；③ **啤酒**：甲类（出厂价≥3000 元/吨，不含增值税）**250 元/吨**，乙类（<3000 元/吨）**220 元/吨**；④ **其他酒**：10%；⑤ 白酒生产企业销售给销售单位的白酒，计税价格低于销售单位对外销售价格 70% 以下的，税务机关可核定最低计税价格 |
| 合规要点 | ① 白酒是**复合计税**，只算 20% 会少缴；② 啤酒类别按**出厂价**划分，包装物押金是否并入销售额按押金规则处理；③ 以自产应税消费品连续生产应税消费品的，可按当期生产领用量**扣除**已纳消费税（白酒除外，白酒外购/委托加工已纳税款不得扣除）；④ 配制酒、泡制酒按「其他酒」10% 还是「白酒」20%，取决于工艺与酒精度，是常见争议点 |
| 信源 | ① https://xiamen.chinatax.gov.cn/xmswcms/content/S1233.html（厦门市税务局：白酒 20%+0.5 元/500 克、黄酒 240 元/吨、啤酒 250/220 元/吨、其他酒 10%）<br>② https://news.hbtv.com.cn/p/4615023.html（湖北广电《税务一点通》专访湖北省税务局货劳处：白酒与黄酒税率、未分别核算从高适用） |

## 32.7 计税方法与高频错算点

| 字段 | 内容 |
|---|---|
| 文号 | 《消费税暂行条例》第五条至第十条；《消费税暂行条例实施细则》 |
| 发文机关 | 国务院；财政部、国家税务总局 |
| 效力层级 | 行政法规 + 部门规章 |
| 公布/施行 | 2009-01-01 |
| 时效性 | 现行有效 |
| 适用范围 | 全部消费税纳税人 |
| 核心条款 | ① **从价定率**：应纳税额＝销售额×比例税率；② **从量定额**：应纳税额＝销售数量×定额税率；③ **复合计税**：应纳税额＝销售额×比例税率＋销售数量×定额税率（卷烟、白酒）；④ **自产自用**：用于连续生产应税消费品的不纳税；用于其他方面的，按同类售价或组成计税价格纳税；⑤ **委托加工**：由受托方（个人除外）代收代缴，组成计税价格＝（材料成本＋加工费）÷（1－比例税率）；⑥ **进口**：组成计税价格＝（关税完税价格＋关税）÷（1－比例税率）；⑦ **兼营不同税率**应税消费品应分别核算，未分别核算或组成成套销售的**从高适用**税率 |
| 合规要点 | ① 复合计税只算从价是最常见少缴；② 组成计税价格公式的分母是「1－税率」，写成「1＋税率」会算错；③ 自产自用「连续生产」与「其他方面」的界限是高频争议；④ 外购/委托加工已纳消费税的扣除仅限**规定情形**（白酒等不得扣除），且需按领用量计算；⑤ 金银首饰改在零售环节后，生产环节不再征收，跨环节企业勿重复计缴 |
