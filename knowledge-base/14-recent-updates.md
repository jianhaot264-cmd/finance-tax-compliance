## 14.1 《个人所得税综合所得汇算清缴管理办法》

| 字段 | 内容 |
|---|---|
| 文号 | 国家税务总局令第 57 号 |
| 发文机关 | 国家税务总局 |
| 效力层级 | 部门规章 |
| 公布/施行 | 2025 年发布施行（具体公布日以税务总局官网为准） |
| 时效性 | 现行有效 |
| 适用范围 | 居民个人综合所得（工资薪金、劳务报酬、稿酬、特许权使用费）年度汇算清缴 |
| 核心条款 | ① 以**部门规章**形式确立汇算清缴制度，提升制度化、规范化水平；② 明确汇算办理渠道（个人所得税 APP、自然人电子税务局、办税服务厅）、退补税流程与申报表体系；③ 明确无需办理汇算的情形与应办理情形；④ 对虚假申报、拒不办理等行为设定法律责任 |
| 合规要点 | ① 每年 3 月 1 日至 6 月 30 日办理上一年度汇算；② 取得两处以上综合所得、预扣率高于全年适用税率、需补税金额较大等情形通常需办理；③ 专项附加扣除信息须在年度内确认，逾期补充可能影响扣除；④ 退税申请须如实填报，虚假填报会被追回并影响信用 |
| 信源 | 国家税务总局《中国税务年度报告（2025）》政策清单 |
| 核验 | 2026-11-05 核验规章名称、文号与制度要点；具体施行日待原文复核 |

## 14.2 资源税有关政策执行口径

| 字段 | 内容 |
|---|---|
| 文号 | 财政部 税务总局公告 2025 年第 12 号 |
| 发文机关 | 财政部、国家税务总局 |
| 效力层级 | 部门规范性文件 |
| 公布/施行 | 2025 年发布施行 |
| 时效性 | 现行有效 |
| 适用范围 | 资源税纳税人（矿产品、盐等） |
| 核心条款 | ① 细化**不征税情形**与适用税目；② 明确具体征税对象与计税依据；③ 规范关联交易情形下的计税价格；④ 明确自用于连续生产非应税产品的处理；⑤ 细化减免税计算方法、减免税管理与纳税义务发生时间 |
| 合规要点 | ① 资源税按原矿/选矿产品口径不同，计税依据须与销售形态匹配；② 关联交易价格明显偏低的，税务机关可按合理方法调整；③ 自用连续生产非应税产品不征资源税，但改变用途须补税；④ 减免税应按规定留存备查资料 |
| 信源 | 财政部 税务总局公告 2025 年第 12 号；税务总局年度报告 |
| 核验 | 2026-11-05 核验文号与细化事项范围 |

## 14.3 优化企业所得税预缴纳税申报

| 字段 | 内容 |
|---|---|
| 文号 | 国家税务总局公告 2025 年第 17 号 |
| 发文机关 | 国家税务总局 |
| 效力层级 | 税务规范性文件 |
| 公布/施行 | 2025 年发布施行 |
| 时效性 | 现行有效 |
| 适用范围 | 企业所得税纳税人（按月/按季预缴） |
| 核心条款 | ① 明确**节能节水、环境保护、安全生产专用设备抵免**政策可在预缴环节享受；② 明确出口企业的申报要求；③ 优化预缴申报表与填报口径，减少汇算清缴阶段集中调整 |
| 合规要点 | ① 预缴享受抵免须取得专用设备发票与合规凭证，并按规定抵免限额计算；② 预缴多享受优惠可能导致汇算补税与滞纳金，需留存测算底稿；③ 出口企业应关注免抵退税与预缴申报的衔接 |
| 信源 | 国家税务总局公告 2025 年第 17 号；税务总局年度报告 |
| 核验 | 2026-11-05 核验文号与两项核心内容 |

| 效力层级 | 部门规范性文件 |
| 公布/施行 | 2025 年发布施行 |
| 时效性 | 现行有效 |
| 适用范围 | 执行新保险合同会计准则的保险企业 |
| 核心条款 | ① 明确保险合同会计准则转换涉及的企业所得税事项；② 对转换产生的收入、费用、准备金差异的税务处理给出衔接口径；③ 避免会计口径变化直接造成重复征税或税款流失 |
| 合规要点 | ① 会计转换不等于税务调整，需按税法口径单独计算；② 准备金、递延所得税等项目的税会差异应建立台账；③ 保险企业申报时应关注专项申报表与附报资料要求 |
| 信源 | 财政部 税务总局公告 2025 年第 15 号；税务总局年度报告 |
