# 16 增值税法实施与高频实操规则（2026 生产版）

> 核验日期：2026-11-06 ｜ 信源：中国政府网、国家税务总局政策法规库、司法部行政法规库、上海/云南/广西/山西/辽宁税务局
> 定位：《增值税法》2026-01-01 施行后的**可操作规则**，覆盖进项抵扣、扣税凭证、不得抵扣、纳税义务发生时间、身份登记。

| 时效性 | 现行有效 |

## 16.2 《中华人民共和国增值税法》进项税额不得抵扣规则

| 字段 | 内容 |
|---|---|
| 文号 | 中华人民共和国主席令第四十一号 |
| 发文机关 | 全国人大常委会 |
| 效力层级 | 法律 |
| 公布/施行 | 2024-12-25 通过，**2026-01-01 施行**；《增值税暂行条例》同时废止 |
| 时效性 | 现行有效 |
| 适用范围 | 发生应税交易的单位和个人 |
| 核心条款 | ① 第二十二条：下列进项税额不得从销项税额中抵扣——(一)适用简易计税方法计税项目对应的进项；(二)免征增值税项目对应的进项；(三)非正常损失项目对应的进项；(四)购进并用于集体福利或个人消费的货物、服务、无形资产、不动产对应的进项；(五)购进并直接用于消费的餐饮服务、居民日常服务和娱乐服务对应的进项；(六)国务院规定的其他进项；② 第六条：不属于应税交易（不征税）情形——员工为受雇单位提供取得工资薪金的服务、收取行政事业性收费和政府性基金、依法被征收征用取得补偿、取得存款利息收入；③ 第二十八条：纳税义务发生时间（收讫销售款项或取得索取凭据当日；先开票的为开票当日；视同应税交易为完成当日；进口为报关进口当日） |
| 合规要点 | ① 2026 年起「不得抵扣」依据由暂行条例/36 号文上升为法律条文，合同与账务系统需同步更新；② 餐饮服务、居民日常服务、娱乐服务即使取得专票也不得抵扣；③ 存款利息、政府补偿等不征税项目不要误开增值税发票 |
| 信源 | https://shanghai.chinatax.gov.cn/tax/ftzs/202601/t479130.html （上海税务局《增值税法及其实施条例可视答疑》，引条文）；https://yunnan.chinatax.gov.cn/art/2026/2/28/art_3855_87521.html （云南税务局 12366 引第二十八条、第三十八条） |
| 核验 | 2026-11-06 双源交叉核验条文编号与内容 |

## 16.3 《中华人民共和国增值税法实施条例》扣税凭证与进项转出

| 字段 | 内容 |
|---|---|
| 文号 | 国务院令第 826 号 |
| 发文机关 | 国务院 |
| 效力层级 | 行政法规 |
| 公布/施行 | 2025-12-25 公布，**2026-01-01 施行**（第五十四条） |
| 时效性 | 现行有效 |
| 适用范围 | 增值税纳税人 |
| 核心条款 | ① 第十二条：可抵扣进项包括增值税专用发票、海关进口增值税专用缴款书、自境外单位/个人购进服务无形资产或境内不动产的完税凭证、农产品收购发票或销售发票计算的进项、其他增值税扣税凭证；② 第二十三条：购进货物（不含固定资产）、服务用于简易计税、免税项目、不得抵扣非应税交易而无法划分的，按销售额或收入占比逐期计算不得抵扣进项，并于**次年 1 月申报期内全年汇总清算**；③ 第二十四条：已抵扣进项发生第二十二条第三至五项情形的，应从当期进项中扣减，无法确定对应进项的按当期实际成本计算；④ 第三十九条：收讫销售款项、取得索取凭据当日的定义（书面合同付款日；无合同或合同未定付款日的，为应税交易完成当日）；⑤ 第四十一条：出口货物报关出口日期早于一般纳税义务时点的，以报关出口当日为准 |
| 合规要点 | ① 固定资产与货物/服务的分摊规则不同，不要混用；② 全年汇总清算是 2026 年新增义务，需在次年 1 月申报期前完成；③ 合同付款日期条款会直接影响纳税义务时间，签约模板应同步评估 |
| 信源 | https://shanghai.chinatax.gov.cn/tax/ftzs/202601/t479130.html （上海税务局答疑引第十二条）；https://guangxi.chinatax.gov.cn/nsfw/bszx/nszx_detail.html?metadataid=12006 （广西税务局引第二十三、二十四、五十四条）；https://shanxi.chinatax.gov.cn/hdjl/zxbjxq/sx-11400-519-54555 （山西 12366 引第三十九至四十一条） |
| 核验 | 2026-11-06 三源交叉核验条文编号与施行日 |

| 核心条款 | ① 小规模纳税人＝年应征增值税销售额未超过 **500 万元**；会计核算健全、能提供准确税务资料的小规模纳税人可主动登记按一般计税方法纳税；② 自然人属于小规模纳税人；不经常发生应税交易且主要业务不属于应税交易范围的非企业单位，可选择按小规模纳税人纳税；③ 超过标准应办理一般纳税人登记，生效之日为**超过规定标准的当期 1 日**，且不早于 2026-01-01；④ 年应征销售额按连续不超过 12 个月或 4 个季度累计，偶然销售无形资产/转让不动产不计入；⑤ 相关证明资料（会计核算健全说明、偶然交易证明、选择/退出小规模纳税的经营情况材料）留存备查 |
| 合规要点 | ① 2026 年起不再由纳税人自选「当月 1 日/次月 1 日」生效，超标即当期生效，跨期票据与收入归属要提前管理；② 43 号令已废止，申报与内控文档不得再引用；③ 逾期不登记可能按销售额依税率计税且不得抵扣进项 |

## 16.5 增值税纳税义务发生时间（三层规则汇总）

| 字段 | 内容 |
|---|---|
| 文号 | 《增值税法》第二十八条；《增值税法实施条例》第三十九、四十、四十一条；财政部 税务总局公告 2026 年第 13 号第四条 |
| 发文机关 | 全国人大常委会、国务院、财政部、国家税务总局 |
| 效力层级 | 法律 + 行政法规 + 部门规范性文件 |
| 公布/施行 | 均自 2026-01-01 起施行 |
| 时效性 | 现行有效 |
| 适用范围 | 发生应税交易、视同应税交易、进口货物的纳税人 |
| 核心条款 | ① 一般规则：收讫销售款项或取得索取销售款项凭据的当日；先开具发票的为开票当日；② 视同应税交易：货物发出、金融商品所有权转移、无形资产转让完成或不动产转让完成当日；③ 进口货物：报关进口当日；④ 特殊：大型机械设备/船舶/飞机（工期>12 个月）按收款或合同约定付款日；预收款分期服务按首次提供服务日与合同约定日孰先、就全部价款申报；销售不动产按权属登记或实际交付孰先；⑤ 出口货物报关出口日早于一般时点的，以报关出口当日为准 |
| 合规要点 | ① 「先开票先纳税」是硬规则，预开票会提前纳税义务；② 合同付款日条款、交付与验收节点要纳入税务内控；③ 与收入确认的会计口径可能不同，需建立税会差异台账 |
