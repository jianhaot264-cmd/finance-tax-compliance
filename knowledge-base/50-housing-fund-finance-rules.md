# 50 · 住房公积金与财务基础法规（缴存 / 提取 / 贷款 / 会计法）

> 定位：中小企业用工成本与个人住房金融的高频规则 + 财务合规基础法规速查。A 层条目可直接引用；速查类 B2 条目引用前回查原文。
> 核验：2026-11-09 依据国务院公报、中国人民银行、全国人大网双源编录。

## 50.1 《住房公积金管理条例》（2019 年修订版框架）

| 字段 | 内容 |
|---|---|
| 文号 | 国务院令第 262 号发布（1999-04-03）；2002 年第一次修订；2019-03-24 国务院令第 710 号第二次修订 |
| 发文机关 | 国务院 |
| 效力层级 | 行政法规 |
| 公布/施行 | 2019 修订版自公布之日起施行 |
| 时效性 | 现行有效 |
| 适用范围 | 境内国家机关、企事业单位、民办非企业单位、社会团体及其**在职职工**（个体工商户/灵活就业人员缴存由各地另行规定） |
| 核心条款 | 公积金属职工个人所有（第三条）；单位应办理缴存登记与账户设立（第十三至十五条：新设单位 30 日内登记、20 日内开户；录用/离职 30 日内办理）；月缴存额 = 上年度月平均工资 × 缴存比例（第十六条）；缴存比例均不得低于 5%（第十八条）；单位按时足额缴存，困难可申请降低比例或缓缴（第二十条）；企业缴存在**成本**中列支（第二十三条） |
| 合规要点 | ①「入职 30 日内开户、离职 30 日内封存/转移」是硬时限；②单位不缴/少缴：责令限期缴存，逾期可申请法院强制执行（第三十八条），不办登记罚款 1 万–5 万（第三十七条）；③公积金不属于社保，但同为用工合规必查项，稽查与劳动仲裁常一并主张；④缴存基数上限一般为当地社平工资 3 倍、下限为最低工资，属地每年公布 |
| 核验 | 2026-11-09 以中国政府网国务院公报 2019 修订全文与 710 号令修改决定双源核验 |
| 信源 | https://www.gov.cn/gongbao/content/2019/content_5468861.htm ；https://www.gov.cn/zhengce/content/2019-04/10/content_5381233.htm |

## 50.2 公积金缴存实务：比例、基数与企业列支

| 字段 | 内容 |
|---|---|
| 文号 | 《住房公积金管理条例》第十六至二十三条；建设部等《关于住房公积金管理若干具体问题的指导意见》（建金管〔2005〕5 号，缴存比例上限 12%） |
| 发文机关 | 国务院；建设部、财政部、中国人民银行 |
| 效力层级 | 行政法规 + 部门规范性文件 |
| 公布/施行 | 条例现行有效；建金管〔2005〕5 号 2005 年发布 |
| 时效性 | 现行有效（基数上下限逐年调整） |
| 适用范围 | 建立住房公积金制度的城镇单位及其在职职工 |
| 核心条款 | 缴存比例单位与个人**各 5%–12%**（同比例执行，具体由公积金管理委员会拟订、省政府批准）；缴存基数为职工上年度月平均工资，上限一般为当地社平工资 3 倍、下限为最低工资标准；新参加工作职工从第二个月起缴存；个人部分由单位每月工资代扣，单位应于发薪日起 5 日内汇缴 |
| 合规要点 | ①5% 是法定下限、12% 是政策上限（超过 12% 部分需并入工资计个税）；②基数不是「实发工资」，是上年度月平均工资（含奖金津贴）；③单位缴存部分在企业成本列支，可税前扣除（企业所得税口径属合理工资薪金性质支出，见 17 系列）；④广州缴存基数上下限以广州住房公积金管理中心年度公告为准 |
| 核验 | 2026-11-09 编录；比例上下限为建金管〔2005〕5 号通行口径，属地执行以当地中心公告为准 |
| 信源 | https://www.gov.cn/gongbao/content/2019/content_5468861.htm （条例第十六至二十三条）；各地住房公积金管理中心年度缴存调整公告（属地检索） |

## 50.3 公积金提取六种法定情形与办理

| 字段 | 内容 |
|---|---|
| 文号 | 《住房公积金管理条例》第二十四、二十五条 |
| 发文机关 | 国务院 |
| 效力层级 | 行政法规 |
| 公布/施行 | 2019 修订版现行 |
| 时效性 | 现行有效 |
| 适用范围 | 缴存住房公积金的职工 |
| 核心条款 | 六情形可提取存储余额：①购买、建造、翻建、大修自住住房；②离休退休；③完全丧失劳动能力并与单位终止劳动关系；④出境定居；⑤偿还购房贷款本息；⑥房租超出家庭工资收入规定比例。②③④提取同时注销账户。办理：单位核实出具提取证明 → 中心受理 → **3 日内**作出准予与否决定 |
| 合规要点 | ①「租房提取」一般按月/按年限额提取（属地额度），不是全额取；②异地购房提取按购房地政策，多地已互认；③死亡/被宣告死亡的，继承人、受遗赠人可提取（同时注销）；④伪造材料骗提会被列入黑名单、退回资金并影响后续使用，属违规红线 |
| 核验 | 2026-11-09 以国务院公报全文核验 |
| 信源 | https://www.gov.cn/gongbao/content/2019/content_5468861.htm （第二十四、二十五条）；https://www.gov.cn/zhengce/content/2019-04/10/content_5381233.htm |

## 50.4 住房公积金贷款利率（2024-05-18 起执行）

| 字段 | 内容 |
|---|---|
| 文号 | 《中国人民银行关于下调个人住房公积金贷款利率的通知》（2024-05-17 发布） |
| 发文机关 | 中国人民银行 |
| 效力层级 | 部门规范性文件 |
| 公布/施行 | 自 2024-05-18 起执行 |
| 时效性 | 现行有效（调整前已发放的存量贷款自 2025-01-01 起执行新利率） |
| 适用范围 | 个人住房公积金贷款（首套与第二套） |
| 核心条款 | 下调 0.25 个百分点后：**首套** 5 年以下（含 5 年）**2.35%**、5 年以上 **2.85%**；**二套** 5 年以下（含 5 年）**不低于 2.775%**、5 年以上 **不低于 3.325%**。范围含新发放与存量贷款（存量 2025-01-01 起执行） |
| 合规要点 | ①二套利率是「不低于」下限，具体上浮由属地与银行确定；②额度上限由各地公积金管理委员会确定（与利率分属两套规则）；③利率调整后仍显著低于同期商贷，组合贷款优先用足公积金额度；④再次调整以央行公告为准，不得硬编码本表 |
| 核验 | 2026-11-09 以中国人民银行官网通知与中国政府网政策解读双源核验 |
| 信源 | https://www.pbc.gov.cn/goutongjiaoliu/113456/113469/2025092212554094241/index.html ；https://www.gov.cn/zhengce/202405/content_6951980.htm |

## 50.5 《会计法》2024 年修正要点（2024-07-01 施行）

| 字段 | 内容 |
|---|---|
| 文号 | 全国人大常委会《关于修改〈中华人民共和国会计法〉的决定》（2024-06-28 通过） |
| 发文机关 | 全国人民代表大会常务委员会 |
| 效力层级 | 法律 |
| 公布/施行 | 2024-06-28 通过并公布；自 2024-07-01 起施行 |
| 时效性 | 现行有效 |
| 适用范围 | 国家机关、社会团体、公司、企业、事业单位和其他组织办理会计事务 |
| 核心条款 | ①加强财会监督：单位内部会计监督制度**纳入内部控制制度**（第二十五条）；②提高违法成本：不依法设置账簿等 10 类行为、伪造变造凭证/账簿、编制虚假财务报告，罚款额度大幅提高（授意指使造假可处 20 万–100 万元，情节严重 100 万–500 万元）；③违法处罚按国家规定**记入信用记录**；④支持会计数字化转型；⑤单位负责人对会计资料真实性完整性负责（第四条，历版保留） |
| 合规要点 | ①中小企业最容易踩的三条：不建账/账外账、白条入账、两套报表——2024 修正后罚款上限大幅提高且进信用记录；②会计人员五年内禁业条款保留（伪造造假情形）；③内控不再是上市公司专属，法律已普遍要求「建立、健全」；④与《会计档案管理办法》《小企业会计准则》配套使用，见 50.6 |

## 50.6 财务基础法规速查（会计档案 · 现金管理 · 代理记账 · 小企业准则）

| 字段 | 内容 |
|---|---|
| 文号 | 《会计档案管理办法》（财政部 国家档案局令第 79 号）；《现金管理暂行条例》（国务院令第 12 号，1988 发布、2011 修订）；《代理记账管理办法》（财政部令第 80 号，2019 年修改）；《小企业会计准则》（财会〔2011〕17 号） |
| 发文机关 | 财政部、国家档案局；国务院；财政部 |
| 效力层级 | 部门规章 + 行政法规 + 会计准则（汇编型条目） |
| 公布/施行 | 79 号令 2016-01-01 施行；现金条例 1988-10-01 施行；80 号令 2016-05-01 施行；小企业准则 2013-01-01 施行 |
| 时效性 | 汇编·动态（各文件独立时效，引用前逐件核验） |
| 适用范围 | 所有建账单位（会计档案、现金）；不具备单独设置会计机构条件的单位（代理记账）；小企业（准则） |
| 核心条款 | ①会计档案：原始凭证、记账凭证、总账明细账、财务报告等保存 **30 年**，年度财务报告**永久**保存，银行对账单与余额调节表 10 年（79 号令附表）；②现金管理：开户单位可用现金范围限于职工工资津贴、个人劳务报酬、差旅费、结算起点（1000 元）以下零星支出等，超范围应转账；③代理记账：须经批准（会计师事务所或专门代理记账机构），双方签订委托合同，本单位仍须指定专人负责货币资金与资产；④小企业会计准则：简化科目与报表体系（小企业可选执行，微型企业适用《小企业会计准则》门槛见工信部联企业〔2011〕300 号划型） |
| 合规要点 | ①档案销毁不得自行处置，须按 79 号令鉴定、清册、监销；②「坐支现金」「白条抵库」是现金管理最常见违规；③代理记账不转移单位负责人责任（会计法第四条）——出事后老板仍是第一责任人；④执行《小企业会计准则》的企业不计提资产减值准备、不确认递延所得税，税会差异处理更简单；⑤本条为汇编索引，具体申报与年限请回查各文件原文 |
