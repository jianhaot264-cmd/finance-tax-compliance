# 05 广东省 · 地方性法规与政策（含大湾区平台税收优惠）

> 核验日期：2026-11-04 ｜ 信源：广东省人民政府门户（gd.gov.cn）、国家税务总局广东省税务局（guangdong.chinatax.gov.cn）、财政部官网、广东人大网

## 5.1 《广东省税费征管保障办法》★

| 字段 | 内容 |
|---|---|
| 发文机关 | 广东省人民政府 |
| 效力层级 | 省政府规范性文件（省政府制定发布） |
| 公布/施行 | 2023-12-25 公开，**2024-01-01 施行，有效期 5 年** |
| 时效性 | 现行有效（2028 年底到期前需关注延续/升格） |
| 适用范围 | 广东省行政区域内税费征收管理保障 |
| 核心条款 | 八章 43 条：① **涉税费信息共享实行目录管理**，由税务机关牵头会同政务服务数据管理部门制定、动态调整；② 电子商务平台、网络直播平台经营者应向税务机关报送平台内经营者身份信息和涉税费信息；③ 服务支持：电子发票应用推广、第三方机构参与服务、涉税费争议处理机制；④ 征缴协助：税费优惠便捷享受机制、信息查询协助；⑤ 监管协作：税费信用纳入社会信用体系，守信激励/失信惩戒；涉税专业服务机构监管（违规税收策划、歪曲解读将被惩治）；⑥ 执法协助：**税警制度化常态化联合办案**，行刑衔接打击虚开、骗税、抗税；⑦ 地方政府及部门不得违法干预税收征管 |
| 合规要点 | ① 在粤企业的涉税数据已进入部门共享目录（市场监管、自然资源、住建、水电燃气等），申报数据与其他部门数据交叉比对是常态化监管方式——口径一致性是合规生命线；② 平台内经营者（电商/直播）的涉税信息报送义务已地方化明确；③ 聘请涉税服务机构要审查其执业合规（违规策划连带风险） |
| 信源 | 广东省人民政府门户 www.gd.gov.cn/zzzq/zcjd/content/post_4306653.html 及解读 post_4305580 |
| 核验 | 2026-11-04 联网核验（官方解读全文） |

## 5.3 《广东省社会保险基金监督条例》

| 字段 | 内容 |
|---|---|
| 发文机关 | 广东省人大常委会 |
| 效力层级 | 省地方性法规 |
| 公布/施行 | 2004-03-30 通过，**2016-03-31 修订，2016-07-01 施行**（省人大常委会公告第 55 号） |

| 核心条款 | 八章 71 条：① 人大监督、行政监督、社会监督"三位一体"；② 契合广东"社保部门制定政策、**税务机关全责征收**、财政专户管理、经办机构计发待遇"模式；③ 用人单位禁止行为：瞒报漏报缴费基数人数、以发放补贴/签订协议形式拒缴、虚构劳动关系骗保、伪造材料骗取待遇、重复领取、冒用身份、出借社保证件等；④ 社保服务机构不得虚列支付项目、冒名就医、过度诊疗等；⑤ 现场检查程序（两名以上人员、3 个工作日前送达通知书等） |
| 合规要点 | 在粤企业注意：以"现金补贴替代社保""不签合同规避参保"被条例明文禁止且属监督重点 |

## 5.6 粤港澳大湾区重大平台税收优惠（国家政策在粤落地）

### 5.6.1 横琴粤澳深度合作区
- **企业所得税**：2022 年财政部、税务总局印发《关于横琴粤澳深度合作区企业所得税优惠政策的通知》——对科教研发和高端制造、中医药/澳门品牌工业、文旅会展商贸、现代金融等 **9 大类 150 项产业**减按 15% 征收企业所得税，并要求实质性运营（合作区已出台实施细则和实质性运营办法）。
- **个人所得税**：2022 年印发《关于横琴粤澳深度合作区个人所得税优惠政策的通知》——境内外**高端人才和紧缺人才个税负超过 15% 的部分直接免征**（方式由补贴改为直接免征）；对澳门居民个税负超过澳门税负部分予以免征（"澳人澳税"）。
- 社保配套：合作区用人单位 2025-04-01 起自行申报社保费（见 5.4）；"粤澳社保一窗通"支持澳门居民在横琴办理澳门社保。
- 核验：2026-11-04 经财政部官网、广东省政府门户核验（政策名称/年份/要点）；**具体文号待核验**（引用时以财政部官网原文为准）。

### 5.6.2 前海深港现代服务业合作区
- **企业所得税**：财政部、税务总局《关于延续实施前海深港现代服务业合作区企业所得税优惠政策的通知》（**财税〔2026〕3 号**）明确继续对符合条件的鼓励类产业企业减按 **15%** 征收，执行期**延长至 2027-12-31**；此前为财税〔2021〕30 号、财税〔2024〕13 号（均止于 2025-12-31）。
- 核验：2026-11-07 联网核验——**财税〔2026〕3 号**已确认（前海 15% 延至 2027-12-31）；此前财税〔2021〕30 号、〔2024〕13 号均止于 2025-12-31。

### 5.6.3 广州南沙
- **企业所得税**：2022 年财政部、税务总局出台南沙企业所得税优惠——高新技术重点行业、信息技术等**八大鼓励类产业**企业减按 15% 征收；并在国内首次对南沙 4 个重点领域高新技术重点行业企业**延长亏损结转年限**。
- **个人所得税**：对在南沙工作的港澳居民个税负超过港澳税负部分予以免征（"港人港税"）。
- 核验：2026-11-04 经财政部官网、广东省政府门户核验（政策框架）；文号待核验。

### 5.6.4 河套深港科技创新合作区
- 对鼓励类产业企业减按 15% 征收企业所得税；对在河套工作的香港居民免征个税负超过港澳税负部分（经广东省大湾区办 2024 年公开表述核验）。

### 5.6.5 大湾区境外人才个税补贴（珠三角九市）
- 《关于粤港澳大湾区个人所得税优惠政策的通知》（**财税〔2019〕31 号**）：对在大湾区珠三角九市工作的境外（含港澳台）高端人才和紧缺人才，其个税负超过 15% 的部分由珠三角九市政府给予补贴。
- 核验：2026-11-07 已核验——财税〔2019〕31 号由**财税〔2023〕34 号**延续至 **2027-12-31**，引用须并列两文号。
