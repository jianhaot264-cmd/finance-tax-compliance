# 社保分险种实操（广东 2026）

> 覆盖：养老、医疗（含生育）、失业、工伤四类费率的广东口径，缴费基数上下限，登记申报与滞纳金。
> 本文件为 **A 层**：每条 10 字段 + 至少 2 个官方信源 + 核验日期 2026-11-07。
> ⚠️ 社保费**省级统筹、地市差异大**：本文件费率以广东省口径为主，基数与医疗费率须按参保地确认；深圳市单列。

## 30.7 未缴/少缴的法律后果（滞纳金、罚款、约定无效）

| 字段 | 内容 |
|---|---|
| 文号 | 《社会保险法》第八十六条；《最高人民法院关于审理劳动争议案件适用法律问题的解释（二）》（**法释〔2025〕12 号**）第十九条；《全国税务行政处罚裁量基准（2026 年版）》 |
| 发文机关 | 全国人大常委会；最高人民法院；国家税务总局 |
| 效力层级 | 法律 + 司法解释 + 部门规范性文件 |
| 公布/施行 | 社会保险法 2011-07-01；法释〔2025〕12 号 **2025-09-01 施行**；裁量基准 2026-11-01 施行 |
| 时效性 | 现行有效 |
| 适用范围 | 用人单位 |
| 核心条款 | ① 未按时足额缴纳的，由征收机构责令限期缴纳或补足，**自欠缴之日起按日加收万分之五的滞纳金**；逾期仍不缴纳的，可处欠缴数额 **1 倍以上 3 倍以下**罚款；② 法释〔2025〕12 号第十九条：用人单位与劳动者约定或劳动者承诺**不缴纳社会保险费的一律无效**；劳动者据此解除合同并要求经济补偿的，人民法院应予支持；③ 2026-11-01 起「用人单位逾期不缴或少缴社保费」已列入全国税务行政处罚裁量基准处罚事项 |
| 合规要点 | ① 「员工自愿放弃 + 承诺书」**不能免除**缴费义务，且成为员工主张经济补偿的证据；② 滞纳金按日万分之五（年化约 18.25%），拖久成本高于补缴本身；③ 补缴不当然免除罚款，是否处罚按裁量基准与首违不罚判断 |
| 信源 | ① https://xapp.southcn.com/node_fb07388412?k=0bcc0a491f&temp=1（南方网：明确「不得通过约定变更或放弃」，引社会保险法第五十八条）<br>② https://zhrsj.zhuhai.gov.cn/hd/hygq/sb/content/post_3904271.html（珠海市人社局：参保义务与登记要求） |
| 核验 | 2026-11-07 联网核验：社会保险法第八十六条与法释〔2025〕12 号第十九条沿用 v6 已核验结论；裁量基准施行日 2026-11-01 见 01 文件 |

## 30.8 基数口径与高频误区（最低基数、试用期、劳务派遣、跨市）

| 字段 | 内容 |
|---|---|
| 文号 | 《社会保险法》第十二条、第六十条；《社会保险费申报缴纳管理规定》（人社部令第 20 号） |
| 发文机关 | 全国人大常委会；人力资源和社会保障部 |
| 效力层级 | 法律 + 部门规章 |
| 公布/施行 | 人社部令第 20 号 2013-11-01 施行 |
| 时效性 | 现行有效 |
| 适用范围 | 全部参保单位 |
| 核心条款 | ① 缴费基数＝职工本人上年度**月平均工资**（含计时/计件工资、奖金、津贴补贴、加班费等），不是基本工资；② 新进人员按**起薪当月工资**；③ 低于下限按下限、高于上限按上限（广东 2026 养老 5510/5521–27603）；④ 劳务派遣人员由**用工单位**承担同工同酬与社保相关责任，派遣单位参保不免除用工单位连带责任 |
| 合规要点 | ① 「按最低基数缴」是最高频违法点，员工可随时主张补缴；② 只按「基本工资」申报、把奖金补贴剔除，属少缴；③ 跨市项目人员应在**用工地**参保（建筑、餐饮等流动性行业尤须注意）；④ 基数每年 7 月调整，须在申报期内切换，避免全年按旧基数 |
| 信源 | ① https://www.foshan.gov.cn/zsk?kCode=CSD00014674（佛山市政府：基数上下限与「按本人工资申报」口径）<br>② https://zhrsj.zhuhai.gov.cn/hd/hygq/sb/content/post_3904271.html（珠海市人社局：低于下限按下限、高于上限按上限） |
| 核验 | 2026-11-07 联网核验：基数口径与上下限处理规则双源一致 |
