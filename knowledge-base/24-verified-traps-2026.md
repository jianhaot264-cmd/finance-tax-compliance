## 24.2 订正：现行专项附加扣除是 **7 项**，法条原文只列 6 项

| 字段 | 内容 |
|---|---|
| 文号 | 《个人所得税法》第六条（2018 修正）；**国发〔2022〕8 号**（设立 3 岁以下婴幼儿照护）；**国发〔2023〕13 号**（提高三项标准） |
| 发文机关 | 全国人大常委会；国务院 |
| 效力层级 | 法律 + 国务院规范性文件 |
| 公布/施行 | 个税法 2019-01-01；国发〔2022〕8 号自 **2022-01-01** 起设立；国发〔2023〕13 号自 **2023-01-01** 起提标 |
| 时效性 | 现行有效 |
| 适用范围 | 居民个人综合所得汇算与预扣预缴 |
| 核心条款 | ① 个税法第六条逐字原文列举 6 项：子女教育、继续教育、大病医疗、住房贷款利息或者住房租金、赡养老人（法条授权国务院确定具体范围标准）；② **国发〔2022〕8 号增设第 7 项「3 岁以下婴幼儿照护」，每孩每月 1000 元定额扣除**，父母可选一方 100% 或双方各 50%，一个纳税年度内不得变更；③ 国发〔2023〕13 号自 2023-01-01 起：婴幼儿照护 1000→**2000 元/月**、子女教育 1000→**2000 元/月**、赡养老人 2000→**3000 元/月**（独生子女 3000，非独生子女分摊每人≤1500） |
| 合规要点 | **高频错误**：只按个税法第六条原文回答「6 项」会漏掉婴幼儿照护、且给出过期标准。智能体回答「专项附加扣除有哪几项/标准多少」必须按 **7 项 + 2023 提标后标准**，并说明「法条授权国务院，第 7 项由国发〔2022〕8 号设立」 |
| 信源 | https://www.gov.cn/zhengce/202309/content_6901816.htm （中国政府网「一老一小」提标解读，明确 2018 年以来设立 7 项）；https://shaanxi.chinatax.gov.cn/jact/front/mailpubdetail.do?sysid=181&transactId=52617 （陕西 12366 逐条引国发〔2022〕8 号与国发〔2023〕13 号）；https://www.qcclegal.com/regulation/b91d93e21073ba839f8b1c0d60ce494e/6?lcc_source=mcp （个税法第六条逐字原文） |
| 核验 | 2026-11-07 权威库回库逐字原文（6 项）+ 中国政府网与 12366 官网双源确认第 7 项与提标，两处口径一致 |

## 24.3 订正：职工教育经费现行 **8%**，条例第四十二条原文仍是 2.5%

| 字段 | 内容 |
|---|---|
| 文号 | 《企业所得税法实施条例》第四十二条；**财税〔2018〕51 号** |
| 发文机关 | 国务院；财政部、国家税务总局 |
| 效力层级 | 行政法规 + 部门规范性文件 |
| 公布/施行 | 条例 2008-01-01 施行（2024 第二次修订）；财税〔2018〕51 号自 **2018-01-01** 起执行 |
| 时效性 | 现行有效（**执行口径以 51 号文为准**） |
| 适用范围 | 全部企业所得税纳税人 |
| 核心条款 | 条例第四十二条逐字原文：「除国务院财政、税务主管部门另有规定外，企业发生的职工教育经费支出，不超过工资薪金总额 **2.5%** 的部分，准予扣除；超过部分，准予在以后纳税年度结转扣除」——**注意「除国务院财政、税务主管部门另有规定外」这一但书**；财税〔2018〕51 号正是依据该但书统一提高至 **8%**，超过部分准予结转以后年度扣除（无结转年限限制） |
| 合规要点 | ① 引用条例 2.5% 而不提 51 号文是**典型「法条没错、结论错」**；② 正确表述：「依据财税〔2018〕51 号，统一按工资薪金总额 8% 扣除，超限部分结转」；③ 软件生产企业的职工培训费、集成电路等特定行业另有全额扣除规定的从其规定 |
| 信源 | https://www.qcclegal.com/regulation/69010ae872a0667aa365f5bf5799e007/62?lcc_source=mcp （条例第四十二条逐字原文，含但书）；https://www.chinatax.gov.cn/n810341/n810765/n3359382/n3359449/c3627522/content.html （财税〔2018〕51 号原文） |
| 核验 | 2026-11-07 权威库回库 + 税务总局政策法规库双源；本库 `20-20.11` 结论正确，此条补充「为什么法条与执行口径不同」的法理依据 |

## 24.7 通用判定 SOP：法条原文 vs 后续政策

| 字段 | 内容 |
|---|---|
| 文号 | 无（方法论条目） |
| 发文机关 | 财税合规智能体项目 |
| 效力层级 | 内部质量规范 |
| 公布/施行 | 2026-11-07 |
| 时效性 | 现行有效 |
| 适用范围 | 全部问答生成与知识库维护 |
| 核心条款 | 生成结论前按序检查：① 该法条是否含但书（如「除国务院财政、税务主管部门另有规定外」）→ 有但书必须查后续规范性文件；② 该领域是否有国务院/财政部/总局的提标、延续、扩围、废止公告 → 有则以后者为准（如 51 号文、国发〔2022〕8 号、人社部发〔2026〕39 号）；③ 该法规是否有多次修订 → 引用现行版本并注明沿革（如条例 2024 第二次修订）；④ 附表/税率是否已被后续公告调整 → 禁止硬编码（如消费税附表）；⑤ 是否有草案拟改动但尚未通过 → 明确「现行仍按 X，草案拟改 Y 未生效」（如征管法修订草案拟取消清税前置） |
| 合规要点 | 回答必须区分三层：**法条原文（23 文件）→ 现行执行口径（本文件 + 各公告条目）→ 立法动态（14 文件）**；只答第一层属于「准确但无用」，混淆第二三层属于「结论错误」 |
| 信源 | 本轮 4 处实测订正（24.1–24.4）+ `SOURCES-CHANNELS.md` 八步 SOP |
| 核验 | 2026-11-07 项目内部质量复核 |
