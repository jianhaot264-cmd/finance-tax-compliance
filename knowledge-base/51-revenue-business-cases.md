## 51.1 赊销商品与应收账款确认（控制权转移）

| 字段 | 内容 |
|---|---|
| 适用范围 | 商品交付、控制权于时点转移但货款未收的赊销；两类准则均适用。 |
| 确认与计量要求 | 按 CAS14 五步法于控制权转移时点按分摊交易价格确认收入，税额按适用税率计算的增值税，按 CAS1 同步结转成本；小企业会计准则于发出商品并办妥收款手续时确认，不用五步法。 |
| 会计分录与处理流程 | 借：应收账款（价税）；贷：主营业务收入、应交税费——应交增值税（销项税额，按适用税率计算）；借：主营业务成本；贷：库存商品。①凭合同/出库单/签收单确定时点；②按客户建应收台账并辅助核算；③期末函证对账、按 CAS22 计提坏账准备（小准则不计提）。 |
| 税务处理规定 | 增值税按收讫款项/取索款凭据当日、先开票为开票当日，分期收款按合同约定收款日；以不含税销售额计税，税率以官方原文为准，须合规开票；所得税时点按现行规定。 |
| 税会差异提示 | 纳税义务与会计确认时点差异属时间性，按当期差额纳税调增/调减；设发出商品、开票与收款台账备查。 |
| 参照依据与关键条款 | 《企业会计准则第14号——收入》（财会〔2017〕22号）：控制权转移确认收入、无条件收款权列应收款；《企业会计准则——基本准则》（财政部令第33号）：权责发生制；《会计法》：核算真实完整 |
| 依据层级 | 法律＞行政法规＞部门规章＞规范性文件＞具体准则（部门规范性文件）；上位法优先，本项以具体准则为主、部门规章为辅 |
| 生效状态 | 现行有效；CAS14 分阶段施行，2026 年度已全面适用 |
| 适用边界 | 执行企业会计准则/小企业准则的一般·小规模纳税人，上市与非上市均适用；全国口径，广东等地方口径回查；含重大融资成分按 CAS14 专项条款；红线：虚开、白条入账、三流不一致、跨期调节收入 |

## 51.2 预收款/合同负债与先收款后交付

| 字段 | 内容 |
|---|---|
| 适用范围 | 先收取客户款项、后交付商品或提供服务的业务。 |
| 确认与计量要求 | 按 CAS14，已收对价而尚未履约的义务确认为合同负债，税额按适用税率计算的增值税于纳税义务发生时确认；履约时按分摊交易价格转收入并结转成本。按 CAS30 合同资产/合同负债分别列报（以官方原文为准）；小企业会计准则以预收账款核算，交付时确认收入。 |
| 会计分录与处理流程 | 借：银行存款；贷：合同负债、应交税费——待转销项税额（按适用税率计算，按现行规定判断）；交付：借：合同负债；贷：主营业务收入；借：主营业务成本；贷：库存商品。①凭合同/收款回单登记台账与开票节点；②取得签收单后结转收入成本；③期末清理未履约余额、按 CAS30 列报。 |

| 适用边界 | 执行企业会计准则（合同负债）/小企业准则（预收账款）的一般·小规模纳税人；全国口径，广东等地方口径回查；例外：长期预收租金等按 CAS21 租赁与 CAS14 合同负债规则判断，具体条款以准则原文为准；红线：预收长期挂账不结转、虚开、三流不一致 |

## 51.3 附有销售退回条款的销售

| 会计分录与处理流程 | 借：应收账款（价税）；贷：主营业务收入、预计负债——应付退货款、应交税费——应交增值税（销项税额，按适用税率计算）；借：主营业务成本、应收退货成本；贷：库存商品；退货：借：预计负债——应付退货款；贷：银行存款；借：库存商品；贷：应收退货成本。①凭合同/历史退货率留存估计依据；②设退货台账、到期结算；③期末复核估计变动并按 CAS30 列报。 |

## 51.5 销售折让、退回与红字发票

| 字段 | 内容 |

| 适用范围 | 已确认收入后发生的折让、退回及开具红字发票业务。 |
| 确认与计量要求 | 按 CAS14，折让按可变对价重新计量交易价格、冲减当期收入；退回（非日后事项）于退回当期冲减收入成本及按适用税率计算的增值税；属资产负债表日后调整事项的按 CAS29 调整报告期（以财政部会计司现行目录为准）。小企业会计准则于退回当期冲减收入成本，简化处理。 |
