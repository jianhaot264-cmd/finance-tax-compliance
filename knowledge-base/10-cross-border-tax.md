## 10.1 《非居民纳税人享受协定待遇管理办法》

| 字段 | 内容 |
|---|---|
| 文号 | 国家税务总局公告 2019 年第 35 号 |
| 发文机关 | 国家税务总局 |
| 效力层级 | 税务规范性文件 |
| 公布/施行 | 2019 年发布，2020-01-01 施行（具体公布日引用前复核） |
| 时效性 | 现行有效 |
| 适用范围 | 非居民纳税人（企业、个人）享受中国对外税收协定待遇 |
| 核心条款 | ① 改为“**自行判断、申报享受、相关资料留存备查**”，不再事前审批；② 自行申报或由扣缴义务人扣缴时直接享受，无需税务机关事先核准；③ 留存备查资料包括协定居民身份证明、与取得所得有关的合同、支付凭证、受益所有人相关材料等；④ 税务机关事后审核，发现不符合条件的追缴税款并加收滞纳金 |
| 合规要点 | ① 能否享受看“税收居民身份 + 受益所有人 + 所得类型”三要素，仅注册在协定国不等于协定居民；② 导管公司、择协避税安排会被否定；③ 留存资料须能支撑“实质经营”，否则协定优惠被追回 |
| 信源 | 国家税务总局公告原文；各地税务局非居民协定待遇办事指引 |
| 核验 | 2026-11-05 核验文号与“自行判断、申报享受、留存备查”机制 |

## 10.3 《特别纳税调查调整及相互协商程序管理办法》与关联申报同期资料

| 字段 | 内容 |
|---|---|
| 文号 | 国家税务总局公告 2016 年第 42 号（关联申报与同期资料）；2017 年第 6 号（特别纳税调查调整及相互协商程序） |
| 发文机关 | 国家税务总局 |
| 效力层级 | 税务规范性文件 |
| 公布/施行 | 2016 年第 42 号自 2016 年度关联申报起执行；2017 年第 6 号自 2017-05-01 施行 |
| 时效性 | 现行有效 |
| 适用范围 | 存在关联交易的企业，特别是跨国企业集团成员 |
| 核心条款 | ① 关联交易遵循**独立交易原则**，可选可比非受控价格法、再销售价格法、成本加成法、交易净利润法、利润分割法；② 同期资料三层文档：**主体文档**（集团合并收入超 10 亿元或需集团准备）、**本地文档**（有形资产购销超 2 亿元、金融资产转让超 1 亿元、其他关联交易超 4000 万元）、**特殊事项文档**（成本分摊协议、劳务）；③ **国别报告**：集团合并收入超 55 亿元的最终控股企业或指定报送企业；④ 主体文档在集团会计年度终了后 12 个月内准备完毕，本地文档与特殊事项文档在关联交易发生年度次年 6 月 30 日前准备完毕；⑤ 同期资料自税务机关要求之日起 30 日内提供，保存 10 年 |
| 合规要点 | ① 关联申报与年度企业所得税申报同步完成，漏报即产生罚则风险；② 跨境关联交易定价应有可比性分析支撑，长期亏损、利润与功能不匹配易被特别纳税调整；③ 被调整后可能加收利息（按基准利率加 5 个百分点） |
| 信源 | 国家税务总局公告 2016 年第 42 号、2017 年第 6 号原文 |
| 核验 | 2026-11-05 核验门槛数字与文档类型；具体金额口径以公告原文为准 |

## 10.4 《非居民金融账户涉税信息尽职调查管理办法》（CRS）

| 字段 | 内容 |
|---|---|
| 文号 | 国家税务总局、财政部、人民银行、银监会、证监会、保监会公告 2017 年第 14 号 |
| 发文机关 | 税务总局等六部门 |
| 效力层级 | 部门联合规范性文件 |
| 公布/施行 | 2017-05-09 发布，**2017-07-01 施行**；2018 年 9 月完成首次金融账户涉税信息自动交换 |
| 时效性 | 现行有效 |
| 适用范围 | 中国境内金融机构及其管理的金融账户（存款、托管、投资实体权益、保险合同等） |
| 核心条款 | ① 金融机构对存量个人账户、存量机构账户、新开账户开展尽职调查，识别**非居民**账户；② 存量个人低净值账户（合计余额不超过 100 万美元）可采用简化调查，高净值账户需强化调查；③ 新开账户须取得纳税人自我证明；④ 金融机构按年向税务机关报送账户持有人身份、账号、余额、利息/股息/出售金融资产收入等；⑤ 中国与协定伙伴国按 MCAA 每年自动交换 |
| 合规要点 | ① 境外账户、境外保单、离岸公司账户信息会被交换回中国，“藏钱”不可行；② 取得境外身份但未改变税收居民身份的，仍属中国税收居民，须申报全球所得；③ 金融机构错报、漏报面临处罚，客户提供虚假自我证明亦担责 |
| 信源 | 国家税务总局公告 2017 年第 14 号；税务总局 CRS 专题 |
| 核验 | 2026-11-05 核验施行日与首次交换时间 |

## 10.5 境外所得税收抵免（企业 + 个人）

| 字段 | 内容 |
|---|---|
| 文号 | 财税〔2009〕125 号；国家税务总局公告 2017 年第 84 号；财政部 税务总局公告 2020 年第 3 号（个人） |
| 发文机关 | 财政部、国家税务总局 |
| 效力层级 | 部门规范性文件 |
| 公布/施行 | 企业：2008 年度起；个人：2020-01-01 起（2019 年度汇算起适用） |
| 时效性 | 现行有效 |
| 适用范围 | 居民企业、居民个人来源于境外的所得 |
| 核心条款 | ① 企业境外所得已在境外缴纳的所得税税额，可在抵免限额内抵免；② 抵免限额＝中国境内外所得依税法计算的应纳税总额 × 来源于某国的应纳税所得额 ÷ 境内外应纳税所得总额；③ 2017 年第 84 号起可选择**分国不分项**或**不分国不分项（综合抵免）**，一经选择 5 年内不得改变；④ 超过抵免限额部分可在以后 5 个年度结转；⑤ 个人境外所得在次年 3 月 1 日至 6 月 30 日申报抵免 |
| 合规要点 | ① 境外所得必须申报，CRS 与情报交换下漏报风险极高；② 抵免需完税凭证或对方税务机关出具的纳税证明；③ 简易抵免（12.5% 定率）仅适用于特定情形，不可滥用 |
| 信源 | 财税〔2009〕125 号、国家税务总局公告 2017 年第 84 号、财政部 税务总局公告 2020 年第 3 号 |
| 核验 | 2026-11-05 核验文号与 5 年结转、综合抵免规则 |

## 10.6 跨境电子商务综合试验区零售出口货物税收政策

| 字段 | 内容 |
|---|---|
| 文号 | 财税〔2018〕103 号 |
| 发文机关 | 财政部、税务总局、商务部、海关总署 |
| 效力层级 | 部门规范性文件 |
| 公布/施行 | **2018-10-01 起执行**（以出口商品申报清单注明的出口日期为准） |
| 时效性 | 现行有效 |
| 适用范围 | 经国务院批准的综试区内、自建或利用第三方平台开展零售出口的企业和个体工商户 |
| 核心条款 | ① 对综试区电子商务出口企业出口**未取得有效进货凭证**的货物，同时符合三条件，试行增值税、消费税**免税**：在综试区注册并在线上综合服务平台登记出口信息；通过综试区所在地海关办理电商出口申报；不属于国家取消出口退（免）税的货物；② 海关总署定期向税务总局传输申报清单电子数据；③ 具体免税管理办法由省级税务部门商财政、商务部门制定；④ 取得有效进货凭证并符合条件者，仍可走出口退（免）税（财税〔2013〕96 号） |
| 合规要点 | ① “无票免税”是免税不是不申报，仍须办理免税申报并留存单证；② 清单、订单、物流、支付“四流”须一致；③ 买单出口、虚构清单可能被认定为骗税或偷税 |
| 信源 | 中国政府网财税〔2018〕103 号原文 |
| 核验 | 2026-11-05 核验文号、三条件与执行日 |

## 10.7 综试区跨境电商零售出口企业所得税核定征收

| 字段 | 内容 |
|---|---|
| 文号 | 国家税务总局公告 2019 年第 36 号 |
| 发文机关 | 国家税务总局 |
| 效力层级 | 税务规范性文件 |
| 公布/施行 | 2019-10-26 发布，**2020-01-01 施行** |
| 时效性 | 现行有效 |
| 适用范围 | 综试区内跨境电商零售出口企业 |
| 核心条款 | ① 同时符合三条件可试行核定征收：综试区注册并在线上综合服务平台登记出口货物信息；通过综试区所在地海关办理电商出口申报；出口货物未取得有效进货凭证且增值税、消费税享受免税；② 采用**应税所得率方式**，应税所得率统一按 **4%** 确定；③ 符合小型微利企业条件的可叠加享受小微优惠；④ 属于税法规定的免税收入仍可免税 |
| 合规要点 | ① 核定征收需税务机关鉴定，不得自行按 4% 申报；② 收入总额须准确核算，核定不等于“按开票额”；③ 4% 是应税所得率，不是税负率，实际税负＝收入×4%×适用税率 |
| 信源 | 中国政府网公告 2019 年第 36 号原文 |
| 核验 | 2026-11-05 核验文号、4% 与三条件 |

| 公布/施行 | 39 号自 2012-07-01 起；2022 年第 9 号自 2022-06 起；2021 年第 19 号自 2021-06-01 起 |
| 时效性 | 现行有效 |
| 适用范围 | 出口企业、发生服务贸易等对外支付的境内机构和个人 |
| 核心条款 | ① 出口货物适用**免抵退税**（生产企业）或**免退税**（外贸企业），须在规定申报期内申报，逾期视同内销征税；② 2022 年第 9 号公告简化申报资料、推行容缺办理与无纸化，正常退税平均办理时间压缩；③ 对外支付单笔等值 **5 万美元以上**的服务贸易、收益、经常转移等项目，需向税务机关办理税务备案后付汇；同一合同可一次备案、多次支付；④ 备案不免除扣缴义务，特许权使用费、利息、股息等仍须源泉扣缴 |
| 合规要点 | ① 出口退税核心是“真实出口 + 单证匹配”，四流不一致易被认定为骗税；② 对外支付定性决定税负：技术服务费 vs 特许权使用费税率与协定待遇不同；③ 备案表信息与实际支付不一致会被银行退回 |
| 信源 | 国家税务总局公告 2022 年第 9 号、2021 年第 19 号；财税〔2012〕39 号 |
| 核验 | 2026-11-05 核验文号、5 万美元门槛与备案机制；申报期限以主管税务机关口径为准 |
