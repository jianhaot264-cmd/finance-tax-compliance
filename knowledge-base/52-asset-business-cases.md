## 52.5 资产减值与处置报废

| 字段 | 内容 |
|---|---|
| 适用范围 | 长期资产减值测试及固定资产、无形资产等出售、报废、毁损处置。 |
| 确认与计量要求 | 按 CAS8，期末对存在减值迹象的资产估计可收回金额（公允价值减处置费用后净额与预计未来现金流量现值孰高），账面价值高于部分确认减值损失，长期资产减值损失一经确认不得转回；处置时终止确认并将净额计入资产处置损益或营业外收支，持有待售按 CAS42 处理（以财政部会计司现行目录为准）。小企业会计准则不计提减值准备。 |
| 会计分录与处理流程 | 借：资产减值损失；贷：固定资产减值准备/无形资产减值准备/长期股权投资减值准备（CAS2 核算）；处置：借：固定资产清理、累计折旧、固定资产减值准备；贷：固定资产；借：银行存款；贷：固定资产清理、应交税费——应交增值税（销项税额，按适用税率计算）；净额结转资产处置损益/营业外支出。①期末识别迹象并测算可收回金额；②凭审批单/评估鉴定/处置单据入账；③结转净损益、按 CAS30 列报。 |
| 税务处理规定 | 资产减值准备不得税前扣除（按现行规定可扣的除外）；处置/报废损失按现行规定留存证据、清单或专项申报后扣除；报废对应进项按现行规定判断是否转出。 |
| 税会差异提示 | 减值准备属时间性差异、当期调增、实际处置时调减；处置损失按现行规定调增/调减；设资产损失备查台账，涉及递延所得税按 CAS18 判断。 |
| 参照依据与关键条款 | 《企业会计准则第8号——资产减值》《企业会计准则第42号——持有待售的非流动资产、处置组和终止经营》（文号以财政部会计司现行目录为准）：减值测试与处置终止确认；《企业会计准则——基本准则》（财政部令第33号）：资产与损失确认；《企业所得税法》及实施条例（国务院令第512号）：资产损失法定框架 |
| 依据层级 | 法律＞行政法规＞部门规章＞规范性文件＞具体准则（部门规范性文件）；上位法优先，本项以具体准则为主、行政法规为辅 |
