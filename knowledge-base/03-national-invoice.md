## 3.1 《中华人民共和国发票管理办法》

| 字段 | 内容 |
|---|---|
| 文号 | 现行版本依据 2023 年修改（国务院令第 764 号，（依据见 19-19.1）；公布日期已核验） |
| 发文机关 | 国务院 |
| 效力层级 | 行政法规 |
| 公布/施行 | 原办法 1993 年发布，2010 年修订；**2023-07-20 国务院公布修改决定并施行** |
| 时效性 | 现行有效 |
| 适用范围 | 印制、领用、开具、取得、保管、缴销发票的单位和个人 |
| 核心条款（2023 修订要点） | ① **电子发票法律地位法定化**：电子发票与纸质发票效力相同，任何单位和个人不得拒收；② 发票编码规则、数据标准由国家税务总局管理；③ 增加发票数据安全义务与违法行为类型（不得超量存储、违规使用、非法出售或向他人提供发票数据）；④ 虚开认定细化：为他人/为自己/让他人为自己/介绍他人开具与实际经营业务情况不符的发票；⑤ 检查权限延伸至发票数据；⑥ 处罚幅度调整与处罚主体明确（县以上税务机关；2000 元以下可由税务所决定） |
| 合规要点 | ① 拒收电子发票违法；② "四流一致"（合同/货物/资金/发票）是从源头防虚开的核心；③ 不得买卖、出借发票数据 |
| 信源 | 上海税务局《修改决定》解读 shanghai.chinatax.gov.cn（202402）；https://www.gov.cn/gongbao/2024/issue_11286/202404/content_6945583.html ；https://www.gov.cn/yaowen/liebiao/202402/content_6934757.htm （2026-11-06 闭环双源） |
| 核验 | 2026-11-06 闭环校验，权威结论见 19-19.1（双官方信源） |

## 3.2 《中华人民共和国发票管理办法实施细则》

| 字段 | 内容 |
|---|---|
| 文号 | 国家税务总局令第 25 号公布（2011-02-14）；第四次修正：**国家税务总局令第 56 号（2024-01-15 公布，2024-03-01 施行）**，此前经 2014、2018、2019 三次修正 |
| 发文机关 | 国家税务总局 |
| 效力层级 | 部门规章 |
| 时效性 | 现行有效（2024 年修正版） |
| 适用范围 | 发票管理办法配套 |
| 核心条款（2024 修正要点） | ① 电子发票定义：以数据电文形式开具收取的收付款凭证；效力等同纸质，不得拒收；② 税务机关建设电子发票服务平台，提供开具、交付、查验服务；③ 发票数据安全管理制度：单位个人不得超规定数量存储、不得违规使用/非法出售或提供发票数据；第三方服务（代开、代管）须接受监管、限额存储、签协议授权；④ **虚开细化**："与实际经营业务情况不符"三种情形——无交易开票/取得；有交易但购买方、销售方、品名、金额等与实际不符；⑤ 领用方式增加"额度确定"；按税收风险程度、纳税信用级别、经营情况确定领用种类数量额度；⑥ 红字发票规则：纸质收回联次注明"红冲"（无法收回需对方有效证明）；电子发票发生退货/折让等按规定开红字；⑦ 代开发票须实名办税身份验证；⑧ 税务机关发票检查可对发票数据提取、调出、查阅、复制；⑨ 以其他凭证代替发票使用的情形界定（应开未开以其他凭证代替；用于抵扣/退税/税前扣除/报销的自制凭证；不合规发票用于抵扣等） |
| 合规要点 | ① 按信用级别管理发票额度——保持良好纳税信用直接影响开票便利；② 红冲/作废严格按细则程序（收回联次或取得证明）；③ "以票抵扣"必须业务真实，取得不合规发票用于扣除属违法 |
| 信源 | 国家税务总局令第 56 号全文（fgk.chinatax.gov.cn/zcfgk/c100011/c5221006） |
| 核验 | 2026-11-04 联网核验（全文） |
