## 9.1 《中华人民共和国行政复议法》（2023 修订）★

| 字段 | 内容 |
|---|---|
| 发文机关 | 全国人大常委会（十四届全国人大常委会第五次会议） |
| 效力层级 | 法律 |
| 公布/施行 | 2023-09-01 修订通过，**2024-01-01 施行**（1999 年制定后首次"大修"，7 章 90 条） |
| 时效性 | 现行有效 |
| 适用范围 | 行政复议一般制度（税务领域与 9.2 衔接） |
| 核心条款 | ① **管辖体制**：县级以上地方政府统一行使复议职责；**税务、国家安全等实行垂直领导的行政机关保留复议职责**（税务复议仍向上一级税务机关申请）；② 复议范围扩大：行政赔偿、工伤认定、行政协议、政府信息公开等可申请复议；③ 复议前置情形：当场作出的行政处罚决定、认为行政机关不履行法定职责、申请政府信息公开不予公开等（前置设定权限收窄为法律、行政法规）；④ **调解入法**：复议案件可以调解，调解书经各方签字盖章即具法律效力；⑤ 简易程序（事实清楚、争议不大）；重大疑难复杂案件应当组织听证；行政复议委员会提供咨询意见；⑥ 便民：可委托 1-2 名代理人、符合条件可申请法律援助、申请材料 5 日内一次性告知补正 |
| 合规要点 | ① 对税务处罚决定不服：可复议（向上一级税务机关）或直接诉讼；对**当场作出的行政处罚决定**不服的，依法应先申请行政复议；② 复议决定一般 60 日内作出（可延长 30 日）；③ 复议期间具体行政行为一般不停止执行（法定情形除外） |
| 信源 | 中国人大网修法报道、人民日报普法解读 |
| 核验 | 2026-11-04 联网核验 |

## 9.2 《税务行政复议规则》

| 字段 | 内容 |
|---|---|
| 文号 | 国家税务总局令公布（第 39 号发布，其后经修改——（依据见 20-20.9）|
| 发文机关 | 国家税务总局 |
| 效力层级 | 部门规章 |
| 时效性 | 现行有效；**已列入 2025 年税务部门规章制定计划二类项目（拟修改，截至核验日未见修改后公布）** |
| 适用范围 | 税务行政复议（与新行政复议法衔接适用） |
| 核心条款 | ① 申请期限：知道具体行政行为之日起 **60 日内**；② **纳税争议复议前置 + 清税前置（现行规定）**：对征税行为不服，必须先依照税务机关确定的税额、期限缴纳或解缴税款和滞纳金，或提供相应担保，才可在缴清/担保确认后 60 日内申请复议——⚠️ 《征管法修订草案》拟取消清税前置（2026-11-02 一审，尚未生效，通过后本条立即更新）；③ 对征税行为以外的具体行政行为（处罚、强制、许可等）不服：可复议也可直接诉讼；④ 对逾期不缴罚款加处罚款的决定不服：先缴纳罚款和加处罚款再复议；⑤ 重大税务案件审理程序作出的决定，审理委员会所在税务机关为被申请人；⑥ 证据类别、委托代理人（1-2 名）等程序规则 |
| 合规要点 | ① 纳税争议（征什么、征多少）想复议——先算清资金账：缴清税款滞纳金或提供保证/抵押/质押担保是门槛；② 复议不收费；③ 复议维持的，复议机关与原机关为共同被告（行政诉讼衔接） |
| 信源 | 税务总局法规库《修改〈税务行政复议规则〉的决定》条文、2025 年规章制定计划；https://www.chinatax.gov.cn/chinatax/n810214/n810641/c102061/c102062/c5171575/content.html ；https://www.chinatax.gov.cn/chinatax/n810341/n810765/n1990035/201601/c2185201/content.html （2026-11-06 闭环双源） |
| 核验 | 2026-11-06 闭环校验，权威结论见 20-20.9（双官方信源） |

## 9.3 《税务行政处罚裁量权行使规则》

| 字段 | 内容 |
|---|---|
| 文号 | 国家税务总局公告 2016 年第 78 号发布，2018 年第 31 号公告修改 |
| 发文机关 | 国家税务总局 |
| 效力层级 | 规范性文件 |
| 时效性 | 现行有效（与《全国税务行政处罚裁量基准（2026年版）》配套适用） |
| 核心条款 | ① 裁量权行使的一般规则：过罚相当、程序正当；② **情节复杂、争议较大、处罚较重、影响较广或拟减轻处罚的，须经集体审议后作出决定**（2026 裁量基准解读援引的第二十一条）；③ 从轻、减轻、不予处罚的适用条件 |
| 合规要点 | 收到处罚决定书后核对：是否载明裁量基准适用情况、应集体审议的是否履行程序——程序瑕疵是复议/诉讼中的有效抗辩点 |
| 信源 | 2026 年版裁量基准官方解读援引 |
| 核验 | 2026-11-04 间接核验 |

## 9.4 《中华人民共和国行政处罚法》（2021 修订）

| 字段 | 内容 |
|---|---|
| 发文机关 | 全国人大常委会 |
| 效力层级 | 法律 |
| 公布/施行 | 2021-01-22 修订通过，2021-07-15 施行（依据见 20-20.10） |
| 时效性 | 现行有效 |
| 核心条款（税务相关） | ① 处罚告知义务：作出处罚决定前须告知违法事实、处罚理由、依据及依法享有的权利；② **听证权**：较大数额罚款、没收较大数额违法所得、降低资质等级、吊销许可证件、责令停产停业等，当事人有权要求听证（应在行政机关告知后五日内提出——（依据见 20-20.10）；听证费用由行政机关承担；③ 首违可不罚：违法行为轻微并及时改正，没有造成危害后果的，不予处罚；初次违法且危害后果轻微并及时改正的，可以不予处罚；④ 处罚决定书应当载明行政处罚的种类、依据等 |
| 合规要点 | 收到《税务行政处罚事项告知书》后，认为处罚过重或事实有误的，在告知期限内书面提出陈述申辩/听证申请——放弃听证不影响后续复议诉讼 |
| 信源 | 《税务稽查案件办理程序规定》解读等官方文件援引（新行政处罚法）；http://www.npc.gov.cn/npc/c2/c30834/202101/t20210122_309857.html ；https://www.mps.gov.cn/n6557558/c7692710/content.html （2026-11-06 闭环双源） |
| 核验 | 2026-11-06 闭环校验，权威结论见 20-20.10（双官方信源） |
