# 08 单行税种法律体系（18 税种全景）

> 核验日期：2026-11-04 ｜ 信源：国家税务总局《中国税务年度报告（2024/2025）》（权威口径）、盘锦市税务局行政执法依据清单、开封市政府税制资料
> 框架：我国现行 **18 个税种**——货物和劳务税 4 个（增值税、消费税、车辆购置税、关税）；所得税 2 个（企业所得税、个人所得税）；财产和行为税 12 个（土地增值税、房产税、城镇土地使用税、耕地占用税、契税、资源税、车船税、印花税、城市维护建设税、烟叶税、船舶吨税、环境保护税）。税收立法进程：已出台税收法律 15 部（含征管法、关税法、增值税法），**消费税法、土地增值税法已征求意见**，房产税法、城镇土地使用税法尚未出台（研究阶段）。
> 增值税/企税/个税/关税/消费税（暂行条例）见 02 文件；本文件收录其余单行税种。

## 8.1 《中华人民共和国印花税法》

| 字段 | 内容 |
|---|---|
| 发文机关 | 全国人大常委会 |
| 效力层级 | 法律 |
| 公布/施行 | 2021-06-10 通过，**2022-07-01 施行**（同时废止《印花税暂行条例》） |
| 时效性 | 现行有效 |
| 适用范围 | 在境内书立应税凭证、进行证券交易的单位和个人；在境外书立境内使用的应税凭证的单位和个人 |
| 核心条款 | ① 应税凭证：合同（买卖、借款、融资租赁、租赁、承揽、建设工程、运输、技术、保管、仓储、财产保险）、产权转移书据、营业账簿；② 税率采用低档比例税率与定额税率（具体按法律所附《印花税税目税率表》，万分之零点五至千分之一不等——引用时以税目税率表为准）；③ **证券交易印花税单列**；④ 小规模纳税人/小型微利/个体工商户"六税两费"减半含印花税（不含证券交易印花税，见 06 文件） |
| 合规要点 | ① 合同签订方（不含保人、证人、鉴定人）是纳税人；② 应税合同、产权转移书据未列明金额的按实际结算金额确定；③ 印花税按季/按次/按年申报 |
| 信源 | 税务总局年度报告（chinatax.gov.cn PDF）、盘锦局依据清单 |
| 核验 | 2026-11-04 联网核验（通过/施行日期） |

## 8.2 《中华人民共和国契税法》

| 字段 | 内容 |
|---|---|
| 发文机关 | 全国人大常委会 |
| 效力层级 | 法律 |
| 公布/施行 | 2020-08-11 通过，**2021-09-01 施行**（同时废止《契税暂行条例》） |
| 时效性 | 现行有效 |
| 适用范围 | 境内转移土地、房屋权属，承受的单位和个人 |
| 核心条款 | ① 税率 3%—5%（具体由省级政府在幅度内提出、报同级人大常委会决定）；② 应税行为：土地使用权出让/转让（含出售、赠与、交换）、房屋买卖/赠与/交换；③ 法定免税：国家机关/事业单位/社会团体/军事单位承受土地房屋用于办公、教学、医疗、科研和军事设施等；婚姻关系存续期间夫妻之间变更土地房屋权属免征（依据见 20-20.8） |
| 合规要点 | ① 房产/土地受让方是契税纳税人，签合同后按规定期限申报；② 购房契税优惠（家庭首套等）另按财政部/税务总局现行公告执行 |
| 信源 | 税务总局年度报告、盘锦局依据清单；https://www.chinatax.gov.cn/chinatax/n810219/n810744/c103147/c5249424/5249424/files/8e2bb59af3de4dec860e856ad66be304.pdf ；https://zhejiang.chinatax.gov.cn/art/2020/9/27/art_13314_477245.html （2026-11-06 闭环双源） |

## 8.11 房产税、城镇土地使用税（暂行条例，未立法）

| 字段 | 内容 |
|---|---|
| 效力层级 | 行政法规（1986 年《房产税暂行条例》、1988 年《城镇土地使用税暂行条例》——（依据见 18-18.4）|
| 时效性 | 现行有效；**房产税法、城镇土地使用税法尚未出台**（研究阶段）；房地产税改革试点授权决定（2021-10-23 通过）仍在框架内 |
| 核心条款 | 房产税：从价（房产原值×(1-扣除比例)×1.2%）或从租（租金×12%）计征（依据见 18-18.4）；城镇土地使用税：按面积定额，各地税额标准不同 |
| 合规要点 | ① 自有房产出租按租金 12% 缴房产税——个人出租住房有优惠（按现行文件）；② "六税两费"减半含房产税、城镇土地使用税（小规模/小微/个体户，见 06）；③ 物流企业大宗商品仓储设施用地减按 50% 征城镇土地使用税（2023-01-01 至 2027-12-31，财政部 税务总局公告 2023 年第 5 号，见 18-18.4） |
| 核验 | 2026-11-06 闭环校验，权威结论见 18-18.4（双官方信源） |
