> 覆盖：土增税税率与扣除、普通住宅优惠、清算与预征；房产税计税依据与广东 30% 减除；土地使用税广东税额分级。

> ⚠️ 三税均**地方差异大**：土增税预征率、房产税申报期限、土地使用税等级税额由市县确定，测算前须按属地核对。

## 33.1 土地增值税：纳税人与四级超率累进税率

## 33.2 普通标准住宅 20% 免征与房地产开发加计 20% 扣除

| 字段 | 内容 |
|---|---|
| 文号 | 《土地增值税暂行条例》**第八条第（一）项**；《实施细则》**第十一条**；《财政部 国家税务总局关于土地增值税若干问题的通知》（财税〔2006〕21 号） |
| 发文机关 | 国务院；财政部、国家税务总局 |
| 效力层级 | 行政法规 + 部门规章 + 规范性文件 |
| 公布/施行 | 1994-01-01；财税〔2006〕21 号 2006-03-02 起 |
| 时效性 | 现行有效 |
| 适用范围 | 建造普通标准住宅出售的房地产开发企业；从事房地产开发的纳税人 |
| 核心条款 | ① 建造**普通标准住宅**出售，增值额**未超过扣除项目金额 20% 的免征**土地增值税；超过 20% 的，**就全部增值额**按规定计税（不是只对超出部分）；② 从事房地产开发的纳税人，可按「取得土地使用权所支付的金额＋房地产开发成本」之和**加计 20% 扣除**；③ 普通标准住宅标准由各省按「住宅小区建筑容积率 1.0 以上、单套建筑面积 120 平方米以下、实际成交价格低于同级别土地上住房平均交易价格 1.2 倍以下」原则确定（粤府另有规定，须属地核对） |
| 合规要点 | ① 20% 是「免征临界点」，一旦超过就**全额计税**，存在明显的税负跳档，定价时须测算；② 加计 20% 仅限**房地产开发企业**，非房企不得加计；③ 普通住宅与高档住宅分别核算，未分别核算不得享受免税；④ 广东省普通住宅标准曾多次调整，签约前须查当地现行标准 |
| 信源 | ① https://fgk.chinatax.gov.cn/zcfgk/c100010/c5194433/content.html（总局法规库：条例第八条）<br>② https://xiamen.chinatax.gov.cn/xmswcms/content/9525.html（厦门市税务局：20% 免征依据与「加计 20% 扣除」说明）<br>③ https://tianjin.chinatax.gov.cn/11200000000/0400/040005/04000503/20190627195416450.shtml（天津市税务局：申报指引，附条例与实施细则全文） |
| 核验 | 2026-11-07 联网核验：第八条第（一）项与加计 20% 规则三源一致 |

## 33.3 土地增值税清算（应清算与可清算）

| 字段 | 内容 |
|---|---|
| 文号 | 《国家税务总局关于印发〈土地增值税清算管理规程〉的通知》（**国税发〔2009〕91 号**）；《国家税务总局关于房地产开发企业土地增值税清算管理有关问题的通知》（国税发〔2006〕187 号） |
| 发文机关 | 国家税务总局 |
| 效力层级 | 部门规范性文件 |
| 公布/施行 | 91 号规程 2009 年印发（多数条款自 2009-07-01 起执行）；187 号 2006 年 |
| 时效性 | 现行有效 |
| 适用范围 | 房地产开发项目（含分期开发、联建、代建等） |
| 核心条款 | ① **应清算**情形：项目全部竣工、完成销售；整体转让未竣工决算项目；直接转让土地使用权；② **可要求清算**情形：已竣工验收且销售比例达 85% 以上，或剩余可售面积已出租/自用；销售比例未达 85% 但剩余面积较大且税务机关有理由认为需要清算；③ 清算以**项目为单位**，分期开发的按分期项目清算；④ 清算收入按实际销售价格确认，扣除项目须提供合法有效凭证；⑤ 清算后再转让的，按「尾盘」规则申报 |
| 合规要点 | ① 达到应清算条件**必须**清算，不因企业未申请而免除；② 85% 销售比例是「可要求清算」的常见触发点，不是唯一标准；③ 扣除凭证不合规（如无发票的建筑安装费）会被剔除，是补税高发点；④ 清算后补税金额大，需提前做税负测算与资金安排 |
| 信源 | ① https://tianjin.chinatax.gov.cn/11200000000/0400/040005/04000503/20190627195416450.shtml（天津市税务局：申报指引，明确列示国税发〔2009〕91 号与实施细则全文）<br>② https://fgk.chinatax.gov.cn/zcfgk/c100010/c5194433/content.html（总局法规库：条例第十条申报与第十一条征收管理） |
| 核验 | 2026-11-07 联网核验：91 号规程文号与文件性质确认；**应清算/可清算的具体比例与情形以规程原文为准，本条目为要点归纳** |

## 33.5 房产税：计税依据与税率（广东减除 30%）

| 字段 | 内容 |
|---|---|
| 文号 | 《中华人民共和国房产税暂行条例》（**国发〔1986〕90 号**）；《广东省房产税施行细则》（**粤府〔1986〕168 号**，经 **2021-09-29 广东省人民政府令第 289 号**修改） |
| 发文机关 | 国务院；广东省人民政府 |
| 效力层级 | 行政法规 + 省级政府规章 |
| 公布/施行 | 条例 1986-10-01；广东细则 1986-12-31 公布，2021 年修改版现行 |
| 时效性 | 现行有效（**尚未立法**） |
| 适用范围 | 城市、县城、建制镇、工矿区范围内的房产；产权所有人/经营管理单位/承典人/代管人或使用人 |
| 核心条款 | ① **从价计征**：房产税依照房产原值**一次减除 30%** 后的余值计算（广东），税率 **1.2%**；应纳税额＝房产原值×(1－30%)×1.2%；② **从租计征**：以租金收入为计税依据，税率 **12%**；③ 个人出租住房按 **4%** 征收（财税〔2008〕24 号）；④ 房产原值按财务会计制度记载；未按制度记载或原值不实的，由税务机关参考同类房产核定；⑤ 房产出租的，以租金收入为计税依据（不再按余值） |
| 合规要点 | ① 广东减除比例是 **30%**（条例允许 10%–30%，各省自定），不能用 10% 或 20% 测算；② 房产原值应包含**地价**及附属设备（电梯、中央空调、消防等），只按购房发票金额申报是常见少缴；③ 免租期期间由**产权所有人**按房产余值缴纳；④ 无租使用他人房产的，由**使用人**代缴 |
| 信源 | ① https://www.gd.gov.cn/attachment/0/486/486093/3718399.pdf（广东省人民政府：广东省房产税施行细则全文，第四、五条）<br>② https://guangdong.chinatax.gov.cn/siteapps/webpage/gdtax/tjjcx/tjjcx_result.jsp?cid=8e2e824f04e9451bac3b4c836a9d807f（广东省税务局 12366 答复：广东减除 30%、1.2% 与计算公式） |
| 核验 | 2026-11-07 联网核验：省政府细则 PDF 原文 + 省税务局答复，30% 与 1.2%/12% 一致 |

## 33.7 城镇土地使用税：广东税额分级

| 字段 | 内容 |
|---|---|
| 文号 | 《中华人民共和国城镇土地使用税暂行条例》（**国务院令第 483 号**，2006 年修订）；《广东省城镇土地使用税实施细则》（**粤府令第 130 号**，2009-01-04 公布，经 **2021-09-29 粤府令第 289 号**修改） |
| 发文机关 | 国务院；广东省人民政府 |

| 公布/施行 | 条例 2007-01-01；广东细则 2009 年公布，2021 年修改 |
| 时效性 | 现行有效（**尚未立法**） |

| 核心条款 | ① **持有环节**：房产税（按余值 1.2% 或租金 12%）＋城镇土地使用税（按面积×等级税额）；② **转让环节**：增值税（9%/5%）＋土地增值税（四级累进）＋城建税与附加＋印花税＋企业所得税；③ 三者**互不替代**：有房产必有房产税（除免税），占用土地必有土地使用税，转让国有土地使用权/房屋才涉及土增税；④ 物流企业大宗商品仓储设施用地，2023-01-01 至 2027-12-31 减按 **50%** 计征城镇土地使用税（2023 年第 5 号） |
| 合规要点 | ① 常见错误：只缴房产税忘了土地使用税（两者纳税义务人、计税依据不同）；② 房屋出租后从租计征 12%，不再按余值 1.2%，不能两头都算或都不算；③ 土增税只对「转让国有土地使用权及地上建筑物」征，**出租不征**；④ 减免政策多带期限，2027-12-31 到期组须建立提醒 |
