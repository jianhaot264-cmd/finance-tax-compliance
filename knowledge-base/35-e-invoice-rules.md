## 35.1 数电票的法律地位与全国推广

| 字段 | 内容 |
|---|---|
| 文号 | 国家税务总局公告 2024 年第 11 号 第一条、第二条、第十二条；《中华人民共和国发票管理办法》（国务院令第 764 号） |
| 发文机关 | 国家税务总局 |
| 效力层级 | 部门规范性文件（依据行政法规） |
| 公布/施行 | 2024-11-12 公布，**2024-12-01 全国正式推广**（2021-12-01 起广东、上海、内蒙古试点） |
| 时效性 | 现行有效 |
| 适用范围 | 全国范围内开具、取得数电票的单位、个体工商户与自然人 |
| 核心条款 | ① 数电票是《发票管理办法》中「电子发票」的一种，**票面要素全面数字化、号码全国统一赋予、开票额度智能授予、信息通过税务数字账户自动流转**；② **与纸质发票具有同等法律效力**；③ 单一联次、以数字化形态存在；④ 类别包括电子发票（增值税专用发票）、（普通发票）、（航空运输电子客票行程单）、（铁路电子客票）、（机动车销售统一发票）、（二手车销售统一发票）等，并可按特定业务标签生成建筑服务、成品油、报废产品收购等特定业务发票 |
| 合规要点 | ① 「数电票」不是新税种、也不改变税率，只改变载体与流程；② 数电票无「作废」概念，只能红冲；③ 税局对「不使用网络办税、无网络条件或重大涉税风险」的纳税人可暂不提供服务（由省级税务机关确定）；④ 收取方不得以「不是纸质票」为由拒收 |
| 信源 | ① https://fgk.chinatax.gov.cn/zcfgk/c100012/c5236067/content.html（国家税务总局政策法规库：2024 年第 11 号公告全文）<br>② https://www.chinatax.gov.cn/chinatax/n810219/n810780/c5236089/content.html（税务总局发布稿：全国推广与法律效力表述） |
| 核验 | 2026-11-07 联网核验：公告全文与发布稿双源一致，施行日 2024-12-01 |

| 公布/施行 | 2024-12-01 |
| 时效性 | 现行有效 |
| 适用范围 | 全部数电票 |
| 核心条款 | ① 票面基本内容：发票名称、发票号码、开票日期、购买方信息、销售方信息、项目名称、规格型号、单位、数量、单价、金额、税率/征收率、税额、合计、价税合计、备注、开票人；② **号码为 20 位**：第 1–2 位＝公历年度后两位，第 3–4 位＝开票方所在省级税务局区域代码，第 5 位＝开具渠道等信息，第 6–20 位＝顺序编码 |

## 35.3 发票总额度（自然月、不含税、动态调整）

| 字段 | 内容 |
|---|---|
| 文号 | 国家税务总局公告 2024 年第 11 号 第六条 |
| 发文机关 | 国家税务总局 |
| 效力层级 | 部门规范性文件 |
| 公布/施行 | 2024-12-01 |
| 时效性 | 现行有效 |
| 适用范围 | 使用电子发票服务平台开票的纳税人 |
| 核心条款 | ① 税务机关根据**税收风险程度、纳税信用级别、实际经营情况**等因素授予发票总额度，并**动态调整**；② 发票总额度＝**一个自然月内**发票开具总金额（**不含增值税**）的上限额度；③ 因实际经营情况变化需调整的，经主管税务机关确认后调整 |
| 合规要点 | ① 额度是「月」概念，跨月自动重置，不是年度额度；② 额度按不含税金额计算，价税合计不等于额度占用；③ 信用等级下降、风险指标异常会导致额度被调减，进而影响开票与收款；④ 额度不足应提前申请调整，不要用拆分开票规避 |
| 信源 | ① https://fgk.chinatax.gov.cn/zcfgk/c100012/c5236067/content.html（第六条原文）<br>② https://hainan.chinatax.gov.cn/ssxc_1_6/25155295.html（海南省税务局转载人民日报报道：额度由平台智能授予并动态调整） |
| 核验 | 2026-11-07 联网核验：额度定义与调整机制双源一致 |

## 35.4 红字数电票：未确认 / 已确认两条路径

| 字段 | 内容 |
|---|---|
| 文号 | 国家税务总局公告 2024 年第 11 号 第八条；《红字发票信息确认单》附件 2 |
| 发文机关 | 国家税务总局 |
| 效力层级 | 部门规范性文件 |
| 公布/施行 | 2024-12-01 |
| 时效性 | 现行有效 |
| 适用范围 | 发生销售退回（全部/部分）、开票有误、应税服务中止（全部/部分）、销售折让等情形 |
| 核心条款 | ① **蓝字票未做用途确认及入账确认**：由开票方发起红冲并直接开具红字票；农产品收购、报废产品收购、光伏收购发票无论是否确认，均由开票方直接红冲；② **已做用途确认或入账确认**（用于出口退税勾选确认的按现行规定）：开票方或受票方均可发起，经对方确认《红字发票信息确认单》后由开票方开具；**《确认单》发起后 72 小时内未确认自动作废**；③ 已用于出口退税勾选确认的，需先操作进货凭证信息回退并确认通过，再由开票方直接红冲；④ 受票方已将数电票用于申报抵扣的，应**暂依《确认单》税额从当期进项税额中转出**，待取得红字票后与《确认单》一并作为记账凭证 |
| 合规要点 | ① 数电票**不能作废**，只能红冲；② 红冲金额须在对应蓝字票金额范围内；③ **当月红冲增加剩余额度、跨月红冲不增加**（见 35.5 官方示例）；④ 已抵扣未转出即红冲，会造成进项多抵，属高频风险 |
| 信源 | ① https://fgk.chinatax.gov.cn/zcfgk/c100012/c5236067/content.html（第八条原文）<br>② https://www.chinatax.gov.cn/chinatax/n810356/n3010387/c5237158/content.html（税务总局举例说明：红冲流程与额度变化，含 750 万额度示例） |
| 核验 | 2026-11-07 联网核验：两条路径、72 小时、进项转出要求三源一致 |

## 35.5 红冲对发票额度的实际影响（官方示例）

| 字段 | 内容 |
|---|---|
| 文号 | 国家税务总局公告 2024 年第 11 号 第六条、第八条；税务总局《举例说明》 |
| 发文机关 | 国家税务总局 |
| 效力层级 | 部门规范性文件 + 官方解读 |
| 公布/施行 | 2024-12-01 |
| 时效性 | 现行有效 |
| 适用范围 | 发生红冲的纳税人 |
| 核心条款 | ① **当月**开具蓝字数电票、**当月**红冲：平台同步增加剩余额度；② **跨月**红冲：**不增加**剩余额度；③ 蓝字纸质发票当月红冲或作废：增加剩余额度，跨月红冲不增加；④ 官方示例：10 月总额度 750 万，1–5 日开票 100 万，6 日红冲 8 月蓝票 10 万（跨月，不恢复额度），7 日红冲 10 月蓝票 50 万（当月，恢复额度），则 8 日剩余额度＝750－100＋50＝**700 万** |
| 合规要点 | ① 额度测算须区分「当月红冲」与「跨月红冲」，否则会误判可用额度；② 月末集中开票 + 次月红冲会让额度「只减不增」，影响下月开票；③ 财务系统对接时应把额度占用按「不含税金额」建模 |
| 信源 | ① https://www.chinatax.gov.cn/chinatax/n810356/n3010387/c5237158/content.html（税务总局官方示例，逐字口径）<br>② https://fgk.chinatax.gov.cn/zcfgk/c100012/c5236067/content.html（第六条额度定义） |
| 核验 | 2026-11-07 联网核验：示例数字与规则均取自税务总局官网 |

|---|---|
| 文号 | 国家税务总局公告 2024 年第 11 号 第十条、第十一条 |
| 发文机关 | 国家税务总局 |
| 效力层级 | 部门规范性文件 |
| 公布/施行 | 2024-12-01 |
| 时效性 | 现行有效 |
| 适用范围 | 取得数电票并拟用于抵扣、退税、勾选成品油库存的纳税人 |
| 核心条款 | ① 用于**申报抵扣增值税进项、成品油消费税、申请出口退税/代办退税、勾选成品油库存**的，应通过**税务数字账户确认用途**；② 确认用途有误可向主管税务机关申请更正；③ 单位和个人可登录税务数字账户、个人所得税 APP 免费查询、下载、打印、导出；可在税务数字账户对发票**入账与否打标识**；可通过电子发票服务平台或全国增值税发票查验平台免费查验 |

## 35.7 交付方式与常见误区

| 字段 | 内容 |
|---|---|
| 文号 | 国家税务总局公告 2024 年第 11 号 第九条；《发票管理办法》（国务院令第 764 号） |
| 发文机关 | 国家税务总局 |
| 效力层级 | 部门规范性文件 |
| 公布/施行 | 2024-12-01 |
| 时效性 | 现行有效 |
| 适用范围 | 开票方与受票方 |
| 核心条款 | ① 已开具的数电票通过电子发票服务平台**自动交付**；② 开票方也可通过**电子邮件、二维码、下载打印**等方式交付；③ 选择下载打印方式交付的，票面自动标记并显示「**下载次数**」「**打印次数**」；④ 电子发票与纸质发票具有同等法律效力，任何单位和个人不得拒收 |
| 合规要点 | ① 「下载次数/打印次数」会显示在票面，重复打印易被质疑，应优先用自动交付或邮件；② 报销归档应保存**原始电子文件**（含 XML/OFD/PDF），仅存打印件不利举证；③ 常见误区：以为数电票需「抄报税/认证」——数电票无需抄报税，勾选确认即可；④ 常见误区：以为红冲要收回原票——数电票红冲不需收回，靠《确认单》与红字票闭环 |
| 信源 | ① https://fgk.chinatax.gov.cn/zcfgk/c100012/c5236067/content.html（第九条原文）<br>② https://hainan.chinatax.gov.cn/ssxc_1_6/25155295.html（海南省税务局：交付方式与同等法律效力） |
| 核验 | 2026-11-07 联网核验：交付方式、次数标记与法律效力表述一致 |
