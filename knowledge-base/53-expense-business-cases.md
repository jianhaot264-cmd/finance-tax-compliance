| 会计分录与处理流程 | 计提：借：生产成本/制造费用/管理费用/销售费用/研发支出；贷：应付职工薪酬——工资/社会保险费/住房公积金/工会经费/职工教育经费/职工福利费；发放：借：应付职工薪酬——工资；贷：银行存款、应交税费——应交个人所得税（代扣）、其他应收款（代垫）。①按考勤/工资表/申报表计提并按部门归集；②发放代扣挂往来、登记薪酬台账；③期末核对余额、按 CAS9/CAS30 披露。 |

## 53.2 业务招待费与广告费和业务宣传费

| 字段 | 内容 |
|---|---|

| 会计分录与处理流程 | 借：管理费用——业务招待费/销售费用——广告费和业务宣传费、应交税费——应交增值税（进项税额，按适用税率计算）；贷：银行存款/应付账款/库存商品。①凭审批单/发票/合同/领用单入账；②按费用项目与部门设明细台账；③期末结转本年利润、不得跨期预提。 |
| 税务处理规定 | 业务招待费按现行规定限额扣除；广告费和业务宣传费：一般企业不超过当年销售（营业）收入 15% 的部分准予扣除、超过部分准予在以后纳税年度结转扣除（《企业所得税法实施条例》第四十四条）；化妆品制造或销售、医药制造、饮料制造（不含酒类制造）三类企业按不超过当年销售（营业）收入 30% 扣除、超过部分结转（财政部 税务总局公告 2025 年第 16 号，执行 2026-01-01 至 2027-12-31，2020 年第 43 号自 2026-01-01 废止）；烟草企业的烟草广告费和业务宣传费一律不得扣除；须取得合规发票等扣除凭证并与生产经营直接相关。 |
| 税会差异提示 | 超限额属永久性差异（广宣费可结转部分属时间性）、当期纳税调增、结转调减；设两类费用台账备查，涉及递延所得税按 CAS18 判断。 |
| 参照依据与关键条款 | 《企业所得税法》及实施条例（国务院令第512号）第四十四条：广告费和业务宣传费不超过当年销售（营业）收入 15% 的部分准予扣除、超过部分结转以后纳税年度；财政部 税务总局公告 2025 年第 16 号：化妆品制造或销售、医药制造、饮料制造（不含酒类制造）三类企业 30% 限额与结转、关联企业分摊协议规则、烟草企业一律不得扣除，执行 2026-01-01 至 2027-12-31，2020 年第 43 号自 2026-01-01 废止；国家税务总局公告 2018 年第 28 号：扣除凭证真实性合法性关联性（具体条款以原文为准）；《会计法》：核算真实完整；《企业会计准则——基本准则》（财政部令第33号）：费用要素 |
| 依据层级 | 法律＞行政法规＞部门规章＞规范性文件＞具体准则（部门规范性文件）；上位法优先，本项以法律、行政法规为主 |
| 生效状态 | 现行有效；企税条例 2024-12-06 修订、2025-01-20 施行；广宣费现行依据为财政部 税务总局公告 2025 年第 16 号（2026-01-01 起执行），2020 年第 43 号已自 2026-01-01 废止；2027-12-31 到期须复核是否延续 |
| 适用边界 | 执行企业会计准则/小企业准则的一般·小规模纳税人；全国口径，广东等地方口径回查；广宣费 30% 档仅限化妆品制造或销售、医药制造、饮料制造（不含酒类制造）三类企业且以主营业务判定，烟草企业烟草类广宣费一律不得扣除（财政部 税务总局公告 2025 年第 16 号）；属 2027-12-31 到期组，未确认延续前不得按 30% 测算 2028 年度；红线：招待费与广宣费混列、白条入账、虚开、沿用已废止的 2020 年第 43 号口径 |

| 会计分录与处理流程 | 借：管理费用/销售费用——差旅费/办公费、应交税费——应交增值税（进项税额，按适用税率计算）；贷：银行存款/库存现金/其他应收款（冲备用金）；捐赠：借：营业外支出——捐赠支出；贷：银行存款/库存商品、应交税费——应交增值税（销项税额，按适用税率计算）。①凭报销单/行程单/发票/审批单入账；②按部门与项目设台账、核对备用金；③期末结转本年利润。 |
| 税务处理规定 | 差旅办公费凭合规凭证据实扣除，符合条件进项可抵扣，用于免税/简易计税/福利等按现行规定转出；公益性捐赠按现行规定限额扣除，非公益捐赠不得扣除。 |
| 税会差异提示 | 进项转出与非公益捐赠属永久性差异、纳税调增；捐赠超限额结转属时间性差异、当期调增、结转调减；设抵扣、转出与捐赠台账。 |
