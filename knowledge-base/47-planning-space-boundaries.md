# 合法操作空间与风险边界：可做、需留证、不可做

> 覆盖：增值税、企业所得税、个人所得税、小税种、跨境、区域优惠、程序权利、裁量空间与刑事红线。
> 本文件为 **A 层**：每条 10 字段 + 至少 2 个官方信源 + 核验日期 2026-11-08。
> ⚠️ **本文件只写法律明文允许的选择权与程序权利，不提供虚假申报、隐瞒收入、虚列成本、虚开发票的方法**。凡涉及「安排交易」的，必须同时满足：真实商业目的、经济实质、证据链完整、不违反强制性规定。

## 47.1 判定三条线：法律授权、经济实质、证据链

| 字段 | 内容 |
|---|---|
| 文号 | 《税收征收管理法》第六十三条（偷税）；《企业所得税法》第四十七条（一般反避税）；《行政处罚法》第三十三条（首违不罚） |
| 发文机关 | 全国人大常委会 |
| 效力层级 | 法律 |
| 公布/施行 | 征管法 2015 修正；企税法 2008-01-01；行政处罚法 2021-07-15 施行 |
| 时效性 | 现行有效 |
| 适用范围 | 所有税务安排与优惠适用的合规判断 |
| 核心条款 | ① **第一条线——法律授权**：有没有明文允许「可以选择」？有（如一般计税/简易计税、查账/核定、年终奖单独/并入），属合法选择；没有明文、靠虚构事实的，属高风险；② **第二条线——经济实质**：交易是否有真实商业目的、是否有与之匹配的人员/资产/风险承担？「注册在优惠地但无人员无场地」通常被认定无实质；③ **第三条线——证据链**：合同、发票、资金、物流、服务成果能否相互印证？四流不一致是高频被调整点；④ **偷税与筹划的分界**：伪造/变造/隐匿/擅自销毁账簿凭证、多列支出/少列收入、虚假申报 → 征管法第六十三条，追税+滞纳金+**0.5–5 倍罚款**，构成犯罪的追究刑责；⑤ **一般反避税**：不具有合理商业目的的安排，税务机关可调整并追溯 **10 年** |
| 合规要点 | ① 任何方案先过「三线测试」，缺一条就降级为「需事前沟通/可能被调整」；② 不要用「别人都这么做」作为依据，稽查看的是证据；③ 方案文档要写清**商业目的、定价依据、风险承担**，而不是只写「省税多少」；④ 涉及跨境/关联交易的，优先考虑**预约定价/事先裁定**；⑤ 拿不准时，书面咨询主管税务机关或 12366，保留答复记录 |
| 信源 | ① https://www.gov.cn/gongbao/content/2007/content_609907.htm（征管法第六十三条偷税认定与处罚）<br>② https://fgk.chinatax.gov.cn/（企业所得税法第四十七条一般反避税；行政处罚法第三十三条） |
| 核验 | 2026-11-08 联网核验：偷税构成要件、0.5–5 倍罚款、10 年追溯期；具体定性以税务机关文书/司法判决为准 |

## 47.2 增值税：身份、计税方法、进项划分、纳税时点

|---|---|
| 文号 | 《增值税法》（2026-01-01 施行）第九条、第十一条、第二十二条；财政部 税务总局公告 2026 年第 10 号（简易计税/差额扣除，至 2027-12-31）、第 13 号（进项抵扣）、第 2 号（身份登记） |
| 发文机关 | 全国人大常委会；财政部、税务总局 |
| 效力层级 | 法律 + 规范性文件 |
| 公布/施行 | 2026-01-01 |
| 时效性 | 现行有效 |
| 适用范围 | 增值税一般纳税人、小规模纳税人 |
| 核心条款 | ① **身份选择**：年应征增值税销售额未超过 **500 万元**的，可选择小规模纳税人；超过的应当登记为一般纳税人；② **计税方法**：一般计税（销项－进项）或简易计税（征收率 3%/5%，2026 年第 10 号公告列 15 项 3%、6 项 5%，至 2027-12-31）；③ **进项划分**：用于免税项目、简易计税项目、集体福利/个人消费的进项**不得抵扣**；无法划分的按销售额比例分摊，**年度清算**；④ **纳税义务时点**：发生应税交易当日；先开具发票的，为开具发票当日；⑤ **差额扣除**：2026 年第 10 号公告列 12 项，按扣除后的销售额计税；⑥ **留抵退税**与**即征即退/先征后返****不能同时**享受 |

## 47.3 企业所得税：收入、扣除、资产、重组、优惠叠加

|---|---|
| 文号 | 《企业所得税法》第八条、第十一条、第十八条、第二十六条、第二十八条；《企业所得税法实施条例》；财税〔2009〕59 号（重组）；财政部 税务总局公告 2023 年第 7 号（研发加计 100%）、2023 年第 12 号（小微，至 2027-12-31）、2023 年第 37 号（设备一次性扣除，至 2027-12-31） |
| 发文机关 | 全国人大常委会；国务院；财政部、税务总局 |
| 效力层级 | 法律 + 行政法规 + 规范性文件 |
| 公布/施行 | 企税法 2008-01-01；各优惠按原文件 |
| 时效性 | 现行有效（部分优惠至 2027-12-31） |
| 适用范围 | 居民企业 |

## 47.5 小税种：合同拆分、税目选择、计税依据

| 字段 | 内容 |
|---|---|
| 文号 | 《印花税法》第五条、第九条；《契税法》第四条；《房产税暂行条例》第三条；《土地增值税暂行条例》第八条 |
| 发文机关 | 全国人大常委会；国务院 |
| 效力层级 | 法律 + 行政法规 |
| 公布/施行 | 各按原文件 |
| 时效性 | 现行有效 |
| 适用范围 | 合同签订、不动产交易、房产持有/出租、土地转让 |
| 核心条款 | ① **印花税**：同一合同载有两个以上税目事项并**分别列明金额**的，分别计税；未分别列明的**从高**适用——这是明确的法定选择空间；② **印花税税目**：租赁 1‰、仓储 1‰、保管 1‰、运输 0.3‰、承揽 0.3‰，业务定性不同税负不同，但必须与**实际业务**一致；③ **房产税**：自用按**余值 1.2%**，出租按**租金 12%**（个人出租住房 4%），计税方式由**使用方式**决定，不是自选；④ **契税**：计税依据为成交价格，**装修费单独列明**可不计入（按当地口径）；⑤ **土地增值税**：普通标准住宅增值率 **不超过 20%** 的**免征**；四级超率累进 30%–60% |
| 合规要点 | ① 合同「分别列明」是合法节税，但**不能虚构税目**（如把租赁写成仓储）——业务实质不符会被调整；② 房产税从租/从价由**实际使用**决定，把自用改成「出租给关联方」低价收租，会被按**公允价值**调整；③ 土增税普通住宅 20% 免税要满足**普通标准住宅**条件（面积/价格），不是所有住宅；④ 印花税金额小，但**合并申报漏税目**是高频问题；⑤ 小税种的「筹划」空间主要在**合同条款与业务定性**，不在税率 |
| 信源 | ① https://guangdong.chinatax.gov.cn/gdsw/zssw_nsrwkt_sphg_zbsp/2022-07/08/b5cbcdef663d476bbcb821cb6ab21a8c/files/5e07417a94ab464895b4c817b3e75c5c.pdf（印花税税目税率与分别列明规则）<br>② https://fgk.chinatax.gov.cn/（契税法、房产税暂行条例、土增税暂行条例） |
| 核验 | 2026-11-08 联网核验：印花税分别列明/从高、房产税 1.2%/12%、土增普通住宅 20% 免税；地方口径以主管税务机关为准 |

| 核心条款 | ① **共同条件**：主营业务属于**鼓励类产业目录**、主营业务收入占收入总额 **60% 以上**、**实质性运营**（实际管理机构在区内，对人员/账务/财产/业务实质管理）；② **海南**：鼓励类产业 15%，旅游业/现代服务业/高新技术产业；③ **横琴**：合作区鼓励类产业 15%（9 大类 150 项）；④ **前海**：现代服务业 15%，延至 **2027-12-31**；⑤ **南沙**：先行启动区鼓励类 15%，至 **2026-12-31**；⑥ **河套**：深圳园区特定产业 15%；⑦ **西部**：鼓励类产业 15%（2021–2030） |
| 合规要点 | ① **「注册即享受」是误解**：必须有实际办公、人员、账务、业务，空壳会被穿透；② 收入占比 60% 按**主营业务收入/收入总额**计算，不是利润占比；③ 优惠区域与高新 15%、小微 5% **不能重复叠加**，择优；④ 南沙 2027 年是否延续未定，预算要按 25% 做保守测算；⑤ 跨区域经营要**分段核算**，不能把区外收入并入区内优惠 |
| 信源 | ① https://www.chinatax.gov.cn/n810341/n810770/common_list_ssty.html（协定/区域政策检索入口）<br>② https://fgk.chinatax.gov.cn/（财税〔2026〕3 号、财税〔2020〕31 号、2020 年第 23 号公告）<br>③ https://guangdong.chinatax.gov.cn/（南沙/横琴/前海政策指引） |
| 核验 | 2026-11-08 联网核验：60% 收入占比、实质性运营、前海 2027/南沙 2026 到期；横琴/河套具体目录以当地公告为准 |

## 47.8 程序空间：预缴、汇算、更正、延期、复议、听证

| 字段 | 内容 |
|---|---|
| 文号 | 《税收征收管理法》第三十一条、第三十二条；《企业所得税法》第五十四条；《个人所得税法》第十一条；《税务行政复议规则》；《行政处罚法》第六十三至六十五条 |
| 发文机关 | 全国人大常委会；国务院；国家税务总局 |
| 效力层级 | 法律 + 行政法规 + 部门规章 |
| 公布/施行 | 各按原文件 |
| 时效性 | 现行有效 |
| 适用范围 | 所有纳税人 |
| 核心条款 | ① **预缴/汇算**：企税按月/季预缴、次年 5 月 31 日前汇算；个税综合所得次年 3–6 月汇算；预缴少缴可在汇算补，多缴可退；② **延期缴纳**：因特殊困难，经省税务局批准可延期，最长 **3 个月**，不加收滞纳金；③ **更正申报**：主动更正多缴可退（3 年内），少缴补税+滞纳金；④ **复议**：纳税争议 60 日内申请，现行仍须**清税/担保前置**；处罚/强制措施可直接复议或诉讼；⑤ **听证**：较大数额罚款等，收到告知书后 **5 日**内提出；⑥ **和解/调解**：行政复议、行政诉讼中可依法调解 |
| 合规要点 | ① 延期缴纳是**审批制**，不是自动延期，未获批仍按日万分之五；② 预缴不足会有滞纳金？——预缴期内按预缴，汇算补税一般不加滞纳金（除故意少缴）；③ 主动更正通常不罚款，被查后补税可能罚款；④ 复议前置只针对**纳税争议**，处罚/强制不受限制；⑤ 听证是**权利**，不提出视为放弃，但不影响后续复议/诉讼 |
| 信源 | ① https://www.gov.cn/gongbao/content/2007/content_609907.htm（征管法第三十一、三十二条）<br>② https://fgk.chinatax.gov.cn/（税务行政复议规则；行政处罚法第六十三至六十五条） |
| 核验 | 2026-11-08 联网核验：延期 3 个月、复议 60 日、听证 5 日、清税前置仍有效；详见 36 文件 |

## 47.9 裁量空间：首违不罚、从轻减轻、处罚幅度

| 字段 | 内容 |
|---|---|
| 文号 | 《行政处罚法》第三十二条、第三十三条；《税务行政处罚裁量权行使规则》；《税务行政处罚"首违不罚"事项清单》（国家税务总局公告 2021 年第 6 号） |
| 发文机关 | 全国人大常委会；国家税务总局 |
| 效力层级 | 法律 + 部门规范性文件 |
| 公布/施行 | 行政处罚法 2021-07-15；首违不罚清单 2021 年发布 |
| 时效性 | 现行有效 |
| 适用范围 | 税务行政处罚案件 |
| 核心条款 | ① **首违不罚**：初次违法且危害后果轻微并及时改正的，**可以**不予行政处罚（注意是「可以」不是「应当」）；② **从轻/减轻**：主动消除/减轻危害后果、受他人胁迫、主动供述、配合查处有立功表现等；③ **不予处罚**：违法行为轻微并及时改正，没有造成危害后果；④ **处罚幅度**：偷税处不缴/少缴税款 **0.5–5 倍**罚款；虚开、骗税等另有规定；⑤ **裁量基准**：各地税务局公布裁量基准，按违法情节分档 |
| 合规要点 | ① 「首违不罚」需同时满足**初次+轻微+及时改正**，不是所有第一次都免；② 主动补缴、配合检查、提供证据，是从轻的重要情节，要**书面留痕**；③ 处罚告知书阶段是**陈述申辩**的关键窗口，不要放弃；④ 罚款幅度可争，但**滞纳金**一般不可免（除非符合法定情形）；⑤ 对处罚不服可直接复议/诉讼，不需要先缴罚款（但复议/诉讼期间不停止执行，除非申请暂缓） |
| 信源 | ① https://fgk.chinatax.gov.cn/（行政处罚法第三十二、三十三条；2021 年第 6 号公告首违不罚清单）<br>② https://www.gov.cn/gongbao/content/2007/content_609907.htm（征管法第六十三条处罚幅度） |
| 核验 | 2026-11-08 联网核验：首违不罚「可以」表述、0.5–5 倍、从轻情节；具体裁量档位以各省基准为准 |

## 47.10 红线清单：这些「操作」不是筹划，是违法

| 字段 | 内容 |
|---|---|
| 文号 | 《刑法》第二百零一条至第二百一十二条；《税收征收管理法》第六十三条、第七十一条；《发票管理办法》 |
| 发文机关 | 全国人大常委会；国务院 |
| 效力层级 | 法律 + 行政法规 |
| 公布/施行 | 刑法修正案（十一）2021-03-01；征管法 2015 修正 |
| 时效性 | 现行有效 |
| 适用范围 | 所有纳税人、扣缴义务人、涉税服务机构 |
| 核心条款 | **绝对红线**：① **虚开发票**（为他人/为自己/让他人为自己/介绍他人开具与实际经营不符的发票）；② **两套账/隐匿收入**；③ **阴阳合同**（股权转让、不动产交易低报价格）；④ **虚列成本/白条入账**；⑤ **骗取出口退税**；⑥ **虚假享受优惠**（伪造高新/小微/研发资料）；⑦ **转移利润至低税地**且无商业实质；⑧ **销毁/隐匿账簿凭证**；⑨ **暴力/威胁抗税**；⑩ **中介帮助策划上述行为**（可能构成共犯）。<br>**后果**：补税+滞纳金+0.5–5 倍罚款；构成犯罪的，逃税罪/虚开增值税专用发票罪/骗取出口退税罪等，最高可至无期徒刑（虚开专票数额特别巨大）。 |
| 合规要点 | ① 「税务筹划」与「偷税」的分界不在形式，在**是否虚构事实、是否隐瞒收入**；② 涉税中介的「筹划方案」若含虚开/两套账，不能采信；③ 一旦被稽查，**主动补缴+配合**是争取从轻的唯一路径；④ 不要销毁证据，可能单独构成犯罪；⑤ 跨境架构要经得起**受益所有人/经济实质**审查 |

| 核验 | 2026-11-08 联网核验：虚开/逃税/骗税罪名与处罚幅度；具体定罪量刑以司法解释和判决为准，本文件不作个案判断 |
