## 37.2 协定待遇办理：「自行判断、申报享受、留存备查」

| 字段 | 内容 |
|---|---|
| 文号 | 国家税务总局公告 2019 年第 35 号 第三条、第五条、第六条 |
| 发文机关 | 国家税务总局 |
| 效力层级 | 部门规范性文件 |
| 公布/施行 | 2020-01-01 |
| 时效性 | 现行有效 |
| 适用范围 | 自行申报或由扣缴义务人源泉扣缴/指定扣缴的非居民纳税人 |
| 核心条款 | ① 享受协定待遇**不需事前审批**，采取「**自行判断、申报享受、相关资料留存备查**」方式；② 自行申报的：在申报时报送《非居民纳税人享受协定待遇信息报告表》；③ 源泉扣缴/指定扣缴的：非居民应填写报告表并**主动提交给扣缴义务人**，扣缴义务人确认信息完整后按协定扣缴，并将报告表作为扣缴申报附表报送税务机关；④ 非居民未提交或填报不完整的，扣缴义务人**依国内法扣缴**（即不享受协定优惠） |
| 合规要点 | ① 「自行判断」意味着**举证责任在纳税人**，判断错误要补税并承担延迟责任；② 扣缴环节是常见失败点：合同签了但未提交报告表，按国内法 10% 扣缴；③ 报告表信息须与合同、居民证明一致，否则后续管理中被否定；④ 可享受而未享受导致多缴的，可在征管法期限内申请退还（第十条，税务机关 30 日内查实） |
| 信源 | ① https://guangdong.chinatax.gov.cn/gdsw/mmsw_tzgg/2019-10/25/content_fba9f50aa18e449c81c4ac7159626ba7.shtml（第三、五、六条原文）<br>② https://shenzhen.chinatax.gov.cn/sztax/xwdt/ztzl/12366nsfwrx/12366rdwt/202606/61d7bb03be98411f8cb1a1eb545e0d07.shtml（深圳市税务局 2026-06 问答：办理方式与资料清单） |

## 37.4 受益所有人判定（五项不利因素）

| 字段 | 内容 |
|---|---|
| 文号 | 国家税务总局公告 2019 年第 35 号 第七条；《国家税务总局关于税收协定中「受益所有人」有关问题的公告》（**国家税务总局公告 2018 年第 9 号**） |
| 发文机关 | 国家税务总局 |
| 效力层级 | 部门规范性文件 |
| 公布/施行 | 2018 年第 9 号 2018-04-01；35 号公告 2020-01-01 |
| 时效性 | 现行有效 |
| 适用范围 | 申请享受股息、利息、特许权使用费条款待遇的缔约对方居民 |
| 核心条款 | ① 「受益所有人」指对所得或所得据以产生的权利/财产具有**所有权和支配权**的人，一般从事实质性经营活动；② 判定按「**实质重于形式**」综合分析，下列因素**不利于**认定：a. 有义务在收到所得 **12 个月内将 50% 以上**支付给第三国（地区）居民（含约定义务与已形成支付事实）；b. 经营活动**不构成实质性经营活动**（仅有登记注册、无制造/经销/管理等）；c. 缔约对方对有关所得**不征税或免税，或实际税率极低**；d. 贷款合同之外存在与第三人**数额、利率、签订时间相近**的其他贷款/存款合同（背靠背）；e. 特许权合同之外存在与第三人关于同一版权/专利/技术的**使用权或所有权转让合同**；③ 代理人、导管公司不属于受益所有人 |
| 合规要点 | ① 「香港/新加坡公司」不自动等于受益所有人，空壳控股是最常见被否情形；② 实质性经营活动可用人员、场地、决策记录、董事会纪要举证；③ 低税地注册 + 12 个月内转付 = 双重不利因素叠加；④ 被否后按国内法征税（股息 10%、利息 10%、特许权 10%），并可能加收滞纳金 |
| 信源 | ① https://guangdong.chinatax.gov.cn/gdsw/gzsw_yjl_zczy_sszn/2026-05/20/251f77a4b0e04b64ba8c599c27b7eab4/files/b62b8bd0c05446b0857c8fa74586f040.pdf（广州市税务局指引：五项不利因素逐项列示）<br>② https://guangdong.chinatax.gov.cn/gdsw/mmsw_tzgg/2019-10/25/content_fba9f50aa18e449c81c4ac7159626ba7.shtml（35 号公告第七条要求留存受益所有人资料） |
| 核验 | 2026-11-07 联网核验：五项不利因素与广州局指引逐条一致；9 号公告文号沿用 2026-11-05 核验结论 |

## 37.5 股息、利息、特许权使用费的限制税率（逐协定查，不得套用）

| 字段 | 内容 |
|---|---|
| 文号 | 各避免双重征税协定第二条/第十条（股息）、第十一条（利息）、第十二条（特许权使用费）及议定书 |
| 发文机关 | 中国政府与缔约对方政府（国际条约） |
| 效力层级 | 国际条约（经批准后在国内适用） |
| 公布/施行 | 逐协定不同，以生效日/适用年度为准 |
| 时效性 | 现行有效（个别协定已重签或修订，须查最新文本） |
| 适用范围 | 缔约对方税收居民取得来源于中国的股息、利息、特许权使用费 |
| 核心条款 | ① 协定对上述三类所得设定**限制税率**（低于国内法 10% 或与国内法相同），常见档位为股息 **5%/10%**（按持股比例分档）、利息 **7%/10%**、特许权使用费 **5%/10%**，但**各协定差异较大**；② 享受限制税率须同时满足：**居民身份 + 受益所有人 + 所得归属 + 程序合规**；③ 部分协定对特定类型特许权（如设备租赁、技术服务）适用不同税率或归入「其他所得」；④ 国内法税率低于协定的，**适用国内法**（协定不加重税负） |
| 合规要点 | ① **不得凭印象报「香港 5%」**：须核对持股比例门槛与最新议定书；② 技术服务费是否属特许权使用费，逐协定定性不同，直接影响税率；③ 同一笔支付涉及多地转付时，需同时评估受益所有人与反滥用条款；④ 建议建立「国别—所得类型—限制税率—条件」四列表，随协定更新维护 |
| 信源 | ① https://guangdong.chinatax.gov.cn/gdsw/mmsw_tzgg/2019-10/25/content_fba9f50aa18e449c81c4ac7159626ba7.shtml（35 号公告：协定待遇定义与留存要求）<br>② http://beijing.chinatax.gov.cn/bjswj/c105367/202304/68226f53684342c9b623b68e1bf201d0.shtml（北京市税务局国际税收问答：协定条款适用与资料要求） |
| 核验 | 2026-11-07 联网核验框架与条件；**逐国税率本库未逐条收录，标注「逐协定查原文」，不得作为测算依据** |

## 37.7 反滥用：主要目的测试与一般反避税

| 字段 | 内容 |
|---|---|
| 文号 | 国家税务总局公告 2019 年第 35 号 第二十一条；《企业所得税法》第四十七条（一般反避税）；各协定「享受协定优惠不应以逃避税为主要目的」条款（PPT） |
| 发文机关 | 国家税务总局；全国人大常委会 |
| 效力层级 | 部门规范性文件 + 法律 + 国际条约 |
| 公布/施行 | 35 号公告 2020-01-01；企业所得税法 2008-01-01 |
| 时效性 | 现行有效 |
| 适用范围 | 存在导管安排、择协避税、人为拆分交易等情形的非居民 |
| 核心条款 | ① 税务机关在后续管理中发现需适用协定**主要目的测试（PPT）**或国内**一般反避税规则**的，按一般反避税相关规定处理；② 一般反避税可对**不具有合理商业目的**的安排进行重新定性、调整应纳税所得；③ 不当享受协定待遇会被建立**信用档案**并加强后续管理（第二十二条）；④ 不符合条件而享受的，视为未按规定申报缴税，追缴税款并追究延迟纳税责任（第十六条） |
| 合规要点 | ① 「商业目的」举证在纳税人：需说明架构的经济实质、决策地、人员与风险承担；② 中间层设在低税地且无实质经营，是 PPT 否定的典型；③ 被否定后不仅补税，还可能面临利息/滞纳金与信用影响；④ 重大跨境架构建议事先做税务尽调或申请预约定价/事先裁定（如适用） |

## 37.8 常见误区（香港公司、导管、常设机构）

| 字段 | 内容 |
|---|---|
| 文号 | 国家税务总局公告 2019 年第 35 号；内地与香港税收安排；各协定常设机构条款 |
| 发文机关 | 国家税务总局；缔约双方 |
| 效力层级 | 部门规范性文件 + 国际条约 |
| 公布/施行 | 按各自生效日 |
| 时效性 | 现行有效 |
| 适用范围 | 跨境支付与跨境经营企业 |
| 核心条款 | ① **误区一**：认为「注册在香港就享受 5% 股息」——须同时满足居民身份、受益所有人、持股比例门槛，空壳公司会被否；② **误区二**：用「导管公司」转付——12 个月内转付 50% 以上是明确的不利因素；③ **误区三**：忽略常设机构（PE）——建筑工地、安装工程、服务型 PE 有时间门槛（逐协定不同，常见 6/12 个月），超期即需在华纳税；④ **误区四**：只关注税率不看定性——技术服务费、设备租赁可能被归入特许权使用费或其他所得，税率不同；⑤ **误区五**：以为备案一次长期有效——居民证明按年度，合同与架构变化需重新评估 |
| 合规要点 | ① 跨境支付前做「四查」：查协定、查居民证明、查受益所有人、查反滥用；② 保留董事会决议、人员社保、办公场所等实质经营证据；③ 常设机构判定要按项目起止日管理，避免超期未申报；④ 涉及大额或复杂架构，建议取得专业意见并留痕 |
