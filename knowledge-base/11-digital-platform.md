# 11 平台经济、直播电商与新业态用工

> 核验日期：2026-11-05 ｜ 信源：中国政府网（国务院令第 810 号）、国家税务总局（2025 年第 15、16 号公告及解读、12366 答复）、国家网信办、市场监管总局
> 定位：平台企业报送义务、平台内经营者与从业人员税务处理、直播收入定性、灵活用工合规边界。**本主题为 2025 年新规，变化快，引用前须复核最新公告。**

## 11.1 《互联网平台企业涉税信息报送规定》

| 字段 | 内容 |
|---|---|
| 文号 | 国务院令第 810 号 |
| 发文机关 | 国务院（2025-06-13 国务院第 61 次常务会议通过，李强总理签署） |
| 效力层级 | 行政法规 |
| 公布/施行 | 2025-06-20 公布，**自公布之日起施行** |
| 时效性 | 现行有效 |
| 适用范围 | 电子商务平台经营者及其他为网络交易提供网络经营场所、交易撮合、信息发布等营利性服务的法人或非法人组织 |
| 核心条款 | ① 平台企业须向主管税务机关报送平台内经营者和从业人员的**身份信息、收入信息**；② 首次报送：施行之日起 30 日内或从事互联网经营业务之日起 30 日内，报送域名、业务类型、运营主体统一社会信用代码及名称；③ 常规报送：**季度终了的次月内**报送上季度收入信息；④ 免报情形：配送、运输、家政等便民劳务从业人员依法享受优惠或无需纳税的收入信息，以及规定施行前的涉税信息；⑤ 已通过扣缴申报、代办申报填报的信息不重复报送；⑥ 平台对信息真实性、准确性、完整性负责，尽到核验义务的可免责；⑦ 税务机关可要求平台提供合同订单、交易明细、资金账户、物流等资料；⑧ 违规可责令改正、罚款，情节严重的责令停业整顿 |
| 合规要点 | ① 平台内**经营者本身没有报送义务**，不存在“多平台重复报送”；② 平台报送不改变纳税义务，但会显著提高收入透明度；③ 平台应建立商户身份核验与收入归集机制，留存核验记录以主张免责；④ 涉税信息须依法保密，泄露将担责 |
| 信源 | 中国政府网 gov.cn/zhengce/content/202506/content_7029052.htm；税务总局 2025-06-20 发布稿；司法部、税务总局答记者问 |
| 核验 | 2026-11-05 核验国务院令号、通过/公布/施行日期与季度报送规则 |

## 11.3 平台企业为从业人员办理扣缴申报、代办申报

| 字段 | 内容 |
|---|---|
| 文号 | 国家税务总局公告 2025 年第 16 号 |
| 发文机关 | 国家税务总局 |
| 效力层级 | 税务规范性文件 |
| 公布/施行 | 2025 年发布并施行 |
| 时效性 | 现行有效 |
| 适用范围 | 互联网平台企业及其平台内从业人员 |
| 核心条款 | ① 从业人员自平台取得**劳务报酬所得**的，平台按累计预扣法预扣预缴：本期应预扣预缴税额＝（累计收入−累计费用−累计免税收入−累计减除费用−累计依法确定的其他扣除）×预扣率−速算扣除数−累计减免税额−累计已预扣预缴税额；② **累计费用按累计收入×20% 计算**；③ 累计减除费用按 **5000 元/月 × 当年在本平台连续取得劳务报酬的月份数** 计算；④ 劳务报酬所得一般包括通过平台提供直播、教育、医疗、配送、家政、家教、旅行、咨询、培训、经纪、设计、演出、广告、翻译、代理、推广、技术服务等营利性服务所得；⑤ **未取得市场主体登记证照**的平台内经营者和从业人员，通过平台销售货物、提供运输服务取得的所得，属于**经营所得**；⑥ 增值税方面可按规定享受小规模纳税人月销售额 10 万元以下免征、3% 征收率减按 1% 等优惠 |
| 合规要点 | ① 收入定性决定申报方式：劳务报酬由平台扣缴，经营所得由个人自行申报；② “转换收入性质”是当前稽查重点，空壳个体户/个独不开票、无人员无场地，极易被穿透；③ 平台不得通过“公会”、第三方或免责协议转嫁扣缴义务 |
| 信源 | 国家税务总局公告 2025 年第 16 号及政策解读；大连市税务局 2025-11 答复；12366 浙江中心答复 |
| 核验 | 2026-11-05 核验文号、累计预扣公式、20% 费用与 5000 元/月规则 |

## 11.4 《中华人民共和国电子商务法》涉税条款

| 字段 | 内容 |
|---|---|
| 发文机关 | 全国人大常委会 |
| 效力层级 | 法律 |
| 公布/施行 | 2018-08-31 通过，**2019-01-01 施行** |
| 时效性 | 现行有效 |
| 适用范围 | 电子商务经营者（平台经营者、平台内经营者、自建网站经营者） |
| 核心条款 | ① 第十一条：电子商务经营者应当依法履行纳税义务，并依法享受税收优惠；② 第十四条：电子商务经营者销售商品或提供服务应出具纸质发票或电子发票，电子发票与纸质发票具有同等法律效力；③ 第二十八条：平台经营者应向市场监管部门报送平台内经营者身份信息，提示未办理登记的经营者在首页显著位置持续公示；④ 第十条：个人销售自产农副产品、家庭手工业产品，个人利用自己技能从事依法无须取得许可的便民劳务活动和零星小额交易活动，以及依照法律、行政法规不需要进行登记的除外 |
| 合规要点 | ① “电商不交税”是误解，线上线下一视同仁；② 平台内经营者应公示营业执照与行政许可信息；③ 零星小额标准与税务上的起征点不是同一概念，免登记不等于免税 |
| 信源 | 全国人大网电子商务法原文 |
| 核验 | 2026-11-05 核验施行日与第十一、十四、二十八条要点 |

## 11.5 《网络交易监督管理办法》

| 字段 | 内容 |
|---|---|
| 文号 | 国家市场监督管理总局令第 37 号 |
| 发文机关 | 市场监管总局 |
| 效力层级 | 部门规章 |
| 公布/施行 | 2021-03-15 公布，**2021-05-01 施行** |
| 时效性 | 现行有效 |
| 适用范围 | 网络交易经营者（含平台、平台内经营者、自建网站） |
| 核心条款 | ① 第八条：个人从事网络交易活动，**年交易额累计不超过 10 万元**的，依电子商务法第十条不需要登记；同一经营者在同一平台或多个平台开设多家网店的，各网店交易额**合并计算**；② 年交易额超过 10 万元须办理市场主体登记；③ 平台应核验、登记平台内经营者身份信息并定期更新；④ 直播服务应显著标明实际销售商品或服务的经营者 |
| 合规要点 | ① “多店拆分”不能规避 10 万元标准，合并计算；② 超过标准未登记，除市场监管处罚外，税务上无法适用小规模优惠与核定政策；③ 直播带货须标明真实销售者，避免责任主体不清 |
| 信源 | 市场监管总局令第 37 号原文 |
| 核验 | 2026-11-05 核验 10 万元标准与合并计算规则 |

## 11.6 《关于进一步规范网络直播营利行为促进行业健康发展的意见》

| 字段 | 内容 |
|---|---|
| 文号 | 三部门联合印发（无单独公告文号），国家网信办官网 2022-03-25 公布 |
| 发文机关 | 国家互联网信息办公室、国家税务总局、国家市场监督管理总局 |
| 效力层级 | 部门联合规范性文件 |
| 公布/施行 | 2022-03-25 发布施行 |
| 时效性 | 现行有效 |
| 适用范围 | 网络直播平台、直播服务机构（MCN）、网络直播发布者（主播） |
| 核心条款 | ① 平台与服务机构应明确区分主播各类收入来源及性质，依法履行**个人所得税代扣代缴**义务；② 不得通过成立“公会”、借助第三方或签订不履行代扣代缴义务的免责协议等方式转嫁、逃避扣缴义务；③ 平台应每半年向网信、税务部门报送存在营利行为的网络直播发布者个人身份、账号、经营主体、收入类型及营利情况；④ 不得为违法失德艺人提供直播复出机会 |
| 合规要点 | ① MCN 与主播签“自负税款”条款不能免除平台/机构扣缴义务；② 打赏、坑位费、佣金、广告费应分别定性，不能一律按“经营所得”核定；③ 平台报送与 810 号令形成双重信息网 |
| 信源 | 国家网信办 2022-03-25 发布稿；税务总局转载 |
| 核验 | 2026-11-05 核验发布机关、日期与扣缴义务条款 |

## 11.7 直播与平台收入定性：劳务报酬 vs 经营所得

| 字段 | 内容 |
|---|---|
| 发文机关 | 国家税务总局（公告 2025 年第 16 号及解读）；司法机关案例 |
| 效力层级 | 税务规范性文件 + 司法裁判口径 |
| 公布/施行 | 2025 年起 |
| 时效性 | 现行有效 |
| 适用范围 | 主播、带货达人、平台服务提供者 |
| 核心条款 | ① 个人未登记市场主体、以个人名义在平台提供直播等营利性服务，所得一般按**劳务报酬**由平台扣缴；② 注册个体工商户、个人独资企业、合伙企业并以该主体**实质性开展经营活动**的，可按经营所得计税；③ 仅注册空壳工作室、无场地无人员无真实业务，用于开票走账、转换收入性质的，按**实质课税原则**穿透，构成偷税；④ 2025 年公开案例：主播注册无租金、无水电、无参保员工、无真实交易的个独企业，收入仍被认定为劳务报酬并追缴处罚 |
| 合规要点 | ① 判断标准是“实质经营”而非“有没有执照”；② 工作室须有真实人员、场地、业务、成本与风险承担；③ 平台扣缴与个人汇算不能相互替代，取得两处以上综合所得仍需汇算 |
| 信源 | 国家税务总局公告 2025 年第 16 号解读；中国经济网 2026-07-17 公开案例报道 |
| 核验 | 2026-11-05 核验定性规则与公开案例 |

## 11.8 灵活用工平台的虚开与用工风险

| 字段 | 内容 |
|---|---|
| 发文机关 | 国家税务总局（稽查口径）；最高人民法院、最高人民检察院（涉税犯罪司法解释） |
| 效力层级 | 税务规范性文件 + 司法解释 |
| 公布/施行 | 持续适用 |
| 时效性 | 现行有效 |
| 适用范围 | 灵活用工平台、用工企业、自由职业者 |
| 核心条款 | ① 平台须基于**真实业务**开具发票，业务流、资金流、合同流、发票流、人员流应相互印证；② 无真实用工而开票、变名开票（如把工资薪金变为“技术服务费”）、资金回流，可能构成虚开增值税专用发票罪或虚开发票罪；③ 用工企业取得虚开发票的进项税额不得抵扣，支出不得税前扣除，并可能被追缴滞纳金与罚款；④ 符合劳动关系特征的“灵活用工”仍可能被认定为事实劳动关系，需补缴社保 |
| 合规要点 | ① 选择平台时核查其委托代征资质、业务真实性审核能力与资金闭环；② 保留任务发布、接单、交付、验收、结算全链路证据；③ 高比例“只开票不干活”是稽查高风险信号；④ 虚开属刑事风险，不可用“补税”简单化解 |
| 信源 | 最高法、最高检涉税犯罪司法解释；税务总局稽查案例通报；各地税务风险提示 |
| 核验 | 2026-11-05 核验风险类型与法律后果；具体罪名适用以司法解释原文为准 |
