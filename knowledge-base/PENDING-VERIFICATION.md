## 五、复核与更新流程

1. `python app/audit_kb.py` → `reports/audit-stats.json`（分型达标率 + flags 明细 + 隔离项）；
2. 对本清单第二/三节逐项取得**两个独立官方信源**（A 级法定文本，B 级官方解读仅作辅证）；
3. 能闭环 → 新建或更新 A 层条目 → `app/apply_corrections.py` 回写源条目 → 从清单移除 → `00-index.md` 版本日志留痕；
4. 不能闭环 → 保留并更新「本轮核验经过」，不得因时间推移自动视为已确认；
5. 重建：`build_kb.py` → `enrich_kb.py` → `audit_kb.py`；重启服务；跑 `e2e-test.py --smoke` 与全量回归；
6. 频率：每月 1 日政策雷达；每季度复核阻断项；2027 年 Q3 起集中到期优惠续期预警。
