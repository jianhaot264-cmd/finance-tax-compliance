| 效力层级 | 行政法规 + 规范性文件 |
| 公布/施行 | 2026-01-01 |
| 时效性 | 现行有效 |
| 适用范围 | 银行、证券、保险、信托、基金、资管产品管理人及企业借款方 |

| 核心条款 | ① 企业新购进**设备、器具**单位价值不超过 **500 万元**的，允许**一次性计入当期成本费用**在税前扣除（2024-01-01 至 2027-12-31）；② 企业研发费用未形成无形资产的，按实际发生额 **100% 加计扣除**；形成无形资产的按成本 **200%** 摊销；③ **先进制造业**企业（制造业一般纳税人）可按当期可抵扣进项税额加计 **5%** 抵减应纳增值税（2023-01-01 至 2027-12-31，与留抵退税等国策不叠加，按公告条件判定） |
| 合规要点 | ① 一次性扣除是**税会差异**，会计仍计提折旧，需做纳税调整与后续年度转回；② 研发加计需建立**辅助账**并按项目归集，负面清单行业不适用；③ 加计抵减 5% 与「生产性生活性服务业 10%/15%」是不同政策，勿混；④ 三项政策均 2027-12-31 到期，需提前评估续期 |
