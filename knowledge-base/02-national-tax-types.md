# 02 全国性法规 · 实体税种

> 核验日期：2026-11-04 ｜ 信源：国家税务总局政策法规库、中国政府网、各省税务局官网
> ★ 核心动态：**《增值税法》及其《实施条例》已于 2026-01-01 同步施行，《增值税暂行条例》同时废止**——我国第一大税种完成立法。

## 2.1 《中华人民共和国增值税法》★

| 字段 | 内容 |
|---|---|
| 发文机关 | 全国人大常委会（十四届全国人大常委会第十三次会议） |
| 效力层级 | 法律 |
| 公布/施行 | 2024-12-25 通过，2026-01-01 施行；**同时废止《增值税暂行条例》** |
| 时效性 | 现行有效 |
| 适用范围 | 境内销售货物、服务、无形资产、不动产（应税交易）及进口货物的单位和个人 |
| 核心条款 | ① 税率：一般应税交易 13%；销售交通运输、邮政、基础电信、建筑、不动产租赁、不动产转让、土地使用权及农产品等 9%；服务（销售土地使用权外）、无形资产 6%；出口货物及跨境规定服务零税率；② 小规模纳税人适用简易计税（征收率 3%，另有法定特殊情形）；③ 一般纳税人实行登记制；④ 应纳税额=当期销项税额−当期进项税额；⑤ 税收优惠法定化并要求政策公开、适时评估调整 |
| 合规要点 | ① 立法后税制框架与税负基本不变，但术语与口径以法律为准（"加工修理修配劳务"并入"服务"）；② 关注"法律+条例+配套文件"三层规范体系，引用依据时注意层级；③ 发票/抵扣规则细节以实施条例（2.2）及后续配套公告为准 |
| 信源 | 国家税务总局 chinatax.gov.cn、河南/吉林税务局解读 |
| 核验 | 2026-11-04 联网核验 |

## 2.2 《中华人民共和国增值税法实施条例》★

| 字段 | 内容 |
|---|---|
| 文号 | 国务院令第 826 号 |
| 发文机关 | 国务院（2025-12-19 国务院第 75 次常务会议通过） |
| 效力层级 | 行政法规 |
| 公布/施行 | 2025-12-25 公布，2026-01-01 与增值税法同步施行 |
| 时效性 | 现行有效 |
| 适用范围 | 增值税法配套 |
| 核心条款 | ① 6章54条：界定货物（含电力热力气体）、服务（含交通运输/建筑/金融/信息技术等）、无形资产、不动产范围；② 单位=企业、行政机关、事业单位、军事单位、社会组织及其他；个人=个体工商户+自然人；**自然人属于小规模纳税人**；③ 境内消费情形界定（境外向境内销售服务等三种情形）；④ 一般纳税人登记按《增值税法》第九条及国家税务总局公告 2026 年第 2 号执行（原 43 号令已于 2026-01-01 废止）；⑤ 开具专票须分别列明销售额与税额；⑥ 跨境零税率服务范围（研发、设计、软件、信息系统、离岸外包等）；⑦ 扣税凭证列举+"其他具有进项税额抵扣功能的扣税凭证"兜底（为以数治税预留）；⑧ 混合用途长期资产抵扣规则完善；⑨ 优惠政策适用范围/标准/条件须依法及时公开 |
| 合规要点 | ① 2026 年起申报、抵扣、开票口径对照条例逐项核对；② 享受优惠前先查公开的适用范围与标准；③ 混合用途资产进项抵扣可依新规主张 |
| 信源 | 吉林税务局转载全文 jilin.chinatax.gov.cn/art/2025/12/25/...；司法部/财政部/税务总局负责人答记者问（税务总局法规库） |
| 核验 | 2026-11-04 联网核验（条文原文） |

## 2.3 《中华人民共和国企业所得税法》

| 字段 | 内容 |
|---|---|
| 发文机关 | 全国人民代表大会 |
| 效力层级 | 法律 |
| 公布/施行 | 2007-03-16 通过，2008-01-01 施行；2017-02-24、2018-12-29 两次修正（依据见 20-20.1） |
| 时效性 | 现行有效 |
| 适用范围 | 境内企业和取得收入的组织；居民企业/非居民企业 |
| 核心条款 | ① 基本税率 25%；② 高新技术企业减按 15%；③ 应纳税所得额=收入总额−不征税收入−免税收入−各项扣除−以前年度亏损；④ 研发费用加计扣除、固定资产加速折旧等优惠授权国务院规定；⑤ 小型微利企业优惠适用 |
| 合规要点 | 优惠采取"自行判别、申报享受、资料留存备查"方式——留存备查资料不齐是稽查高发问题 |
| 信源 | 国家法律法规数据库 flk.npc.gov.cn；http://www.npc.gov.cn/c2/c30834/201905/t20190521_296654.html ；https://neris.csrc.gov.cn/falvfagui/rdqsHeader/mainbody?secFutrsLawId=745439065454041418 （2026-11-06 闭环双源） |
| 核验 | 2026-11-06 闭环校验，权威结论见 20-20.1（双官方信源） |

## 2.5 《中华人民共和国个人所得税法》

| 字段 | 内容 |
|---|---|
| 发文机关 | 全国人大常委会 |
| 效力层级 | 法律 |
| 公布/施行 | 1980-09-10 通过；2018-08-31 第七次修正，2019-01-01 施行 |
| 时效性 | 现行有效 |
| 适用范围 | 居民/非居民个人的所得 |
| 核心条款 | ① 综合所得（工资薪金+劳务报酬+稿酬+特许权使用费）按年计税，基本减除费用 6 万元/年；税率 3%-45% 超额累进；② 经营所得 5%-35%；③ 综合所得汇算清缴（次年 3-6 月）；④ 专项扣除+专项附加扣除+依法确定的其他扣除；⑤ 反避税条款与个人转让股权等规则 |
| 合规要点 | ① 年度汇算勿漏（退税可放弃、补税不可拖）；② 专项附加扣除信息如实填报留存资料 |
| 核验 | 框架性内容 2026-11-04 间接核验 |

## 2.9 《中华人民共和国消费税暂行条例》

| 字段 | 内容 |
|---|---|
| 文号 | 国务院令第 539 号（2008-11-10 修订公布） |
| 发文机关 | 国务院（依据见 18-18.1） |
| 效力层级 | 行政法规 |
| 公布/施行 | 2008-11-10 修订公布，2009-01-01 施行（1993-12-13 国务院令第 135 号首次发布，2008 年修订） |
| 时效性 | 现行有效；**消费税法尚未出台**——国务院 2026 年度立法工作计划（2026-05 公布）将其列为"预备提请全国人大常委会审议的法律案"，立法仍在推进；现行依据仍为《消费税暂行条例》 |
| 适用范围 | 在中华人民共和国境内生产、委托加工和进口应税消费品的单位和个人 |

| 合规要点 | 消费税应税消费品企业关注立法动态，税目税率调整将直接影响成本；消费税是**价内税**，与增值税价外税不同 |
