# 17 所得税扣除、汇算与专项附加扣除（生产版）

> 定位：企业所得税税前扣除硬比例、个人所得税汇算与专项附加扣除。所有数字均取自法规原文，非二次转述。

## 17.1 《中华人民共和国企业所得税法实施条例》扣除限额

| 字段 | 内容 |
|---|---|
| 文号 | 国务院令第 512 号 |
| 发文机关 | 国务院 |
| 效力层级 | 行政法规 |
| 公布/施行 | 2007-12-11 公布，**2008-01-01 施行** |
| 时效性 | 现行有效（个别条款经后续文件调整，见 17.2） |
| 适用范围 | 居民企业及在中国境内设立机构场所的非居民企业 |
| 核心条款 | ① 第三十四条：合理的工资薪金支出准予扣除；② 第三十五条：按规定的基本社保费与住房公积金准予扣除，补充养老/医疗在规定标准内扣除；③ 第四十条：职工福利费不超过工资薪金总额 **14%**；④ 第四十一条：拨缴的工会经费不超过 **2%**；⑤ 第四十二条：职工教育经费不超过 **2.5%**，超过部分结转以后年度（后续文件已提高至 8%，见 17.2）；⑥ 第四十三条：业务招待费按发生额 **60%** 扣除，且最高不超过当年销售（营业）收入 **5‰**；⑦ 第四十四条：广告费和业务宣传费不超过当年销售收入 **15%**，超过部分结转；⑧ 第五十三条：公益性捐赠不超过**年度利润总额 12%** 的部分准予扣除；⑨ 第四十九条：企业之间支付的管理费、内设机构之间租金与特许权使用费、非银行内设机构之间利息不得扣除 |
| 合规要点 | ① 三个「工资薪金总额」口径与「销售收入」口径不同，不能混用基数；② 业务招待费是「双限额取小」；③ 超限额的广宣费、职工教育经费可结转，业务招待费不可结转；④ 公益性捐赠须通过公益性社会组织或县级以上政府，年度利润总额按会计利润计算 |
| 信源 | https://www.gov.cn/zhengce/2007-12/11/content_2602496.htm （中国政府网国务院令第 512 号原文）；https://xzfg.moj.gov.cn/front/law/detail?LawID=1741 （司法部国家行政法规库全文） |
| 核验 | 2026-11-06 双源逐条核对条款号与比例，均一致 |

## 17.2 企业所得税扣除标准的后续调整（避免引用旧限额）

| 字段 | 内容 |
|---|---|
| 文号 | 《企业所得税法》第九条；财政部 税务总局公告 2023 年第 12 号等延续文件；财政部 税务总局公告 2025 年第 16 号 |
| 发文机关 | 全国人大常委会、财政部、国家税务总局 |
| 效力层级 | 法律 + 部门规范性文件 |
| 公布/施行 | 512 号令 2008-01-01；后续公告按各自执行期 |
| 时效性 | 现行有效（**512 号令原文比例未改，但特定项目已被后续文件提高，须按新文件执行**） |
| 适用范围 | 企业所得税纳税人 |
| 核心条款 | ① 职工教育经费：512 号令为 2.5%，后续政策将**一般企业职工教育经费税前扣除比例提高至工资薪金总额 8%**（财税〔2018〕51 号，引用前复核原文）；② 广宣费：化妆品制造或销售、医药制造、饮料制造（不含酒类）提高至 **30%**，依据财政部 税务总局公告 2025 年第 16 号，执行至 **2027-12-31**；③ 公益性捐赠：超过年度利润总额 12% 的部分准予结转以后三年扣除（《企业所得税法》第九条）；④ 公益性捐赠「全额扣除」等特殊政策按专项公告执行，须逐项核对有效期 |
| 合规要点 | ① **生产系统不能硬编码 512 号令的 2.5%/15% 作为唯一上限**，必须叠加行业与年度政策；② 2027-12-31 是多项优惠的共同到期日，需建立续期监控；③ 所有超限额结转项目应建立台账，避免重复扣除 |
| 信源 | https://www.gov.cn/zhengce/2007-12/11/content_2602496.htm （512 号令原文）；https://www.chinatax.gov.cn/chinatax/n810219/n810744/c103147/c5249424/5249424/files/8e2bb59af3de4dec860e856ad66be304.pdf （《中国税务年度报告（2025）》记 2025 年第 16 号公告 30% 延续至 2027-12-31） |
| 核验 | 2026-11-06 双源核验 30% 与到期日；**职工教育经费 8% 的具体文号列为本轮剩余复核项**（见 PENDING-VERIFICATION.md） |

## 17.3 《个人所得税综合所得汇算清缴管理办法》

| 字段 | 内容 |
|---|---|
| 文号 | 国家税务总局令第 57 号 |
| 发文机关 | 国家税务总局（2025-02-21 局务会议审议通过） |
| 效力层级 | 部门规章 |
| 公布/施行 | **2025-02-26 公布，自公布之日起施行** |
| 时效性 | 现行有效 |
| 适用范围 | 取得工资薪金、劳务报酬、稿酬、特许权使用费四项综合所得的居民个人；非居民个人、分类所得不适用 |
| 核心条款 | ① 汇算期：取得所得的**次年 3 月 1 日至 6 月 30 日**；② 应退/应补税额＝[(综合所得收入额−60000−专项扣除−专项附加扣除−其他扣除−公益慈善捐赠)×适用税率−速算扣除数]−减免税额−已预缴税额；③ 无需办理四类情形（补税但全年综合所得收入不超过规定金额、补税不超过规定金额、预缴税额与应纳税额一致、符合退税条件但不申请退税）；④ 需办理三类情形（申请退税、补税且不符合豁免、因所得项目错误/扣缴义务人未扣缴/无扣缴义务人导致少申报或未申报）；⑤ 同时取得综合所得与经营所得的，6 万元减除费用及各项扣除只能在其中一处申报，不得重复；⑥ 办理方式：自行办理、单位代为办理、委托涉税专业服务机构；相关资料自汇算期结束之日起**留存 5 年**；⑦ 申报信息错误主动改正的可按「首违不罚」免予处罚；未申报补税或未足额补税的加收滞纳金并在纳税记录中标注 |
| 合规要点 | ① 57 号令是「管长远」的部门规章，替代以往每年发布的汇算公告，企业代扣代缴流程应据此固化；② 单位代办须取得纳税人书面或电子确认，未确认不得代办；③ 法定代表人、合伙自然人合伙人、个独投资者未依法汇算会关联纳入企业纳税信用评价 |
| 信源 | https://fgk.chinatax.gov.cn/zcfgk/c100011/c5238560/content.html （国家税务总局政策法规库全文）；https://shanghai.chinatax.gov.cn/gate/big5/shanghai.chinatax.gov.cn/zcfw/zcfgk/grsds/202502/t475327.html （上海税务局全文）；https://www.chinatax.gov.cn/chinatax/n810214/n810641/c102061/zfxxgks.html （总局规章目录，记 57 号令公布施行日） |
| 核验 | 2026-11-06 三源交叉核验文号、公布/施行日、汇算期、留存 5 年与信用关联条款 |

## 17.4 《个人所得税专项附加扣除暂行办法》及提标通知

| 字段 | 内容 |
|---|---|
| 文号 | 国发〔2018〕41 号（暂行办法）；国发〔2023〕13 号（提高标准） |
| 发文机关 | 国务院 |
| 效力层级 | 国务院规范性文件 |
| 公布/施行 | 暂行办法 2018 年印发；**国发〔2023〕13 号 2023-08-28 印发，调整后标准自 2023-01-01 起实施** |
| 时效性 | 现行有效 |
| 适用范围 | 取得综合所得的居民个人；7 项专项附加扣除 |
| 核心条款 | ① 7 项：3 岁以下婴幼儿照护、子女教育、继续教育、大病医疗、住房贷款利息、住房租金、赡养老人；② 提标后：3 岁以下婴幼儿照护、子女教育由每孩每月 1000 元提高至 **2000 元**；赡养老人由每月 2000 元提高至 **3000 元**（独生子女按 3000 元定额扣除；非独生子女分摊 3000 元额度，每人分摊不超过 **1500 元**）；③ 父母可选择由一方按 100% 扣除或双方各按 50% 扣除，一个纳税年度内不能变更；④ 其他事项仍按暂行办法执行；⑤ 已填报的无需重新填报，系统自动按新标准计算 |
| 合规要点 | ① 企业 HR/薪酬系统若仍按 1000 元/2000 元旧标准计算会少扣、多扣个税；② 3 岁以下婴幼儿照护与子女教育不能对同一子女同期重复享受；③ 赡养老人分摊额度需留存分摊协议；④ 员工提供信息不实，企业作为扣缴义务人应提示更正并留存沟通记录 |

| 核验 | 2026-11-06 三源交叉核验三项标准、分摊上限与实施日 |

## 17.5 企业所得税收入确认与不得扣除项目

| 字段 | 内容 |
|---|---|
| 文号 | 《企业所得税法实施条例》第九、二十三、二十五、二十八、三十二、五十四、五十五条 |
| 发文机关 | 国务院 |
| 效力层级 | 行政法规 |
| 公布/施行 | 2008-01-01 施行 |
| 时效性 | 现行有效 |
| 适用范围 | 企业所得税纳税人 |
| 核心条款 | ① 第九条：应纳税所得额计算以**权责发生制**为原则；② 第二十三条：分期收款销售按合同约定收款日确认；持续时间超过 12 个月的大型设备/建筑安装等按完工进度或工作量确认；③ 第二十五条：非货币性资产交换，以及将货物、财产、劳务用于捐赠、偿债、赞助、集资、广告、样品、职工福利、利润分配的，应**视同销售**；④ 第二十八条：区分收益性支出与资本性支出，不征税收入形成的费用或财产不得扣除，不得重复扣除；⑤ 第三十二条：损失减除责任人赔偿和保险赔款后的余额按规定扣除，已作损失处理又收回的应计入当期收入；⑥ 第五十四条：赞助支出指与生产经营无关的各种非广告性质支出（不得扣除）；第五十五条：未经核定的准备金支出不得扣除 |
| 合规要点 | ① 视同销售是稽查高频点，市场推广样品、职工福利发放自产产品都要确认收入；② 不征税收入对应支出不得扣除，需单独核算；③ 资产损失须留存证据链并按申报口径处理 |
| 信源 | https://xzfg.moj.gov.cn/front/law/detail?LawID=1741 （司法部国家行政法规库全文）；https://www.gov.cn/zhengce/2007-12/11/content_2602496.htm （中国政府网国务院令第 512 号原文） |
| 核验 | 2026-11-06 双源逐条核对条款号与内容 |
