# 13 产业与区域税收优惠（高新技术、研发、软件、西部、创投等）

> 核验日期：2026-11-05 ｜ 信源：财政部、税务总局、科技部、中国政府网政策文件库

## 13.1 高新技术企业减按 15% 征收企业所得税

| 字段 | 内容 |
|---|---|
| 文号 | 国科发火〔2016〕32 号；财税〔2018〕76 号（亏损结转） |
| 发文机关 | 科技部、财政部、国家税务总局 |
| 效力层级 | 部门规范性文件 |
| 公布/施行 | 2016-01-29 发布，自 2016-01-01 起实施；资格有效期 3 年 |
| 时效性 | 现行有效 |
| 适用范围 | 国家重点支持的高新技术领域内、持续研发与成果转化的居民企业 |
| 核心条款 | ① 经认定后减按 **15%** 税率征收企业所得税（法定 25%）；② 认定条件：注册成立满 1 年；拥有核心知识产权所有权；技术属于八大领域；**科技人员占职工总数不低于 10%**；研发费用占销售收入比例：最近一年收入 ≤5000 万元的不低于 **5%**，5000 万–2 亿元的不低于 **4%**，2 亿元以上的不低于 **3%**，境内研发费用占全部研发费用不低于 **60%**；**高新技术产品（服务）收入占同期总收入不低于 60%**；创新能力评价 **71 分以上**；申请前一年无重大安全、质量、环境违法；③ 资格期满前须重新认定；④ 具备资格年度之前 5 个年度未弥补亏损，结转年限由 5 年延长至 **10 年** |
| 合规要点 | ① 高新资格不是“终身制”，每年需满足条件，抽查不合格会被取消并追缴；② 研发费用归集口径与加计扣除口径不完全一致，不能一套数据两处套用；③ 高新收入占比不足是复审失败主因；④ 认定后须按规定报送年度发展情况报表 |
| 信源 | 国科发火〔2016〕32 号；财税〔2018〕76 号；税务总局政策指引 |
| 核验 | 2026-11-05 核验 15% 税率、10%/5%/4%/3%/60%/60%/71 分等硬指标 |

## 13.2 研发费用税前加计扣除 100%

| 字段 | 内容 |
|---|---|
| 文号 | 财政部 税务总局公告 2023 年第 7 号；财税〔2015〕119 号；财税〔2018〕64 号 |
| 发文机关 | 财政部、税务总局 |
| 效力层级 | 部门规范性文件 |
| 公布/施行 | 2023-03-26 发布，**自 2023-01-01 起执行，作为制度性安排长期实施** |
| 时效性 | 现行有效 |
| 适用范围 | 除烟草制造业、住宿和餐饮业、批发和零售业、房地产业、租赁和商务服务业、娱乐业外的企业 |
| 核心条款 | ① 研发费用未形成无形资产计入当期损益的，据实扣除后再按实际发生额的 **100%** 加计扣除；② 形成无形资产的，按无形资产成本的 **200%** 税前摊销；③ 不适用加计的活动：常规性升级、直接应用公开成果、商品化后的技术支持、重复或简单改变、市场调查/效率调查/管理研究、常规质量控制与维修维护、社会科学艺术人文研究；④ 委托境外研发费用按实际发生额 80% 计入，且不超过境内符合条件研发费用的三分之二；⑤ 采用“真实发生、自行判别、申报享受、相关资料留存备查”方式 |
| 合规要点 | ① 研发项目须有立项决议、研发人员工时、材料领用、费用分配等证据链；② 生产与研发共用设备、人员须合理分摊；③ 负面行业清单内企业不得享受，行业归类以主营业务为准；④ 加计扣除与高新认定、研发补贴的归集口径不同，需分别建账 |
| 信源 | 财政部 税务总局公告 2023 年第 7 号；中国政府网《研发费用税前加计扣除新政指引》 |
| 核验 | 2026-11-05 核验 100%/200%、负面行业清单与制度性安排 |

|---|---|

| 发文机关 | 财政部、税务总局 |
| 效力层级 | 部门规范性文件 |
| 公布/施行 | 2023 年发布，执行期 **2023-01-01 至 2027-12-31** |
| 时效性 | 现行有效（执行期内） |
| 适用范围 | 高新技术企业（含所属非法人分支机构）中的制造业一般纳税人 |
| 核心条款 | ① 允许按当期可抵扣进项税额加计 **5%** 抵减应纳增值税税额；② 加计抵减额不改变进项税额，不参与留抵退税计算；③ 抵减后仍有未抵减额可结转下期，执行期满未抵减完的停止抵减；④ 同时符合多项加计抵减政策的，只能选择一项 |
| 合规要点 | ① 前提是“高新资格 + 制造业一般纳税人”，两项缺一不可；② 出口货物劳务、跨境应税行为对应的进项不得计提加计抵减；③ 需单独核算加计抵减额的计提、抵减、结余 |
| 信源 | 财政部 税务总局公告 2023 年第 43 号 |

| 核心条款 | ① 国家鼓励的集成电路设计、装备、材料、封装、测试企业和软件企业，自获利年度起**第一年至第二年免征、第三年至第五年减半征收**（两免三减半）；② 国家鼓励的**重点**集成电路设计企业和软件企业，自获利年度起第一年至第五年免征、接续年度减按 **10%** 征收；③ 优惠期自获利年度起算，获利年度指应纳税所得额为正的年度；④ 清单管理，由发改委、工信部等部门确定并动态调整 |
| 合规要点 | ① 须进入鼓励清单，未入清单不得享受；② “获利年度”认定影响整个优惠期，亏损年度不计入；③ 软件产品增值税即征即退与所得税优惠可叠加，但退税收入需计入应税收入；④ 研发人员、研发费用占比等条件须持续满足 |
| 信源 | 财政部 税务总局 发展改革委 工信部公告 2020 年第 45 号 |
| 核验 | 2026-11-05 核验文号与两免三减半、10% 规则 |

## 13.5 西部大开发企业所得税 15%

| 字段 | 内容 |
|---|---|
| 文号 | 财政部 税务总局 国家发展改革委公告 2020 年第 23 号 |
| 发文机关 | 财政部、税务总局、国家发展改革委 |
| 效力层级 | 部门规范性文件 |
| 公布/施行 | 2020 年发布，执行期 **2021-01-01 至 2030-12-31** |
| 时效性 | 现行有效（执行期内） |
| 适用范围 | 设在西部地区、以《西部地区鼓励类产业目录》项目为主营业务的企业 |
| 核心条款 | ① 主营业务收入占企业收入总额 **60% 以上**的，减按 **15%** 税率征收企业所得税；② 鼓励类产业目录由国家发展改革委发布并动态调整；③ 总分机构跨省区的，按分摊比例分别适用；④ 企业可在预缴环节自行享受，汇算清缴时按规定报送资料 |
| 合规要点 | ① 60% 收入占比按纳税年度计算，不能按单笔合同判断；② 目录版本会影响产业归类，需核对最新版；③ 与高新 15% 不能叠加，但可选择更有利政策 |
| 信源 | 财政部 税务总局 国家发展改革委公告 2020 年第 23 号 |
| 核验 | 2026-11-05 核验 15%、60% 与 2030-12-31 执行期 |

| 发文机关 | 财政部、税务总局 |
| 效力层级 | 部门规范性文件 |
| 公布/施行 | 2018-05-14 发布，自 **2018-01-01** 起执行 |
| 时效性 | 现行有效 |
| 适用范围 | 创业投资企业、有限合伙制创业投资企业法人合伙人、天使投资个人 |
| 核心条款 | ① 采取股权投资方式直接投资于**种子期、初创期科技型企业**满 **2 年**的，可按投资额的 **70%** 在股权持有满 2 年的当年抵扣应纳税所得额；② 当年不足抵扣的，可结转以后纳税年度抵扣；③ 天使投资个人转让该股权时，按投资额 70% 抵扣转让所得，当期不足抵扣可结转；④ 被投资企业须满足从业人数、资产总额、销售收入等初创科技型企业条件 |
| 合规要点 | ① 投资须直接投向符合条件的企业，通过多层架构间接投资不适用；② 满 2 年时点以实缴出资为准；③ 抵扣的是应纳税所得额，不是应纳税额；④ 需留存投资合同、实缴凭证、被投资企业资质材料 |
| 信源 | 财税〔2018〕55 号 |
| 核验 | 2026-11-05 核验 70%、2 年与适用主体 |

| 核心条款 | ① 按《资源综合利用产品和劳务增值税优惠目录》确定退税比例（30%–100%）；② 须取得相关资质、符合环保要求，并单独核算综合利用产品销售额与应纳税额；③ 未单独核算的不得享受；④ 退税款项不征收企业所得税，但对应收入须计入收入总额 |

| 信源 | 财政部 税务总局公告 2021 年第 40 号及目录 |

| 时效性 | 现行有效 |
| 适用范围 | 居民企业技术转让所得 |
| 核心条款 | ① 一个纳税年度内，技术转让所得不超过 **500 万元**的部分**免征**企业所得税；② 超过 500 万元的部分**减半**征收；③ 技术转让须经省级以上科技部门认定登记；④ 技术转让所得＝技术转让收入−技术转让成本−相关税费；⑤ 5 年内（含）技术转让所得应合并计算 |

## 13.9 广告费和业务宣传费税前扣除（30% 档延续）

| 字段 | 内容 |
|---|---|
| 文号 | 财政部 税务总局公告 2025 年第 16 号 |
| 发文机关 | 财政部、税务总局 |
| 效力层级 | 部门规范性文件 |
| 公布/施行 | 2025 年发布，政策延续执行至 **2027-12-31** |
| 时效性 | 现行有效（执行期内） |
| 适用范围 | 化妆品制造或销售、医药制造、饮料制造（不含酒类制造）企业 |
| 核心条款 | ① 符合条件的广告费和业务宣传费支出，不超过当年销售（营业）收入 **30%** 的部分准予扣除；② 超过部分准予在以后纳税年度**结转扣除**；③ 烟草企业的烟草广告费和业务宣传费支出，一律不得扣除；④ 其余行业一般按 15% 扣除 |
| 合规要点 | ① 30% 档仅限三类行业，需以主营业务判定；② 广宣费须取得合规发票且与生产经营相关；③ 赞助支出、与销售无关的推广费不得按广宣费扣除；④ 结转扣除需建立台账，避免重复扣除 |
| 信源 | 财政部 税务总局公告 2025 年第 16 号；国家税务总局《中国税务年度报告（2025）》 |
| 核验 | 2026-11-05 核验文号、30% 与 2027-12-31 |
