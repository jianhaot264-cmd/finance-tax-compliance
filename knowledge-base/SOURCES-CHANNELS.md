## 二、核验 SOP（每条入库必走）

1. **定文号**：先确定文件全称与文号（主席令/国务院令/部令/公告年第号）。
2. **找原文**：优先 A 级渠道；联合发文以主办部委或国务院文件库为准。
3. **看时效**：确认“现行有效 / 已废止 / 修订中 / 草案”，并记录**施行日期**而非仅公布日期。
4. **抓硬指标**：金额门槛、比例、期限、人数、税率必须逐字核对，禁止凭印象填写。
5. **查落地**：地方文件是否另有实施细则、基数、费率、申报期限。
6. **双源交叉**：至少 2 个独立来源一致（如税务总局库 + 中国政府网；或官方原文 + 官方解读）。
7. **标注不确定性**：无法确认的字段写“待核验/以原文为准”，不得用推测补齐。
8. **留痕**：记录信源名称、链接、核验日期；知识库每次更新写版本日志。

### 判定规则

- 只有 1 个来源 → 标“待核验”，不作为智能体确定结论。
- 官方原文与解读冲突 → 以原文为准，解读仅作理解参考。
- 新旧文件冲突 → 后法优于前法；特别规定优于一般规定；上位法优于下位法。
- 草案/征求意见稿 → 标“草案阶段”，禁止表述为“现行规定”。

## 四、检索技巧（提高命中率）

1. **文号精确检索**：如 `财政部 税务总局公告2023年第7号`，比关键词更准。
2. **site 限定**：`site:chinatax.gov.cn 平台 涉税信息 报送`；`site:gd.gov.cn 社保 基数`。
3. **“政策解读”反查**：先读答记者问，再回到原文核对硬指标。
4. **年度报告/立法计划**：用于判断“某法是否已出台”“今年是否修订”，比零散新闻可靠。
5. **地方落地**：国家文件 + `广东省 + 文件名`；社保类再加地市名（广州/深圳/东莞）。
6. **旧文核对**：搜索“文件名 + 废止/修订”，确认是否被新公告替代。
7. **数字复核**：所有金额、比例、期限至少用两个来源比对，避免“记忆型错误”。

## 六、质量标签（写入知识库字段）

| 标签 | 含义 | 智能体处理 |
|---|---|---|
| 已核验 | 双源交叉，硬指标一致 | 可作为确定结论引用 |
| 待核验 | 仅单一来源或关键字段缺失 | 必须提示“以原文为准”，不得作为唯一依据 |
| 草案阶段 | 征求意见稿/立法计划项目 | 禁止表述为现行规定 |
| 已到期 | 优惠执行期结束且无延续文件 | 明确提示已到期，不套用旧比例 |
| 地方口径 | 省/市执行口径 | 标注地域，不外推全国 |

| 官网双源 | 人大网/政府网/财政部/总局/司法部/湖北省财政厅/12366 | 沿革与现行执行口径确认 | 最终裁定依据 |

**实测结论（写入 `23-23.14`、`24-24.4`）**：
1. 权威数据库的「现行有效」标签**不能单源采信**，本轮实测存在 1991 年规章仍标现行有效的版本噪声；
2. 引用核验工具「未命中静默丢弃」——征管法第八十八条首轮未命中、二次定向复核后正常命中，故**未命中 ≠ 条文不存在**，也 ≠ 已核验；
3. 法规归一法名含版本标签（如「2024修订」「2018修正」），须与官网沿革交叉后方可写入知识库；
4. 权威库只作第三源辅证与逐字原文来源，**不替代官网双源**。

**本轮方法论收获**：两处最有价值的发现（企税法实施条例版本、专项附加扣除法条 6 项 vs 现行 7 项）都来自「对已有结论做权威回库复检」，而不是「新增更多条目」。生产库的核心风险是**结论过期与法条原文被后续文件覆盖**，不是收录量。
