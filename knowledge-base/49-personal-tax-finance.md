# 49 · 个人与个体工商户财税（专项附加 / 经营所得 / 汇算 / 灵活就业）

> 定位：面向个人纳税人、个体工商户、自由职业与灵活就业者的高频财税规则。A 层条目可直接引用；B2 条目引用前按 `SOURCES-CHANNELS.md` 回查原文。
> 核验：2026-11-09 依据官方公报与部委公告编录。

## 49.1 个人所得税专项附加扣除七项标准（2023 年提标后现行）

| 字段 | 内容 |
|---|---|
| 文号 | 国发〔2023〕13 号（提标）+《个人所得税专项附加扣除暂行办法》（国发〔2018〕41 号）+ 国家税务总局公告 2023 年第 14 号（执行口径） |
| 发文机关 | 国务院；国家税务总局 |
| 效力层级 | 规范性文件（国务院通知 + 总局公告） |
| 公布/施行 | 2023-08-28 公布；提标部分自 2023-01-01 起实施 |
| 时效性 | 现行有效 |
| 适用范围 | 取得综合所得或经营所得的居民个人；七项扣除可叠加享受（符合条件时） |
| 核心条款 | 七项标准：①子女教育 2000 元/月/孩（父母各 50% 或一方 100%）；②3 岁以下婴幼儿照护 2000 元/月/孩（分摊同上）；③赡养老人 3000 元/月（独生子女全额；非独生兄弟姐妹分摊，每人≤1500 元/月）；④住房贷款利息 1000 元/月（首套，最长 240 个月）；⑤住房租金 1500/1100/800 元/月三档（按城市规模，与房贷利息不可同享）；⑥继续教育学历 400 元/月（最长 48 个月）、职业资格当年 3600 元定额；⑦大病医疗每年限额 80000 元内据实（个人负担超 15000 元部分，汇算时扣） |
| 合规要点 | ①七项中前三项 2023 年提标（1000→2000、2000→3000），旧口径作废；②住房贷款利息与住房租金**不可同时享受**；③大病医疗只能汇算清缴时扣，预扣预缴不扣；④扣缴义务人（单位）可按月预扣，也可年度汇算自行扣；⑤留存备查资料（协议、证明）自法定汇算期结束起留存 5 年 |
| 核验 | 2026-11-09 依据中国政府网国务院公报版与政策文件库版双源核验 |
| 信源 | https://www.gov.cn/gongbao/2023/issue_10706/202309/content_6904866.html ；https://www.gov.cn/zhengce/content/202308/content_6901206.htm |

## 49.2 综合所得汇算清缴（工资薪金 / 劳务 / 稿酬 / 特许权使用费）

| 字段 | 内容 |
|---|---|
| 文号 | 《个人所得税法》第十一条 +《个人所得税法实施条例》+ 国家税务总局历年汇算公告（如 2025 年第 2 号办理 2024 年度汇算） |
| 发文机关 | 全国人大常委会；国务院；国家税务总局 |
| 效力层级 | 法律 / 行政法规 / 年度规范性文件 |
| 公布/施行 | 年度汇算：次年 3 月 1 日至 6 月 30 日办理上一年度汇算 |
| 时效性 | 汇编·动态（年度公告逐年更新，引用时须用当年公告） |
| 适用范围 | 取得综合所得且符合汇算情形的居民个人（多处取得、有扣除未充分享受、年收入超 12 万且补税超 400 元等） |
| 核心条款 | 应退应补税额 = [(综合所得收入额 − 60000 − 三险一金 − 专项附加 − 其他扣除) × 预扣率 − 速算扣除数] − 已预缴税额；免于汇算情形：年收入≤12 万且补税≤400 元、多缴税、符合退税条件 |
| 合规要点 | ①3–6 月办理，逾期产生滞纳金（万分之五/日）；②「个人所得税 APP」可一键带入申报数据，但**须本人核对**（专项附加、已缴税额）；③有大病医疗、年金、个人养老金等扣除的务必汇算（预扣阶段没扣全）；④取得劳务报酬多处的，预扣率低于汇算税率，汇算大概率补税，提前预留资金 |
| 核验 | 2026-11-09 编录；年度公告请以税务总局当年发布为准 |
| 信源 | 国家税务总局政策法规库（个人所得税综合所得汇算清缴专栏，按年度检索）；https://www.gov.cn/gongbao/2023/issue_10706/202309/content_6904866.html （扣除标准衔接） |

## 49.3 全年一次性奖金单独计税（延续至 2027-12-31）

| 字段 | 内容 |
|---|---|
| 文号 | 财政部 税务总局公告 2023 年第 30 号（延续财税〔2018〕164 号政策） |
| 发文机关 | 财政部、国家税务总局 |
| 效力层级 | 部门规范性文件（公告） |
| 公布/施行 | 2023-08 发布；执行期至 2027-12-31 |
| 时效性 | 现行有效（**有到期日：2027-12-31**） |
| 适用范围 | 居民个人取得全年一次性奖金（年终奖）；一个纳税年度内**只允许采用一次**单独计税 |
| 核心条款 | 单独计税：以全年一次性奖金收入 ÷ 12 查月度税率表确定税率与速算扣除数，应纳税额 = 奖金全额 × 税率 − 速算扣除数；也可选择并入当年综合所得计税（二选一，可测算后择优） |
| 合规要点 | ①「单独计税」不等于永远划算：低收入人群并入综合所得可能更省税，**发放前用两种方式测算择优**；②一年只能用一次，多处取得年终奖只能选一处；③2027-12-31 到期后是否延续以官方公告为准，不得默认延续，企业应在 2027 年第四季度**提前预警**测算两种情形；④季度奖、半年奖一律并入当期工资薪金计税，不适用单独计税 |
| 核验 | 2026-11-09 编录（政策内容与财税〔2018〕164 号一致，执行期由 2023 年第 30 号延至 2027-12-31） |
| 信源 | 国家税务总局政策法规库（财政部 税务总局公告 2023 年第 30 号，文号检索直达）；https://www.gov.cn/gongbao/2023/issue_10706/202309/content_6904866.html （同期个税优惠口径衔接） |

## 49.4 经营所得五级超额累进税率与汇算

| 字段 | 内容 |
|---|---|
| 文号 | 《个人所得税法》第三条、第六条、附表二（经营所得适用税率表） |
| 发文机关 | 全国人大常委会 |
| 效力层级 | 法律 |
| 公布/施行 | 2018-08-31 第七次修正，2019-01-01 施行 |
| 时效性 | 现行有效 |
| 适用范围 | 个体工商户业主、个人独资企业投资人、合伙企业个人合伙人、承包承租经营者、个人从事其他生产经营取得的所得 |
| 核心条款 | 五级超额累进：≤3 万 5%；3 万–9 万 10%（速算 1500）；9 万–30 万 20%（速算 10500）；30 万–50 万 30%（速算 40500）；>50 万 35%（速算 65500）。应纳税所得额 = 收入总额 − 成本费用损失 − 6 万/年 − 专项扣除 − 专项附加 − 其他扣除（业主本人费用扣除） |
| 合规要点 | ①经营所得**不并入综合所得**，单独计税、次年 3 月 31 日前汇算；②两处以上经营所得需合并汇算；③亏损可向以后 5 年结转弥补；④业主本人的工资不得税前扣除（按 6 万/年费用扣除），家属工资按实际合理发放列支；⑤优惠叠加：个体户减半征收等政策见 15-15.6、06 系列条目 |
| 核验 | 2026-11-09 编录（税率表为个税法附表二法定内容） |
| 信源 | 中国人大网（个人所得税法 2018 年修正文本）；国家税务总局政策法规库（经营所得申报表 A 表/B 表填报说明） |

## 49.5 个体工商户征收方式：查账征收与核定征收

| 字段 | 内容 |
|---|---|
| 文号 | 《个体工商户税收定期定额征收管理办法》（国家税务总局令第 16 号）；国税发〔2008〕30 号（企业所得税核定办法参照原则）；国家税务总局公告 2021 年第 41 号（权益性投资一律查账） |
| 发文机关 | 国家税务总局 |
| 效力层级 | 部门规章 / 规范性文件 |
| 公布/施行 | 16 号令 2007-01-01 施行；2021 年第 41 号公告 2022-01-01 施行 |
| 时效性 | 现行有效 |
| 适用范围 | 个体工商户、个人独资与合伙企业（个税口径） |
| 核心条款 | 查账征收（账簿健全、核算准确）按实际所得五级累进；定期定额（双定户）按核定的经营额与所得率征收；持有权益性投资的独资合伙企业（2022 起）**一律查账**，不得核定 |
| 合规要点 | ①建账是原则：达到《个体工商户建账管理暂行办法》标准的必须建账，达不到可经批准不建账但需收支凭证粘贴簿；②核定≠包税，定额会按年核定调整；③连续 12 个月开票额超 500 万强制转一般纳税人（增值税口径）；④「核定征收解决成本票」类操作属高风险筹划，票、账、实不符会被调整并处罚，见 47 红线条目 |
| 核验 | 2026-11-09 编录；各地核定所得率与起征点执行口径差异大，以主管税务机关为准 |
| 信源 | 国家税务总局政策法规库（国家税务总局令第 16 号、2021 年第 41 号公告，文号检索）；12366 纳税服务平台（个体工商户征收方式专栏） |

## 49.6 灵活就业人员与自由职业者的社保与个税要点

| 字段 | 内容 |
|---|---|
| 文号 | 《社会保险法》第十条/第二十三条（灵活就业人员可参加职工养老、职工医保）；国办发〔2021〕〔灵活就业支持政策〕；平台从业者口径见 11 系列条目 |
| 发文机关 | 全国人大常委会；国务院办公厅 |
| 效力层级 | 法律 / 规范性文件 |
| 公布/施行 | 社会保险法 2011-07-01 施行（2018 修正） |
| 时效性 | 汇编·动态（缴费基数与比例逐年由属地公布） |
| 适用范围 | 无雇工的个体工商户、未在单位参保的非全日制从业人员、自由职业者、平台从业人员 |
| 核心条款 | ①可个人身份参加职工基本养老与职工基本医疗保险（户籍地或就业地，属地开放）；②缴费基数一般在当地上年度社平工资 60%–300% 档次自选，比例养老约 20%（12% 入统筹 + 8% 入个人账户，属地口径）；③个税：劳务报酬按 20%–40% 预扣、汇算并入综合所得 3%–45%；经营所得按 49.4 五级累进 |
| 合规要点 | ①灵活就业社保**只含养老与医保两险**，不含失业工伤生育（单位职工才是五险）；②社保缴费可在个税税前扣除（专项扣除），记得在 APP 填报；③多地重复参保无效，重复时段不重复计待遇；④按次收入（劳务报酬）预扣率高、汇算常退税，每年 3–6 月务必汇算；⑤广州等城市缴费基数上下限以当年人社部门公告为准（如 2026 年度口径见 05/30 系列条目） |
| 核验 | 2026-11-09 编录；缴费基数与办理渠道每年变动，以参保地人社/医保部门公告为准 |
| 信源 | 中国人大网（社会保险法文本）；国家税务总局政策法规库（灵活就业人员社保费缴纳与个税扣除问答） |
