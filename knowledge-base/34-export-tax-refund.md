## 34.2 生产企业免抵退税：计算逻辑与申报期限

| 字段 | 内容 |
|---|---|
| 文号 | 财税〔2012〕39 号；《国家税务总局关于发布〈出口货物劳务增值税和消费税管理办法〉的公告》（**国家税务总局公告 2012 年第 24 号**）第四条 |
| 发文机关 | 国家税务总局 |
| 效力层级 | 部门规范性文件 |
| 公布/施行 | 2012-07-01 起 |
| 时效性 | 现行有效 |
| 适用范围 | 具有生产能力（含加工修理修配能力）的出口企业 |
| 核心条款 | ① 免抵退税＝**免征出口环节增值税**，对应进项税额抵减内销应纳税额，未抵减完的部分予以退还；② 当期应纳税额＝当期销项税额－（当期进项税额－当期不得免征和抵扣税额）；③ **不得免征和抵扣税额**＝当期出口货物离岸价×外汇人民币折合率×（出口货物征税率－出口退税率）；④ 申报：当月出口货物须在**次月增值税纳税申报期内**办理纳税申报及免抵退税申报；⑤ 收齐凭证申报期为出口之日次月起至**次年 4 月 30 日前**的各增值税纳税申报期，逾期不得申报免抵退税 |
| 合规要点 | ① 征退税率差需做**进项转出**，漏做会导致多抵进项；② 逾期即失去退税资格（可转免税或视同内销），时间节点必须进台账；③ 免抵退税额与留抵税额不得重复计算（见 34.6）；④ 生产企业出口非自产货物须符合「视同自产」条件，否则按外贸企业办法或征税 |
| 信源 | ① https://tianjin.chinatax.gov.cn/11200000000/0600/060007/06000702/20191111112942322.shtml（天津市税务局：免抵退税申报指引，引 24 号公告第四条申报期限与资料）<br>② https://www.chinatax.gov.cn/chinatax/n810219/n810744/n1671176/n2884609/c2884646/5116257/files/%E3%80%8A%E2%80%9C%E8%B5%B0%E5%87%BA%E5%8E%BB%E2%80%9D%E7%A8%8E%E6%94%B6%E6%8C%87%E5%BC%95%E3%80%8B%EF%BC%882024%E5%B9%B4%E4%BF%AE%E8%AE%A2%E7%89%88%EF%BC%89.pdf（总局《"走出去"税收指引》：免抵退税申报程序与留存单证要求） |

## 34.3 外贸企业免退税：免征增值税、退还进项

| 字段 | 内容 |
|---|---|
| 文号 | 财税〔2012〕39 号 第一条第（二）项；国家税务总局公告 2012 年第 24 号 第五条 |
| 发文机关 | 财政部、国家税务总局 |
| 效力层级 | 部门规范性文件 |
| 公布/施行 | 2012-07-01 起 |
| 时效性 | 现行有效 |
| 适用范围 | 不具有生产能力的外贸企业或其他单位（自营或委托出口） |
| 核心条款 | ① 外贸企业出口货物、劳务**免征增值税**，相应的**进项税额予以退还**；② 出口货物如属消费税应税消费品，同时退还前一环节已征消费税；③ 申报需提供：出口货物报关单、增值税专用发票（抵扣联）或海关进口增值税专用缴款书、委托出口的代理出口货物证明、应税消费品的消费税专用缴款书或分割单等；④ 退税额按**购进货物增值税专用发票注明的金额×退税率**计算（不同于生产企业的免抵退） |
| 合规要点 | ① 外贸企业是「免退」不是「免抵退」，**不参与内销抵扣**；② 购进出口货物的专票必须与报关单商品名称、数量匹配，否则不予退税；③ 委托出口须取得受托方主管税务机关签发的**代理出口货物证明**；④ 综试区内的跨境电商零售出口另有「无票免税」政策（见 34.5），不能用外贸企业免退税套用 |

## 34.4 单证备案：15 日内、三类单证、保存 5 年

| 字段 | 内容 |
|---|---|
| 文号 | 《国家税务总局关于进一步便利出口退税办理 促进外贸平稳发展有关事项的公告》（**国家税务总局公告 2022 年第 9 号**）第二条 |
| 发文机关 | 国家税务总局 |
| 效力层级 | 部门规范性文件 |
| 公布/施行 | 2022-05-01 起（公告第一条至第三条） |
| 时效性 | 现行有效 |
| 适用范围 | 申报出口退（免）税的出口企业（零税率跨境应税行为不实行备案单证管理） |
| 核心条款 | ① 应在申报出口退（免）税后 **15 日内**收齐并留存三类单证：**购销合同**（出口合同、外贸综合服务合同、购货合同等）、**运输单据**（海运提单、航空运单、铁路运单、承运单据、邮政收据，及国内运输发票、国际货代服务费发票）、**委托报关单据**（委托报关协议、代理报关服务费发票）；② 按申报时间顺序制作**备案单证目录**，注明存放方式；③ 保存期 **5 年**，不得擅自损毁；④ 可自行选择纸质化、影像化或数字化方式留存；⑤ **未按规定备案的出口货物不得申报退（免）税，适用免税政策**；已申报的应以负数冲减；⑥ 单证虚假或内容不实的，对应货物适用**征税**政策，属偷骗税按相关规定处理 |

## 34.6 免抵退税与留抵退税的顺序（不得重复）

| 字段 | 内容 |
|---|---|
| 文号 | 《财政部 税务总局关于进一步加大增值税期末留抵退税政策实施力度的公告》（**财政部 税务总局公告 2022 年第 14 号**）第九条；《增值税法实施条例》第四十七条 |
| 发文机关 | 财政部、税务总局；国务院 |
| 效力层级 | 部门规范性文件 + 行政法规 |
| 公布/施行 | 2022 年第 14 号 2022-04-01 起；实施条例 2026-01-01 |
| 时效性 | 现行有效 |
| 适用范围 | 既适用免抵退税又适用留抵退税的纳税人 |
| 核心条款 | ① 纳税人出口货物劳务、发生跨境应税行为适用**免抵退税**办法的，**应先办理免抵退税**；② 免抵退税办理后仍有留抵税额的，可按规定申请留抵退税；③ 同一笔进项税额不得既计算免抵退税额又申请留抵退税 |
| 合规要点 | ① 顺序颠倒会导致重复退税，属高风险事项；② 申报表逻辑：先完成免抵退申报，再以剩余留抵计算留抵退税；③ 2026 年起留抵退税仍以财政部/总局公告为准，实施条例未直接规定留抵退税条件 |
| 信源 | ① https://yunnan.chinatax.gov.cn/art/2022/5/18/art_3855_61521.html（云南省税务局：明确「既适用免抵退税又适用留抵退税，应先办理免抵退税」并引 2022 年第 14 号第九条）<br>② http://beijing.chinatax.gov.cn/bjswj/c104560/202602/4cf701ebd7ac4cbfaed2769ab3dd025a.shtml（实施条例第四十七条：免抵退税与免退税办法的法定表述） |

## 34.7 出口退税高频风险（骗税、单证不实、逾期、分类下调）

| 字段 | 内容 |
|---|---|
| 文号 | 《税收征收管理法》第六十六条；财税〔2012〕39 号 第七条；国家税务总局公告 2022 年第 9 号 第二条；出口企业分类管理办法（总局公告 2016 年第 46 号及后续修订） |
| 发文机关 | 全国人大常委会；财政部、税务总局 |
| 效力层级 | 法律 + 规范性文件 |
| 公布/施行 | 各按原施行日 |
| 时效性 | 现行有效 |
| 适用范围 | 全部出口企业 |
| 核心条款 | ① 以假报出口或其他欺骗手段骗取国家出口退税款的，由税务机关**追缴**其骗取的退税款，并处骗取税款 **1 倍以上 5 倍以下**罚款；构成犯罪的依法追究刑事责任；② 备案单证虚假或内容不实的，对应货物适用**征税**政策；③ 逾期未申报（超过次年 4 月 30 日）不得申报免抵退税；④ 未按规定收集、装订、存放备案单证的，一、二类企业降为三类；拒绝提供备案单证的，降为四类 |
| 合规要点 | ① 「四自三不见」（自带客户、自带货源、自带汇票、自行报关；不见出口产品、不见供货货主、不见外商）是骗税典型特征，触碰即高风险；② 供货方走逃失联会导致其发票被列为异常凭证，进而影响退税，须做供应商尽调；③ 退税速度与分类等级挂钩，日常单证管理直接影响现金流；④ 被认定骗税的，除补税罚款外还可能被停止出口退税权 |
