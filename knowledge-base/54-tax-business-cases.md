## 54.1 增值税一般计税、进项抵扣与进项转出

| 确认与计量要求 | 按现行增值税会计处理规定（文号以财政部会计司现行目录为准），采购时按适用税率计算的增值税确认为进项税额，销售时确认销项税额；不得抵扣情形按适用税率计算的增值税转入相关成本费用；月末将应交未交增值税结转至未交增值税。小企业会计准则下明细科目设置与结转按现行规定简化（以官方原文为准）。 |
| 会计分录与处理流程 | 借：原材料/库存商品/管理费用、应交税费——应交增值税（进项税额，按适用税率计算）；贷：银行存款/应付账款；销售：借：银行存款/应收账款；贷：主营业务收入、应交税费——应交增值税（销项税额，按适用税率计算）；进项转出：借：主营业务成本/待处理财产损溢；贷：应交税费——应交增值税（进项税额转出）；月末：借：应交税费——应交增值税（转出未交增值税）；贷：应交税费——未交增值税；缴纳：借：应交税费——未交增值税；贷：银行存款。①按发票与单据登记进销项台账；②月末核对抵扣、计算转出与应交额；③按 CAS30 列报。 |
| 税务处理规定 | 一般计税应纳税额为销项减进项；进项须取得合规扣税凭证、用于应税项目方可抵扣，用于免税/简易计税/集体福利/个人消费等的按现行规定转出。 |

| 依据层级 | 法律＞行政法规＞部门规章＞规范性文件＞具体准则（部门规范性文件）；上位法优先，本项以法律、行政法规为主，规范性文件为辅 |
| 生效状态 | 现行有效；《增值税法》及实施条例 2026-01-01 施行，原暂行条例口径不再作为独立依据 |
| 适用边界 | 一般纳税人（小规模纳税人不适用进项抵扣）；全国口径，广东等地方口径回查；例外：免税项目、集体福利、非正常损失对应进项；红线：虚开/失控发票、三流不一致、不得抵扣项目未转出 |

| 会计分录与处理流程 | 借：银行存款/应收账款；贷：主营业务收入、应交税费——应交增值税（按适用税率计算）；减免：借：应交税费——应交增值税；贷：其他收益/营业外收入（按现行规定，以官方原文为准）；缴纳：借：应交税费——应交增值税；贷：银行存款。①按开票与收款单据登记台账；②期末按实际享受减免调整计提；③留存依据、按 CAS30 列报。 |

| 依据层级 | 法律＞行政法规＞部门规章＞规范性文件＞具体准则（部门规范性文件）；上位法优先，本项以法律、行政法规为主，规范性文件为辅 |
| 生效状态 | 现行有效；《增值税法》2026-01-01 施行；2023 年第 12 号优惠至 2027-12-31，到期回查 |
| 适用边界 | 小规模纳税人及符合条件小微企业；全国口径，广东等地方口径回查；免税/减征按库内 31.4 条目判断：先看月 10 万/30 万免征、再看六税两费减半；主体条件与销售额口径以财政部 税务总局公告 2023 年第 12 号第二条、第五条为准；优惠至 2027-12-31，不默认延续；红线：以核定征收解决成本票、身份混用、虚开 |

## 54.4 企业所得税预缴、汇算与递延所得税

| 字段 | 内容 |
|---|---|
| 适用范围 | 所得税费用的确认、预缴与汇算清缴账务及递延所得税确认。 |
| 确认与计量要求 | 按 CAS18 采用资产负债表债务法，当期所得税按适用税率计算的应缴额确认为负债与所得税费用；递延所得税按资产、负债账面价值与计税基础的暂时性差异，以预期适用税率计算，分别确认递延所得税负债及递延所得税资产（以很可能取得的应纳税所得额为限，以官方原文为准），对应计入所得税费用或其他综合收益。小企业会计准则采用应付税款法，不确认递延所得税。 |
| 会计分录与处理流程 | 借：所得税费用——当期所得税费用；贷：应交税费——应交所得税（按适用税率计算）；预缴：借：应交税费——应交所得税；贷：银行存款；递延：借：递延所得税资产；贷：所得税费用——递延所得税费用（或其他综合收益）；借：所得税费用——递延所得税费用；贷：递延所得税负债。①按期间编制所得税计算表与暂时性差异台账；②期末复核递延所得税资产可收回性；③汇算后按审批调整、按 CAS30 列报。 |
| 税务处理规定 | 按季（月）预缴、年度汇算清缴，以利润总额为基础按现行规定纳税调整后计税；税率及小微优惠、亏损弥补年限按现行规定（以官方原文为准）；按规定报送申报表并留存备查资料。 |
| 税会差异提示 | 时间性差异按当期差额调增/调减并后续转回，永久性差异仅单向调增或调减；设纳税调整台账，递延所得税确认按 CAS18 判断。 |
| 参照依据与关键条款 | 《企业所得税法》及实施条例（国务院令第512号）：应纳税所得额、税率与预缴汇算法定框架；《税收征收管理法》及实施细则（国务院令第362号）：纳税申报与期限；国家税务总局公告2018年第28号：税前扣除凭证（具体条款以原文为准） |
| 依据层级 | 法律＞行政法规＞部门规章＞规范性文件＞具体准则（部门规范性文件）；上位法优先，本项以法律、行政法规为主 |
| 生效状态 | 现行有效；企税条例 2024-12-06 修订、2025-01-20 施行 |
| 适用边界 | 执行企业会计准则/小企业准则的一般·小规模纳税人、查账征收为主；全国口径，广东等地方口径回查；区域性优惠：南沙 15% 执行至 2026-12-31，截至 2026-11-09 未见官方延续文件，不得按 15% 测算 2027 年度（P-24 隔离项，见 41.1）；前海 15% 已由财税〔2026〕3 号延至 2027-12-31；红线：白条入账、以核定征收替代成本凭证、逾期申报 |

## 54.5 个人所得税代扣代缴与六税两费/小微优惠

| 字段 | 内容 |
|---|---|
| 适用范围 | 支付薪酬、劳务报酬、股息等时代扣代缴，以及现行减免优惠下的税费计提。 |
| 确认与计量要求 | 代扣款项属企业承担的代扣负债，按 CAS9 于发放时自应付职工薪酬扣减并确认为应交税费，实际缴纳时冲减，不进损益；享受现行减免优惠的按实际应缴额计提，减免部分按现行会计处理规定处理（科目以官方原文为准）。小企业会计准则按实际代扣代缴额挂账，简化处理。 |
| 会计分录与处理流程 | 借：应付职工薪酬；贷：银行存款、应交税费——应交个人所得税（代扣）；缴纳：借：应交税费——应交个人所得税；贷：银行存款；减免：借：税金及附加（按实际应缴额、按适用税率计算）；贷：应交税费——应交××税。①按工资表与扣缴申报表登记代扣台账；②发放与缴纳逐笔核对；③期末与薪酬、应交税费明细账核对并按 CAS30 列报。 |
| 税务处理规定 | 工资薪金、劳务报酬等按现行规定代扣代缴个税并申报；全年一次性奖金单独计税按财政部 税务总局公告 2023 年第 30 号（至 2027-12-31）；专项附加扣除与小微、六税两费优惠按现行规定。 |
