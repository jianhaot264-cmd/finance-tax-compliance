> 覆盖：救济路径选择、清税前置、申请与审理期限、诉讼期限与举证、听证权、修订草案动态。

| 发文机关 | 全国人大常委会 |
| 效力层级 | 法律 |
| 公布/施行 | 征管法现行版本（2015 修正）；行政复议法 2024-01-01；行政诉讼法 2017 修正 |

| 核心条款 | ① **纳税争议**（征税行为：确认纳税主体、征税对象、征税范围、减免退税、适用税率、计税依据、纳税环节、纳税期限、征收方式等）→ **必须复议前置**，且须先清税或提供担保；② 对**处罚决定、强制执行措施、税收保全措施**不服 → **可复议也可直接诉讼**（选择制）；③ 对其他税务行政行为不服 → 一般可复议或诉讼；④ 复议机关为**上一级税务机关**（税务系统垂直复议） |

## 36.2 清税前置：纳税争议必须先缴税或提供担保

| 字段 | 内容 |
|---|---|
| 文号 | 《税收征收管理法》**第八十八条**；《税务行政复议规则》（**国家税务总局令第 21 号**）第三十三条 |
| 发文机关 | 全国人大常委会；国家税务总局 |
| 效力层级 | 法律 + 部门规章 |
| 公布/施行 | 征管法 2015 修正版；21 号令 2010-02-10 公布，经 2015-12-28、2018-06-15 两次修正 |
| 时效性 | **现行有效**（草案拟取消，但未生效） |
| 适用范围 | 与税务机关发生纳税争议的纳税人、扣缴义务人、纳税担保人 |
| 核心条款 | ① 发生纳税争议时，必须先依照税务机关的纳税决定**缴纳或解缴税款及滞纳金，或者提供相应担保**，然后才可以依法申请行政复议；② 申请期限自**缴清税款和滞纳金之日**或**担保被确认之日**起 60 日内计算（不是从知道行政行为之日起算）；③ 对复议决定不服的，可依法向人民法院起诉（起诉前仍须清税） |
| 合规要点 | ① 无力清税时可选择**提供担保**（保证、抵押、质押），不必全额现金；② 期限起算点是「缴清/担保确认日」，容易误算；③ 实务中「先复议后诉讼」的双重前置仍适用，**不要直接起诉纳税争议**；④ 草案若通过将取消复议前清税，需持续跟踪（见 36.8） |
| 信源 | ① https://tianjin.chinatax.gov.cn/11200000000/8000/800008/80000814/20190909104320622.shtml（天津市税务局：清税前置与 60 日起算）<br>② https://hunan.chinatax.gov.cn/ld/county/20190719084881/show/20191029189801（湖南省税务局：缴清或担保确认之日起 60 日） |
| 核验 | 2026-11-07 联网核验：清税前置依据与期限起算双源一致 |

## 36.3 复议申请期限与管辖（60 日 / 上一级税务机关）

| 字段 | 内容 |
|---|---|
| 文号 | 《行政复议法》第二十条；《税务行政复议规则》（总局令第 21 号）第三十二条、第三十三条 |
| 发文机关 | 全国人大常委会；国家税务总局 |
| 效力层级 | 法律 + 部门规章 |
| 公布/施行 | 行政复议法 2024-01-01；21 号令现行修正版 |
| 时效性 | 现行有效 |
| 适用范围 | 税务行政复议申请人 |
| 核心条款 | ① 申请人可自**知道税务机关作出具体行政行为之日起 60 日内**提出复议申请；② 因不可抗力或被申请人设置障碍等正当理由耽误期限的，期限自障碍消除之日起继续计算；③ 纳税争议按 36.2 的特殊起算点；④ 管辖：向**作出具体行政行为的税务机关的上一级税务机关**申请（税务系统保留垂直复议职责）；⑤ 申请可书面或口头，可通过电子税务局在线提交 |
| 合规要点 | ① 60 日是**不变期间**（除法定顺延），逾期丧失复议权；② 对「不予受理」决定不服，可向上级税务机关申诉或直接起诉该不予受理行为；③ 复议申请书中须写明复议请求、事实理由、证据，并附纳税决定文书与清税/担保凭证 |
| 信源 | ① https://tianjin.chinatax.gov.cn/11200000000/8000/800008/80000814/20190909104320622.shtml（天津市税务局：60 日与上一级管辖）<br>② https://xizang.chinatax.gov.cn/art/2025/9/19/art_5706_525733.html（西藏自治区税务局：救济渠道公示，含复议期限与审理期限） |
| 核验 | 2026-11-07 联网核验：期限与管辖规则双源一致 |

## 36.4 复议审理期限（60 日 + 可延 30 日 / 简易 30 日）

| 字段 | 内容 |
|---|---|
| 文号 | 《行政复议法》（2023 修订）第五十六条、第五十七条；《税务行政复议规则》 |
| 发文机关 | 全国人大常委会；国家税务总局 |
| 效力层级 | 法律 + 部门规章 |
| 公布/施行 | 2024-01-01 |
| 时效性 | 现行有效 |
| 适用范围 | 税务行政复议机关 |
| 核心条款 | ① 复议机关应自**受理申请之日起 60 日内**作出行政复议决定；法律规定少于 60 日的除外；② 情况复杂不能按期作出的，经复议机构负责人批准可适当延期，并书面告知当事人，**延长期限最多不超过 30 日**；③ 适用**简易程序**审理的，应自受理之日起 **30 日内**作出决定；④ 撤回申请应于复议期间届满前办结 |
| 合规要点 | ① 60 日 + 30 日是复议机关的审理期限，不是申请人的准备期；② 简易程序适用于事实清楚、争议不大的案件，30 日结案对企业现金流更友好；③ 复议期间可申请**调解/和解**（2023 修订强化），达成后可提前结案；④ 复议机关逾期不作决定，申请人可在复议期满之日起 15 日内起诉（见 36.5） |
| 信源 | ① https://xizang.chinatax.gov.cn/art/2025/9/19/art_5706_525733.html（西藏自治区税务局：60 日、延 30 日、简易 30 日）<br>② https://hunan.chinatax.gov.cn/ld/county/20190719084881/show/20191029189801（湖南省税务局：审理期限与延期规则） |
| 核验 | 2026-11-07 联网核验：三类期限（60/90/30）双源一致 |

## 36.5 行政诉讼期限（15 日 / 6 个月）与举证责任

| 字段 | 内容 |
|---|---|
| 文号 | 《税收征收管理法》第八十八条；《行政诉讼法》第四十五条、第四十六条、第三十四条 |
| 发文机关 | 全国人大常委会 |
| 效力层级 | 法律 |
| 公布/施行 | 行政诉讼法 2017 修正 |
| 时效性 | 现行有效 |
| 适用范围 | 税务行政诉讼当事人 |
| 核心条款 | ① 不服复议决定的，自**收到复议决定书之日起 15 日内**向人民法院起诉；② 复议机关**逾期不作决定**的，可在复议期满之日起 **15 日内**起诉；③ **直接起诉**（非纳税争议）的，应自知道或应当知道行政行为之日起 **6 个月内**提出；④ 举证责任：**被告（税务机关）对作出的行政行为负举证责任**，应提供作出该行为的证据和所依据的规范性文件 |
| 合规要点 | ① 15 日极短，收到复议决定当天就应启动起诉准备；② 纳税争议起诉前仍须清税（现行法），否则法院可能不予立案；③ 税务机关不得在诉讼中自行向原告和证人收集证据（事后补证受限），这是纳税人的重要抗辩点；④ 起诉期限与复议期限是两套时钟，勿混 |
| 信源 | ① https://tianjin.chinatax.gov.cn/11200000000/8000/800008/80000814/20190909104320622.shtml（天津市税务局：15 日与 6 个月两类期限）<br>② https://hunan.chinatax.gov.cn/ld/county/20190719084881/show/20191029189801（湖南省税务局：逾期不作决定的起诉期限） |
| 核验 | 2026-11-07 联网核验：15 日/6 个月与逾期起诉规则双源一致 |

## 36.6 处罚与强制措施：可复议可诉讼（选择制）

| 字段 | 内容 |
|---|---|
| 文号 | 《税收征收管理法》第八十八条第二款；《行政强制法》第八条 |
| 发文机关 | 全国人大常委会 |
| 效力层级 | 法律 |
| 公布/施行 | 征管法 2015 修正；行政强制法 2012-01-01 |
| 时效性 | 现行有效 |
| 适用范围 | 对处罚决定、强制执行措施、税收保全措施不服的当事人 |
| 核心条款 | ① 对税务机关的**处罚决定、强制执行措施或者税收保全措施**不服的，可以依法申请行政复议，**也可以依法直接向人民法院起诉**（无需先复议）；② 直接起诉期限为知道或应当知道之日起 **6 个月**；③ 申请复议的，复议期限 60 日，对复议决定不服再 15 日内起诉；④ 强制执行/保全造成损失且行为违法的，可依法申请**行政赔偿** |
| 合规要点 | ① 选择制意味着可以「先诉讼、跳过复议」，但纳税争议不适用；② 处罚与补税常在同一份决定书中，须**拆分争议性质**分别走路径；③ 申请停止执行需提供担保，法院/复议机关裁量；④ 赔偿请求可与复议/诉讼一并提出，也可单独提出 |
| 信源 | ① https://tianjin.chinatax.gov.cn/11200000000/8000/800008/80000814/20190909104320622.shtml（天津市税务局：处罚/强制措施可复议可诉讼）<br>② https://hunan.chinatax.gov.cn/ld/county/20190719084881/show/20191029189801（湖南省税务局：两类救济方式并列） |
| 核验 | 2026-11-07 联网核验：选择制与直接起诉 6 个月期限双源一致 |

## 36.7 听证权：5 日内提出、按笔录决定

| 字段 | 内容 |
|---|---|
| 文号 | 《行政处罚法》（2021-01-22 修订，**2021-07-15 施行**）第六十三条、第六十四条、第六十五条 |
| 发文机关 | 全国人大常委会 |
| 效力层级 | 法律 |
| 公布/施行 | 2021-07-15 |
| 时效性 | 现行有效 |
| 适用范围 | 拟作出较大数额罚款、没收较大数额违法所得、降低资质等级、吊销许可证件、责令停产停业、责令关闭、限制从业等处罚的当事人 |
| 核心条款 | ① 行政机关拟作出上述处罚，应当告知当事人有要求听证的权利；② 当事人要求听证的，应当在行政机关告知后 **5 日内**提出（旧法「3 日」已废）；③ 行政机关应在举行听证 **7 日前**通知当事人及有关人员时间、地点；④ 听证应**制作笔录**，行政机关**根据听证笔录**作出决定；⑤ 听证费用由行政机关承担，当事人不承担 |
| 合规要点 | ① 5 日是极短的窗口，收到《税务行政处罚事项告知书》应立即决策；② 听证不是「求情会」，重点在事实、证据、法律适用与裁量；③ 笔录签字前务必核对，笔录是决定依据；④ 听证权放弃不影响后续复议/诉讼，但失去一次低成本纠错机会 |
| 信源 | ① http://www.npc.gov.cn/c2/c30834/202101/t20210122_309857.html（中国人大网：《行政处罚法》全文，第六十三至六十五条）<br>② https://www.mps.gov.cn:8090/n6557558/c7692710/content.html（公安部转载主席令第七十号全文，条文一致） |
