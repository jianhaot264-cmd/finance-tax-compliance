# 会计准则与税会差异（企业会计准则 / 小企业会计准则）

> 覆盖：制度体系选择、基本准则、收入准则、租赁准则、小企业会计准则、财务报表格式、税会差异与差错更正。
> 本文件为 **A 层**：每条 10 字段 + 至少 2 个官方信源 + 核验日期 2026-11-07。
> ⚠️ 会计口径与税务口径**不是一套规则**：会计确认不等于税前扣除，本文每条均标注税会差异要点。

## 38.3 收入准则（CAS 14）：控制权转移与五步法

| 字段 | 内容 |
|---|---|
| 文号 | 《企业会计准则第 14 号——收入》（**财会〔2017〕22 号**） |
| 发文机关 | 财政部 |
| 效力层级 | 部门规范性文件（具体准则） |
| 公布/施行 | 2017-07-05 印发；**分阶段施行**：境内外同时上市及境外上市并采用 IFRS/企业会计准则编制报表的企业 **2018-01-01**；其他境内上市企业 **2020-01-01**；执行企业会计准则的非上市企业 **2021-01-01**；允许提前执行 |
| 时效性 | 现行有效 |
| 适用范围 | 所有与客户之间的合同（排除租赁、保险合同、金融工具等由其他准则规范的合同） |
| 核心条款 | ① 收入确认核心：**在客户取得相关商品控制权时**确认收入（控制权＝能主导商品使用并从中获得几乎全部经济利益）；② 合同须同时满足五项条件：各方已批准并承诺履约、权利义务明确、支付条款明确、具有商业实质、对价很可能收回；③ 五步法：识别合同→识别履约义务→确定交易价格→分摊交易价格→履行履约义务时确认收入；④ 取代原 CAS14 收入与 CAS15 建造合同 |
| 合规要点 | ① 会计上按履约进度确认收入，**增值税/企业所得税纳税义务可能更早**（如先开票、预收款），形成时间性差异；② 合同负债（预收）与增值税纳税义务不同步，需分别台账；③ 可变对价、重大融资成分、质保义务的判断影响收入金额，进而影响税基；④ 建造合同并入收入准则后，完工百分比法判断更依赖「履约进度」证据 |
| 信源 | ① https://kjs.mof.gov.cn/zhengcefabu/201707/t20170719_2653110.htm（财政部会计司：财会〔2017〕22 号通知，含分阶段施行安排）<br>② https://kjs.mof.gov.cn/zt/kjzzss/kuaijizhunzeshishi/201709/t20170907_2694006.htm（财政部会计司：CAS 14 全文，第四、五条） |
| 核验 | 2026-11-07 联网核验：施行时间表与确认条件双源一致 |

## 38.4 租赁准则（CAS 21）：使用权资产与租赁负债

| 字段 | 内容 |
|---|---|
| 文号 | 《企业会计准则第 21 号——租赁》（**财会〔2018〕35 号**） |
| 发文机关 | 财政部 |
| 效力层级 | 部门规范性文件（具体准则） |
| 公布/施行 | 2018 年修订印发；**分阶段施行**：境内外同时上市及境外上市企业 2019-01-01；其他境内上市企业 2020-01-01；执行企业会计准则的非上市企业 **2021-01-01** |
| 时效性 | 现行有效 |
| 适用范围 | 执行企业会计准则的企业（小企业会计准则不适用本准则） |
| 核心条款 | ① 承租人不再区分经营租赁与融资租赁（短期租赁和低价值资产租赁可选择简化处理），统一确认**使用权资产**与**租赁负债**；② 租赁负债按租赁期开始日未支付租赁付款额的**现值**计量，折现率优先用租赁内含利率，无法确定的用增量借款利率；③ 使用权资产按成本初始计量，后续计提折旧并确认利息费用；④ 出租人仍区分融资租赁与经营租赁 |
| 合规要点 | ① 会计上确认使用权资产，**税务上仍按租金扣除**（企业所得税），形成「资产折旧+利息」与「租金」的差异，需纳税调整；② 增值税进项按租金发票抵扣，与会计费用口径不同；③ 短期租赁（≤12 个月）与低价值资产租赁可简化，但需一致应用；④ 租赁期判断（含续租选择权、终止选择权）影响负债金额，是审计重点 |
| 信源 | ① https://www.mof.gov.cn/gkml/caizhengwengao/wg201901/wg201905/201909/t20190912_3385305.htm（财政部：财会〔2019〕6 号，明确新租赁准则财会〔2018〕35 号及施行安排）<br>② https://kjs.mof.gov.cn/zhengcefabu/201707/t20170719_2653110.htm（财政部会计司：新收入准则通知，同为分阶段施行体系，用于对照） |
| 核验 | 2026-11-07 联网核验：文号、施行阶段与「小企业不适用」确认 |

## 38.5 小企业会计准则：简化处理与适用范围

| 字段 | 内容 |
|---|---|
| 文号 | 《小企业会计准则》（**财会〔2011〕17 号**） |
| 发文机关 | 财政部 |
| 效力层级 | 部门规范性文件 |
| 公布/施行 | 2011-10-18 印发，**2013-01-01 施行**（鼓励提前执行）；废止《小企业会计制度》（财会〔2004〕2 号） |
| 时效性 | 现行有效 |
| 适用范围 | 境内依法设立、符合《中小企业划型标准规定》**小型企业**标准的企业；**微型企业参照执行**。三类除外：① 股票或债券在市场上公开交易的小企业；② 金融机构或其他具有金融性质的小企业；③ 企业集团内的母公司和子公司 |
| 核心条款 | ① 资产按**成本计量，不计提资产减值准备**（除坏账、存货毁损等实际发生损失外）；② 长期股权投资一律采用**成本法**；③ 固定资产折旧方法：年限平均法为主，确需加速可用双倍余额递减法/年数总和法；④ 采用**历史成本**为主，简化公允价值使用；⑤ 报表体系简化（资产负债表、利润表、现金流量表、附注） |
| 合规要点 | ① 不计提减值准备会与税法「未经核定的准备金不得扣除」意外一致，减少部分纳税调整；② 但**资产实际损失**税前扣除仍需按 2011 年第 25 号公告做专项申报（见 22 文件）；③ 小企业准则不是「低标准」，会计法责任一致；④ 一旦转执行企业会计准则，**不得转回** |
| 信源 | ① https://www.gov.cn/gongbao/content/2012/content_2121709.htm（国务院公报：财会〔2011〕17 号全文，第二条三类除外、第六条不计提减值）<br>② https://kjs.mof.gov.cn/zhengwuxinxi/zhengcefabu/201111/P020111118325852319878.pdf（财政部会计司：《小企业会计准则》PDF 全文） |
| 核验 | 2026-11-07 联网核验：适用范围、三类除外、成本计量与不计提减值四项确认 |

| 发文机关 | 全国人大常委会；国务院；国家税务总局 |

## 38.8 会计政策变更、差错更正与追溯调整

| 字段 | 内容 |
|---|---|
| 文号 | 《企业会计准则第 28 号——会计政策、会计估计变更和差错更正》；《企业会计准则第 38 号——首次执行企业会计准则》 |
| 发文机关 | 财政部 |
| 效力层级 | 部门规范性文件（具体准则） |
| 公布/施行 | 2006 年首发，后续修订 |
| 时效性 | 现行有效 |
| 适用范围 | 执行企业会计准则的企业；小企业会计准则按自身规定简化处理 |
| 核心条款 | ① **会计政策变更**：一般采用**追溯调整法**（调整期初留存收益及相关项目），无法确定累积影响数时用未来适用法；② **会计估计变更**：采用**未来适用法**，不追溯；③ **前期差错**：重要差错采用追溯重述法，非重要差错可在发现当期更正；④ 首次执行企业会计准则按 CAS 38 处理 |
| 合规要点 | ① 政策变更需在附注披露性质、内容、影响金额；② 税务上不因追溯调整而改变以前年度应纳税额，需分别办理更正申报或按规定处理；③ 滥用「会计估计变更」调节利润是审计与稽查关注点；④ 差错更正涉及补税/退税的，按征管法更正申报程序办理（草案拟将更正申报入法，见 36.8） |
