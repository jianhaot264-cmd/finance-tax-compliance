## 27.1 《新设企业首次办税与身份选择》场景卡

| 字段 | 内容 |
|---|---|
| 适用场景 | 刚取得营业执照，需确定增值税身份、建账方式、首个申报期与可享优惠 |
| 适用主体 | 新设企业、个体工商户；查账 / 核定待定 |
| 判断路径 | ① 确认主体形态（公司缴企税 / 个体户缴经营所得个税）→ ② 预估年应征增值税销售额是否 ≤500 万，选小规模或自愿登记一般纳税人 → ③ 确认是否达建账标准、选择适用会计制度 → ④ 办理税务登记信息确认与票种核定（数电票）→ ⑤ 确认社保登记（用工起 30 日内）→ ⑥ 对照优惠有效期与主体条件判断可享项目 → ⑦ 建立首个申报期日历 |
| 必须核验 | 500 万口径（23-23.1）；建账要求（01-1.2）；社保 30 日（23-23.8）；优惠有效期（26-26.7） |
| 边界与例外 | 分支机构不单独判断小微资格；核定征收不是可自由选择的优惠；个体户不适用小微 5% |

| 关联条目 | 15-15.1；15-15.2；23-23.1；23-23.8 |

## 27.2 《首次开票、数电票与红冲》场景卡

| 字段 | 内容 |
|---|---|
| 适用场景 | 首次给客户开票、开具数电票、发生销货退回 / 折让需红冲 |
| 适用主体 | 全部纳税人；一般 / 小规模均可 |
| 判断路径 | ① 确认纳税义务是否已发生（收款 / 取索凭据 / 先开票三者取最早）→ ② 确认票种与开票权限（数电票）→ ③ 核对购买方信息、品名、金额、税率 / 征收率与业务实质一致 → ④ 发生折让 / 退回按实施条例第十三、十四条冲减销项或进项（一般 / 简易计税路径不同）→ ⑤ 按 28 号公告留存合同、付款、物流等资料 |
| 必须核验 | 纳税义务发生时间（23-23.1）；折让冲减（23-23.2）；扣除凭证三性（28-28.3） |
| 边界与例外 | 先开票即触发纳税义务，不论是否收款；出口报关早于时点以报关当日为准；不合规发票不得作为扣除凭证 |
| 易错结论 | 「先开票不影响纳税」「红冲等于作废不用留痕」「品名可按客户要求改」 |
| 应弃答或转介 | 涉及变更品名、代开、富余票、买卖发票等一律转介并标高风险 |
| 关联概念 | C10；C06；C13；C26 |

## 27.3 《年销售额接近或超过 500 万》场景卡

| 字段 | 内容 |
|---|---|
| 适用场景 | 季度末累计销售额逼近 500 万，或已超标需切换计税方法 |
| 适用主体 | 小规模纳税人 |
| 判断路径 | ① 按连续 12 个月 / 4 个季度累计**应征增值税销售额**重算，不按会计收入 → ② 判断是否 >500 万 → ③ 超标则办理一般纳税人登记，2026-01-01 起自**超标当期 1 日**生效 → ④ 该期全部销售额按适用税率重算，梳理进项抵扣资格与开票 → ⑤ 检查是否仍适用小规模专属优惠（超标后不再适用）→ ⑥ 复核进项分摊与年度清算义务 |
| 必须核验 | 500 万口径与生效日（16-16.4、21-21.3）；43 号令已废止（20-20.2） |
| 边界与例外 | 生效日不早于 2026-01-01；自然人等可例外不登记；自愿登记后一般不得转回 |
| 易错结论 | 沿用旧 43 号令「次月生效」；把 500 万当成自然年度收入；把生效日当成办理登记当日 |
| 应弃答或转介 | 涉及稽查查补销售额是否计入累计须按现行公告口径，未收录时提示回查官方原文 |

| 关联条目 | 16-16.4；21-21.3；23-23.1 |
| 时效性 | 汇编·动态（解释性场景条目；2026-01-01 起规则） |
| 信源 | https://www.qcclegal.com/regulation/c86c8a1a0b85580286c1551098dbf907/21?lcc_source=mcp ；https://www.chinatax.gov.cn/chinatax/n810219/n810744/c103147/c5249424/5249424/files/8e2bb59af3de4dec860e856ad66be304.pdf |

## 27.4 《员工入职、离职与社保登记》场景卡

| 字段 | 内容 |
|---|---|
| 适用场景 | 新员工入职、试用期、离职停缴、跨省转移、基数年度切换 |
| 适用主体 | 用人单位及职工 |
| 判断路径 | ① 自**用工之日起 30 日内**办理社保登记（含试用期，不能以「转正」为由延后）→ ② 按属地当期基数上下限与职工工资确定缴费基数 → ③ 自行申报、按时足额缴纳 → ④ 离职按规定办理停缴与转移 → ⑤ 每年基数切换时复核（广东 2026 年 1 月 / 7 月分阶段）→ ⑥ 未按时足额的自欠缴日起按日万分之五加收滞纳金 |
| 必须核验 | 社保法第五十八、六十、八十六条（23-23.8）；广东 2026 基数（05-5.8） |
| 边界与例外 | 深圳按当地口径另行公布；失业 / 工伤基数地市可另定；补差在本社保年度内缴纳视为正常缴费 |
| 易错结论 | 「试用期满再参保」「按最低工资申报即可」「员工签了放弃承诺书就不用缴」——承诺书无效（法释〔2025〕12 号第十九条） |
| 应弃答或转介 | 涉及广东工伤条例修订、地市细则、省级非税规定时属地确认（阻断项 P-06b） |
| 关联概念 | C23；C21；C25 |
| 关联条目 | 04-4.1；04-4.9；05-5.8；23-23.8 |
| 时效性 | 汇编·动态（解释性场景条目；基数为 2026 年度广东口径） |
| 信源 | https://www.qcclegal.com/regulation/a1b31bb5ee665ac0d0ae29bc178c63a2/102?lcc_source=mcp ；https://www.chinatax.gov.cn/chinatax/n810219/n810744/c103147/c5249424/5249424/files/8e2bb59af3de4dec860e856ad66be304.pdf |

## 27.5 《汇算清缴前凭证未取得》场景卡

| 字段 | 内容 |
|---|---|
| 适用场景 | 年底已发生支出但发票未到、发票不合规、跨年才取得凭证 |
| 适用主体 | 查账征收居民企业 |
| 判断路径 | ① 判断支出是否真实且已实际发生、属税法允许扣除范围 → ② 判断所属年度：属于**当年度**的，预缴可暂按账面金额核算，但应在**当年度汇算清缴期结束前**补开换开有效凭证（28 号公告第十三条、2011 年第 34 号第六条）→ ③ 属于**以前年度**且当年未扣除的，做专项申报及说明，追补至发生年度，**追补 ≤5 年**（2012 年第 15 号第六条）→ ④ 追补后多缴税款在追补确认年度抵扣、不足递延或申请退税 → ⑤ 亏损企业先调整所属年度亏损额再按亏损弥补原则处理 → ⑥ 留存合同、付款凭证、支出依据备查（28 号公告第七条） |
| 必须核验 | 28 号公告第七、十二、十三条（28-28.3）；2012 年第 15 号第六条（28-28.4）；权责发生制（23-23.4） |
| 边界与例外 | 不合规发票 / 虚开发票不得作为扣除凭证；汇缴期补票与追补申报不是同一时限；小额零星按起征点判断（地方标准 2026 年有变化） |
| 易错结论 | 「没发票一律不能扣」「5 年内任何无票支出都能补」「跨年发票直接计入取得年度」 |
| 应弃答或转介 | 起征点按次标准、地方口径差异须属地确认；涉虚开转介 |
| 关联概念 | C13；C14；C20；C19 |
| 关联条目 | 15-15.9；28-28.3；28-28.4 |
| 时效性 | 汇编·动态（解释性场景条目） |
| 信源 | https://www.chinatax.gov.cn/n810341/n810765/n812151/n812416/c1083545/content.html ；https://ydzk.chineselaw.com/zxt/statuteDetail/detailPage/b2b3e83dec39d980bdad15f12e38b499?text=13 |
| 核验 | 2026-11-07 总局 2012 年第 15 号公告官网原文 + 华宇元典 28 号公告第十三条逐字条文交叉 |

## 27.6 《优惠适用判断：小微 / 高新 / 加计 / 六税两费》场景卡

| 字段 | 内容 |
|---|---|
| 适用场景 | 企业问「我们能享受哪些优惠」「这几个能不能叠加」 |
| 适用主体 | 居民企业、个体户、小规模纳税人 |
| 判断路径 | ① 先分清**三套口径**（增值税小规模 / 企税小型微利 / 工信部划型）→ ② 按税种分别列出候选优惠 → ③ 逐项核对「主体 + 行业 + 指标 + 有效期」四条件 → ④ 识别互斥或择一关系（小微 5% 与高新 15% 需测算；留抵退税与即征即退互斥）→ ⑤ 检查是否需要资格认定 / 备案 / 单独核算（高新、研发加计、不征税收入）→ ⑥ 检查到期日分组（2026-12-31 / 2027-12-31）→ ⑦ 输出清单并标注「以官方最新公告为准」 |
| 必须核验 | 三套口径（25.1–25.3）；优惠速查（06-1）；到期分组（26-26.7） |
| 边界与例外 | 个体户不适用小微 5%；分支机构汇总判断；30% 广宣费限三类行业；前海 15% 已延至 2027-12-31，南沙仅至 2026-12-31 |
| 易错结论 | 「小微企业所有税都减半」「优惠自动续期」「高新和小微可以直接叠加」 |
| 应弃答或转介 | 南沙 2027 年是否延续、地方细则、行业专属名单未收录时明确提示不确定性 |
| 关联概念 | C01；C02；C03；C08；C09；C16；C29 |
| 关联条目 | 06-1；07-7.5；13-13.1；26-26.7；PENDING-VERIFICATION.md |
| 时效性 | 汇编·动态（优惠有效期逐项变化） |

## 27.7 《收到异常凭证通知或协查函》场景卡

| 字段 | 内容 |
|---|---|
| 适用场景 | 上游走逃 / 被定性虚开，下游收到《已证实虚开通知单》或被要求进项转出 |
| 适用主体 | 取得增值税专用发票的一般纳税人 |
| 判断路径 | ① 先定性：收到的是「异常凭证」管控还是已定性的虚开结论 → ② 异常凭证已申报抵扣的**一律先作进项转出**（2019 年第 38 号公告）→ ③ 检查纳税信用是否 A 级：A 级可自接到通知起 **10 个工作日内**提出核实申请 → ④ 整理真实交易证据链（合同、付款、物流、验收、沟通记录）→ ⑤ 若最终认定善意取得（真实交易 + 不知情），能重新取得合法有效专票的可抵扣，否则补缴已抵扣税款；依国税函〔2007〕1240 号**不加收滞纳金** → ⑥ 全流程转介执业税务师 / 律师 |
| 必须核验 | 28 号公告不合规发票不得扣除（28-28.3）；187 号 / 1240 号 / 38 号公告（28-28.7） |
| 边界与例外 | 异常凭证 ≠ 已定性虚开；不加收滞纳金 ≠ 不用补税；异常凭证进项占比 70% 且超 5 万元时对应开具专票也列入异常 |
| 易错结论 | 「收到协查函就等于被定性」「善意取得不用补税」「A 级自动免于转出」 |
| 应弃答或转介 | **强制转介**：涉虚开 / 偷税 / 刑事风险，且不得给出「如何规避」类建议 |
| 关联概念 | C07；C26；C25；C30 |
| 关联条目 | 03-3.1；11-11.5；28-28.7 |
| 时效性 | 汇编·动态（解释性场景条目；个案以主管税务机关认定为准） |
| 信源 | https://www.chinacourt.cn/law/detail/2008/01/id/123136.shtml ；https://ydzk.chineselaw.com/zxt/statuteDetail/detailPage/800f429454100a5692431d6fe13e4148?text=2 |
| 核验 | 2026-11-07 中国法院网 1240 号批复全文 + 华宇元典 38 号公告第二条逐字条文 + 海南省政府网三亚税务局问答三源交叉 |

## 27.8 《稽查、处罚告知与听证》场景卡

| 字段 | 内容 |
|---|---|
| 适用场景 | 收到税务检查通知、处罚事项告知书，考虑陈述申辩 / 听证 / 首违不罚 |
| 适用主体 | 被检查纳税人 |
| 判断路径 | ① 读文书标题定性：是「税务处理决定」（补税）还是「行政处罚」（罚款）→ ② 核对事实、依据条文、金额与计算期间 → ③ 判断是否适用首违不罚：初次 + 危害后果轻微 + 及时改正 + 落在现行清单内，注意是「**可以**不予处罚」→ ④ 拟作出较大数额罚款等处罚的，当事人要求听证应在告知后 **5 日内**提出 → ⑤ 陈述申辩与证据提交 → ⑥ 处罚争议可**直接**申请复议或起诉；纳税争议须**清税前置** → ⑦ 涉及偷抗骗、虚开的强制转介 |
| 必须核验 | 行政处罚法第三十三条 / 第六十四条（28-28.8、20-20.10）；征管法第八十八条（23-23.9） |
| 边界与例外 | 不予处罚不免除补税、滞纳金与改正义务；涉虚开偷税不适用首违不罚；复议 60 日与听证 5 日不是同一期限 |
| 易错结论 | 「第一次违法一律不罚」「所有税务争议都要先缴税」「听证可以口头随时提」 |
| 应弃答或转介 | 稽查应对、重大补税、争议诉讼强制转介执业税务师 / 律师 |
| 关联概念 | C24；C25；C27；C30 |
| 关联条目 | 01-1.4；09-9.2；09-9.4；20-20.10 |
| 时效性 | 汇编·动态（解释性场景条目） |
| 信源 | https://www.qcclegal.com/regulation/8648b183eccc77167aab718e2903911f/51?lcc_source=mcp ；https://www.qcclegal.com/regulation/7cd4528371b7ff79d826c9ca70c9dc27/117?lcc_source=mcp |

## 27.9 《纳税争议复议路径选择》场景卡

| 字段 | 内容 |
|---|---|
