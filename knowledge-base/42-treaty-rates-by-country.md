## 42.1 读表口径：先分清「法定税率 / 协定限制税率 / 有效税负」

|---|---|

| 发文机关 | 全国人民代表大会；国务院；国家税务总局 |
| 效力层级 | 法律 + 行政法规 + 部门规范性文件（执行国际条约） |
| 公布/施行 | 企业所得税法 2008-01-01 施行（2017、2018 修正）；实施条例 2008-01-01 施行；35 号公告 2020-01-01 施行 |
| 时效性 | 现行有效 |
| 适用范围 | 非居民企业取得来源于中国境内的股息、利息、特许权使用费（企业所得税法第三条第三款所得） |

| 信源 | ① https://www.gov.cn/gongbao/content/2007/content_609907.htm（中国政府网：《企业所得税法》全文，第四条税率、第三十七条源泉扣缴）<br>② https://guangdong.chinatax.gov.cn/gdsw/mmsw_tzgg/2019-10/25/content_fba9f50aa18e449c81c4ac7159626ba7.shtml（广东省税务局转载：35 号公告全文，第二十三条协定优先） |
