| 时效性 | 现行有效 |

|---|---|

| 发文机关 | 工信部、国家统计局、发改委、财政部（经国务院同意） |
| 效力层级 | 部门规范性文件 |
| 公布/施行 | 2011-06-18 印发施行 |
| 时效性 | 现行有效（工信部已上线规模类型自测小程序：baosong.miit.gov.cn/ScaleTest） |

| 合规要点 | ① 划型结论直接决定能否适用小微优惠（"六税两费"、政府采购预留份额等）；② 从业人数含劳务派遣；大型企业的分支机构、控股股东为大型企业的不算中小企业 |
| 信源 | 中国政府网公报、多地政府转载 |

| 发文机关 | 国务院 |
| 效力层级 | 行政法规 |
| 公布/施行 | 修订版 **2025-06-01 施行**（原条例 2020-09-01 实施） |
| 时效性 | 现行有效 |
| 适用范围 | 机关、事业单位、大型企业与中小企业的款项支付 |
