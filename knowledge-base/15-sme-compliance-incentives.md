# 15 中小企业财税合规与税收优惠全景

> 核验日期：2026-11-05 ｜ 信源：全国人大、国务院、财政部、税务总局、人社部、市场监管总局、广东省人社厅
> 定位：以“中小企业”为视角，把**申报义务、财务核算、优惠适用、监管信用**四条主线放在同一张图上。
> 重要：中小企业常同时涉及“三套口径”——统计划型、小型微利企业、小规模纳税人，三者不能混用（见 15.1）。

---

## 15.1 中小企业“三套口径”与适用主体

| 字段 | 内容 |
|---|---|
| 适用范围 | 在境内依法设立的各类中小企业、个体工商户 |
| 生效状态 | 现行有效 |
| 核心义务/优惠 | ① **统计划型**：按《中小企业划型标准规定》（工信部联企业〔2011〕300 号），分中型/小型/微型，用于享受政府采购、专项资金、融资担保等扶持；② **小型微利企业**（税务口径）：从事国家非限制和禁止行业，年度应纳税所得额≤300 万元、从业人数≤300 人、资产总额≤5000 万元，用于 5% 实际税负优惠；③ **小规模纳税人**（增值税口径）：年应征增值税销售额≤500 万元，用于简易计税与月 10 万元免征等优惠；④ 个体工商户依《民法典》《促进个体工商户发展条例》登记，可个人或家庭经营 |
| 适用条件 | 三套口径判断维度不同：划型看行业+从业人数+营业收入+资产总额；小型微利看所得税三项指标；小规模看增值税销售额。同一企业可能“小型微利但不是小规模”，也可能“是小规模但不符合小微” |
| 主要依据 | 工信部联企业〔2011〕300 号；财政部 税务总局公告 2023 年第 12 号；《增值税法》第九条（2026-01-01 施行） |
| 合规要点 | ① 申报优惠时按对应口径取数，不能拿统计划型直接套税务优惠；② 小型微利指标按**全年季度平均值**计算，年度中间开业/终止按实际经营期计算；③ 小规模超标须登记为一般纳税人，2026 年起生效日为超标当期 1 日（见 15.4） |
| 信源 | 财政部 税务总局公告 2023 年第 12 号原文；《增值税法》；工信部划型标准 |
| 核验 | 2026-11-05 核验三套口径与硬指标 |

## 15.2 《中华人民共和国公司法》（2023 年修订）

| 字段 | 内容 |
|---|---|
| 适用范围 | 有限责任公司、股份有限公司及其股东、董监高 |
| 生效状态 | 2023-12-29 第十四届全国人大常委会第七次会议修订通过，**2024-07-01 施行**；现行有效 |
| 核心义务/优惠 | ① 有限责任公司全体股东认缴的出资额，由股东按章程规定**自公司成立之日起 5 年内缴足**；② 股份有限公司发起人应在公司成立前按认购股份全额缴纳股款；③ 存量公司（2024-07-01 前设立）出资期限超过 5 年的，应逐步调整至法定期限内；出资期限、出资额明显异常的，登记机关可要求及时调整；④ 股东可用货币、实物、知识产权、土地使用权、股权、债权等可估价并可转让的非货币财产出资；⑤ 公司不能清偿到期债务时，公司或已到期债权的债权人有权要求未届出资期限的股东提前缴纳出资（第五十四条） |
| 适用条件 | 所有公司制中小企业；国务院《关于实施〈公司法〉注册资本登记管理制度的规定》（2024-07-01 施行）对存量公司过渡作出安排 |
| 主要依据 | 《公司法》（2023 修订）；国务院注册资本登记管理规定（2024-07-01） |
| 合规要点 | ① “认缴”不等于“不缴”，5 年是硬期限；② 盲目高额认缴会把有限责任变成实质无限责任；③ 减资、股权转让、注销前须核实出资义务与债务清偿；④ 抽逃出资、虚假出资仍要承担补足与赔偿责任 |
| 信源 | 中国政府网 2023-12 解读、司法部/市场监管总局 2024-07 答记者问、市场监管总局专题 |
| 核验 | 2026-11-05 核验修订/施行日期、5 年缴足与存量过渡 |

## 15.3 市场主体登记与个体工商户

| 字段 | 内容 |
|---|---|
| 适用范围 | 公司、非公司企业法人、个人独资企业、合伙企业、农民专业合作社、个体工商户等 |
| 生效状态 | 《市场主体登记管理条例》（国务院令第 746 号）**2022-03-01 施行**；《促进个体工商户发展条例》（国务院令第 755 号）**2022-11-01 施行**；均现行有效 |
| 核心义务/优惠 | ① 市场主体应办理设立、变更、注销登记，未经登记不得以市场主体名义经营；② 个体工商户可个人经营或家庭经营，可自愿变更经营者或转型为企业，变更/转型应结清税款、妥善处理债权债务；③ 登记机关应提供规范、便捷的登记服务；④ 无照经营可责令改正、没收违法所得，拒不改正处 1 万–10 万元罚款，情节严重责令关闭并处 10 万–50 万元罚款；提交虚假材料取得登记可处 5 万–20 万元罚款，情节严重处 20 万–100 万元并吊销营业执照 |
| 适用条件 | 所有市场主体；依法无需登记的情形除外（如电商法第十条规定的自产农副产品、家庭手工业、便民劳务、零星小额交易） |
| 主要依据 | 《市场主体登记管理条例》（746 号令）；《促进个体工商户发展条例》（755 号令）；《电子商务法》第十条 |
| 合规要点 | ① 注销前必须完成税务清算与清税，否则无法顺利注销；② 个体户“变更经营者”不是新设，原债务与税务责任要处理清楚；③ 注册地址、经营范围与实际经营不一致会触发市监与税务风险 |
| 信源 | 中国政府网、国务院政策例行吹风会、市场监管总局登记指引 |
| 核验 | 2026-11-05 核验两个条例的令号与施行日 |

## 15.4 增值税：纳税人身份、申报义务与优惠

| 字段 | 内容 |
|---|---|
| 适用范围 | 在境内发生应税交易的单位、个体工商户和自然人 |
| 生效状态 | 现行有效；《增值税法》**2026-01-01 施行**；《增值税法实施条例》（国务院令第 826 号）同步施行；《增值税一般纳税人登记管理办法》（43 号令）**已于 2026-01-01 废止**（国家税务总局令第 62 号）；现按《增值税法》第九条及国家税务总局公告 **2026 年第 2 号**执行 |
| 核心义务/优惠 | ① **小规模纳税人**=年应征增值税销售额未超过 **500 万元**；② 超过标准的，除“不经常发生应税交易且主要业务不属于应税交易范围的非企业单位”和“自然人”外，应办理一般纳税人登记；③ 2026 年起，一般纳税人生效之日为**超过规定标准的当期 1 日**，且不早于 2026-01-01（不再由纳税人自选当月/次月）；④ 小规模优惠：月销售额 10 万元以下（含）免征；3% 征收率减按 1%，至 **2027-12-31**；⑤ 会计核算健全的小规模纳税人可主动登记、按一般计税方法纳税 |
| 适用条件 | 小规模优惠适用于增值税小规模纳税人；一般纳税人登记以“连续不超过 12 个月或 4 个季度”的累计应征销售额判断，偶然销售无形资产/不动产不计入 |
| 主要依据 | 《增值税法》第九条、第三十八条；《增值税法实施条例》第七条、第五十四条；国家税务总局公告 2026 年第 2 号；财政部 税务总局公告 2023 年第 19 号 |
| 合规要点 | ① 按月/按季申报，期满之日起 15 日内（遇节假日顺延，具体以主管税务机关通知为准）；② 超标未登记：次月起按销售额依税率计算、不得抵扣进项，直至办理登记；③ 2026 年起追溯登记不早于 2026-01-01，跨期票据与收入归属要提前梳理；④ 小规模优惠与一般计税不能同时适用，身份转换前要做税负测算 |
| 信源 | 《增值税法》原文；上海、辽宁、云南、大连税务局 2026 年答复与解读 |
| 核验 | 2026-11-05 核验 500 万标准、2026 年第 2 号公告、43 号令废止 |

## 15.5 企业所得税：预缴、汇算与小型微利优惠

| 字段 | 内容 |
|---|---|
| 适用范围 | 居民企业（含中小企业）、在中国境内设立机构场所的非居民企业 |
| 生效状态 | 现行有效；《企业所得税法》2008-01-01 施行（2018 修正）；小型微利优惠按财政部 税务总局公告 2023 年第 12 号执行至 **2027-12-31** |
| 核心义务/优惠 | ① 按月/按季预缴，月份或季度终了后 **15 日内**申报预缴；年度终了后 **5 个月内**汇算清缴；② 小型微利企业：减按 **25%** 计入应纳税所得额、按 **20%** 税率，实际税负 **5%**；③ 条件：非限制禁止行业 + 年度应纳税所得额≤**300 万元** + 从业人数≤**300 人** + 资产总额≤**5000 万元**；④ 从业人数含劳务派遣；指标按全年季度平均值计算；⑤ 具备高新技术企业或科技型中小企业资格的，前 5 年未弥补亏损结转年限由 5 年延长至 **10 年** |
| 适用条件 | 小型微利企业以**年度汇算清缴结果**判定；新设企业符合条件可在首次汇算前按小微预缴 |
| 主要依据 | 《企业所得税法》第五十四条；财政部 税务总局公告 2023 年第 12 号；财税〔2018〕76 号 |
| 合规要点 | ① 预缴少缴会在汇算时补税并可能加收滞纳金；② 季度平均值公式：季度平均值=(季初+季末)÷2，全年=各季度平均值之和÷4；③ 与高新 15% 等优惠存在择一/叠加判断，需逐案测算；④ 弥补亏损、优惠事项均需留存备查资料 |
| 信源 | 财政部 税务总局公告 2023 年第 12 号；厦门市税务局 2026-05 热点答复 |
| 核验 | 2026-11-05 核验 300/300/5000、5% 与 2027-12-31 |

## 15.6 个人所得税：代扣代缴、经营所得与个体户优惠

| 字段 | 内容 |
|---|---|
| 适用范围 | 企业作为扣缴义务人；个体工商户、个人独资/合伙企业投资人；取得综合所得的个人 |
| 生效状态 | 现行有效；《个人所得税法》2019-01-01 施行；《个人所得税综合所得汇算清缴管理办法》（税务总局令第 57 号）2025 年施行；个体户减半政策执行至 **2027-12-31** |
| 核心义务/优惠 | ① 工资薪金：企业按月预扣预缴，次月 15 日内申报；② 综合所得年度汇算：次年 **3 月 1 日–6 月 30 日**；③ 经营所得：按月/按季预缴，次年 **3 月 31 日前**汇算；④ 个体工商户年应纳税所得额不超过 **200 万元**的部分，**减半征收**个人所得税，可与其他个税优惠叠加 |
| 适用条件 | 个体户减半适用于个体工商户（查账/核定征收均可）；个人独资企业、合伙企业不适用“个体工商户”条款，按其他规定判断 |
| 主要依据 | 《个人所得税法》；国家税务总局公告 2018 年第 61 号（扣缴申报）；税务总局令第 57 号；财政部 税务总局公告 2023 年第 12 号 |
| 合规要点 | ① 工资、劳务报酬、经营所得定性不同，不能把工资拆成“服务费”；② 两处以上综合所得、补税金额较大等需汇算；③ 个体户减半无需备案，但应准确计算应纳税所得额；④ 虚列人员、拆分工资会被社保与个税数据比对发现 |
| 信源 | 财政部 税务总局公告 2023 年第 12 号；税务总局令第 57 号；税务总局年度报告 |
| 核验 | 2026-11-05 核验 200 万减半、汇算期限与 57 号令 |

## 15.7 印花税、房产税、城镇土地使用税与附加税费

| 字段 | 内容 |
|---|---|
| 适用范围 | 书立应税凭证、拥有房产/土地使用权的企业；缴纳增值税、消费税的单位和个人 |
| 生效状态 | 《印花税法》**2022-07-01 施行**；《城市维护建设税法》**2021-09-01 施行**；房产税、城镇土地使用税仍按暂行条例（现行有效，未立法） |
| 核心义务/优惠 | ① 印花税按税目税率表就合同、产权转移书据、营业账簿等计税，按季/按年/按次申报；② 房产税按房产原值减除 10%–30% 后的余值或租金收入计征，按年征收、分期缴纳；③ 城镇土地使用税按实际占用面积与地段等级税额计征；④ 城建税按实际缴纳的增值税、消费税计征（市区 7%、县镇 5%、其他 1%）；⑤ 小规模纳税人、小型微利企业、个体工商户**减半**征收资源税（不含水）、城建税、房产税、城镇土地使用税、印花税（不含证券交易）、耕地占用税及教育费附加、地方教育附加，至 **2027-12-31** |
| 适用条件 | “六税两费”减半适用于增值税小规模纳税人、小型微利企业和个体工商户；已享受其他优惠的可叠加 |
| 主要依据 | 《印花税法》；《城市维护建设税法》；《房产税暂行条例》；《城镇土地使用税暂行条例》；财政部 税务总局公告 2023 年第 12 号 |
| 合规要点 | ① 印花税按合同类型确定税目，同一合同含多项业务要分别判断；② 房产原值是否含地价、附属设备影响税基；③ 免租期、无租使用、转租的房产税处理不同；④ 附加税费随主税减免而减免，不能独立“筹划” |
| 信源 | 全国人大、国务院、财政部 税务总局公告 2023 年第 12 号 |
| 核验 | 2026-11-05 核验各法施行日与六税两费范围 |

## 15.8 社会保险费、残保金与非税收入

| 字段 | 内容 |
|---|---|
| 适用范围 | 用人单位及其职工；安排残疾人就业未达比例的用人单位；缴纳非税收入的单位和个人 |
| 生效状态 | 现行有效；《社会保险法》2011-07-01 施行（2018 修正）；法释〔2025〕12 号 **2025-09-01 施行**；残保金优惠执行至 **2027-12-31**；广东 2026 养老基数按粤人社发〔2026〕24 号执行 |
| 核心义务/优惠 | ① 用人单位应自行申报、按时足额缴纳社保费；② **约定或承诺不缴社保无效**；劳动者可据此解除合同并主张经济补偿；③ 广东企业职工养老基数：2026-01-01 起下限 5510 元/月，2026-07-01 起上限 27603、下限 5521；④ 残保金：在职职工 30 人（含）以下免征；安排残疾人就业比例≥1% 未达标按应缴额 50% 缴纳，<1% 按 90%；⑤ 非税收入实行目录清单管理，目录外违规收费有权拒缴 |
| 适用条件 | 社保覆盖各类用人单位；残保金按上年在职职工人数、工资总额与安排残疾人就业比例计算；非税按项目文件执行 |
| 主要依据 | 《社会保险法》第五十八、六十条；法释〔2025〕12 号第十九条；粤人社发〔2026〕24 号；财政部公告 2023 年第 8 号；《政府非税收入管理办法》 |
| 合规要点 | ① “自愿放弃社保+现金补贴”不能免除补缴、滞纳金与行政处罚；② 社保基数与个税工资、企业所得税工资薪金需相互印证；③ 残保金按年申报，逾期可能加收滞纳金；④ 非税缴费要索取财政票据 |
| 信源 | 最高法 2025-08-01 发布会；广东省人社厅；财政部公告 2023 年第 8 号 |
| 核验 | 2026-11-05 核验司法解释、广东基数与残保金分档 |

## 15.9 发票管理与数电票

| 字段 | 内容 |
|---|---|
| 适用范围 | 领用、开具、取得、保管发票的单位和个人 |
