## 4.1 《中华人民共和国社会保险法》

| 字段 | 内容 |
|---|---|
| 发文机关 | 全国人大常委会 |
| 效力层级 | 法律 |
| 公布/施行 | 2010-10-28 通过，2011-07-01 施行（2018 年修正——（依据见 19-19.2）|
| 时效性 | 现行有效；**修改社会保险法已列入十四届全国人大常委会立法规划（第二类项目，国务院牵头），2024 年完成执法检查、2025 年开展修法专题调研，截至核验日尚未修改** |
| 适用范围 | 基本养老、基本医疗、工伤、失业、生育五项社会保险 |
| 核心条款 | ① 用人单位应当**自行申报、按时足额缴纳**社会保险费（第六十条，税务/社保部门执法依据）；② 职工个人缴费由用人单位代扣代缴；③ 未按时足额缴费的加收滞纳金（按日万分之五）并可处罚款；④ 基金专款专用、分账核算 |
| 合规要点 | ① 全员足额参保、基数如实申报（瞒报漏报基数人数是稽查重点）；② "以补贴换社保""虚构劳动关系参保"均属违法 |
| 信源 | 中国人大网 2025-11 社建委议案审议报告、2025-09 国务院落实社保法执法检查报告；https://www.gov.cn/zhengce/zhengceku/202309/content_6901384.htm ；https://banshi.beijing.gov.cn/pubtask/task/1/110107000000/2a7e2b8c-10f7-43b0-b09d-f46399002c47.html （2026-11-06 闭环双源） |

## 4.5 社会保险费申报缴纳流程改革（自行申报）

| 字段 | 内容 |
|---|---|
| 性质 | 全国部署、分省分批落地的征管改革（无单一全国公告文号；各省由税务、财政、人社、人行、医保五部门联合公告） |
| 时效性 | 各地现行有效 |
| 核心内容 | ① 将"先向人社/医保部门核定、再向税务缴费"改为**缴费人自行向税务部门申报缴费**；② 覆盖用人单位职工五险及灵活就业人员；③ 参保登记、权益记录、待遇支付仍由人社/医保经办机构办理；④ 特殊补缴仍先经人社/医保核定 |
| 合规要点 | ① 用人单位自行申报后责任前移——申报数据错误直接产生法律责任；② 每月申报缴费时限各地不同（如北京 10-25 日、深圳 25 日前），以当地公告为准 |
| 信源 | 北京 2023 年第 5 号、上海 2023 年第 2 号、山西等省公告；广东情况见 05 文件 |

## 4.7 《政府非税收入管理办法》

| 字段 | 内容 |
|---|---|
| 文号 | 财政部印发（依据见 18-18.6） |
| 发文机关 | 财政部 |
| 效力层级 | 部门规范性文件 |
| 公布/施行 | 2016 年印发，自颁布之日起施行 |
| 时效性 | 现行有效 |
| 适用范围 | 非税收入设立、征收、票据、资金和监督管理 |
| 核心条款 | ① 12 类非税收入：行政事业性收费、政府性基金、罚没收入、国有资源（资产）有偿使用收入、国有资本收益、彩票公益金、特许经营收入、中央银行收入、捐赠收入、主管部门集中收入、利息收入、其他；② **不包括社会保险费、住房公积金（计入个人账户部分）**；③ 分类分级管理；县级以上财政部门为主管部门；④ 任何部门单位不得违规设立项目或设定征收对象/范围/标准/期限；**缴纳义务人对违规设立项目、扩大范围、提高标准的，有权拒绝缴纳并向有关部门举报**（第十五条）；⑤ 收入全部上缴国库，国库集中收缴；⑥ 非税收入票据三类（通用票据/专用票据/一般缴款书），存根保存一般 5 年；⑦ 附加在价格上征收或需依法纳税的非税收入应开具税务发票 |
| 合规要点 | ① 企业被收费先查该项目是否在合法目录内（乱收费可拒缴+举报）；② 政府性基金/行政事业性收费缴纳票据是税前扣除凭证的重要组成 |
| 信源 | 办法全文经多级政府网站转载核验；https://www.gov.cn/gongbao/content/2016/content_5086359.htm ；http://fgk.mof.gov.cn/ui/src/views/law_html/84292.html （2026-11-06 闭环双源） |

## 4.9 《最高人民法院关于审理劳动争议案件适用法律问题的解释（二）》第十九条 ★

| 字段 | 内容 |
|---|---|
| 文号 | 法释〔2025〕12 号 |
| 发文机关 | 最高人民法院（2025-02-17 审判委员会第 1942 次会议通过） |
| 效力层级 | 司法解释 |
| 公布/施行 | 2025-07-31 公布，**2025-09-01 施行** |
| 时效性 | 现行有效 |
| 适用范围 | 用人单位与劳动者的社会保险、竞业限制、劳动合同等争议 |
| 核心条款 | ① **用人单位与劳动者约定，或者劳动者向用人单位承诺无需缴纳社会保险费的，该约定或承诺无效**；② 用人单位未依法缴纳社保费，劳动者可依《劳动合同法》第三十八条第一款第三项解除劳动合同，并要求支付经济补偿；③ 用人单位按行政机关要求补缴后，可请求劳动者返还已按约定支付的社保费补偿款；④ 经济补偿标准：每满 1 年支付 1 个月工资，不满 6 个月支付半个月工资；⑤ 同时明确混同用工、竞业限制、二倍工资等规则 |
| 合规要点 | ① “自愿放弃社保 + 现金补贴”自 2025-09-01 起在司法上确定无效，企业不能以此抗辩；② 员工可据此主动解除并索赔经济补偿，补缴后仍可能面临滞纳金与行政处罚；③ 已发补贴可主张返还，但不能抵消补缴义务；④ 与《社会保险法》第五十八条、第六十条的行政责任并行，民事与行政风险叠加 |
| 信源 | 最高人民法院 2025-08-01 新闻发布会；中国法院网、人民网报道 |
| 核验 | 2026-11-05 核验文号、施行日与第十九条全文 |
