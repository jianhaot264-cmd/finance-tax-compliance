# 征管程序与纳税人权利：登记、申报、征收、担保、强制、检查、反避税、信用

> 覆盖：企业从设立到注销的 10 个征管节点，以及每个节点上的**纳税人权利**与**执法边界**。
> 本文件为 **A 层**：每条 10 字段 + 至少 2 个官方信源 + 核验日期 2026-11-08。
> 口径：征管法现行仍为 **2015 修正版**；2026-11-06 修订草案一审未通过，本文件不采用草案内容。

| 合规要点 | ① 不办登记/逾期登记可处 **2000 元以下**罚款，情节严重 **2000–10000 元**；② 地址变更跨区可能涉及**迁移**，不是简单变更；③ 注销「简易注销」与「一般注销」适用条件不同，有欠税/异常户不能简易；④ 分支机构也要登记，不能只登记总部；⑤ 实名信息与发票领用、退税、优惠办理绑定，人员离职要及时变更 |

| 核验 | 2026-11-08 联网核验：30 日登记/变更、注销清税、实名办税四项与现行规定一致；具体材料以电子税务局清单为准 |

## 46.2 纳税申报：按期、延期最长 3 个月、更正申报

| 字段 | 内容 |
|---|---|
| 文号 | 《税收征收管理法》第二十五条至第二十七条；《税收征收管理法实施细则》第三十条至第三十七条 |
| 发文机关 | 全国人大常委会；国务院 |
| 效力层级 | 法律 + 行政法规 |
| 公布/施行 | 2015 修正 / 2016 修订 |
| 时效性 | 现行有效 |
| 适用范围 | 所有纳税人、扣缴义务人 |
| 核心条款 | ① 按**法定期限**申报，即使当期无收入、无应纳税额也要**零申报**；② **延期申报**：因不可抗力或财务处理特殊原因，可在期限内申请延期，最长**不超过 3 个月**；③ 延期申报**不免除**税款缴纳义务，应按上期税额或税务机关核定**预缴**；④ **更正申报**：发现申报错误可主动更正，多缴可申请退还（3 年内），少缴要补税+滞纳金；⑤ 申报方式：电子税务局、办税服务厅、邮寄、数据电文 |
| 合规要点 | ① 逾期申报可处 **2000 元以下**罚款，情节严重 **2000–10000 元**；② 「零申报」不等于「不申报」，长期零申报会被列入风险监控；③ 更正申报**主动**与**被查后**补税，滞纳金都从滞纳之日起算，但主动更正通常不罚款；④ 延期申报批准不等于延期纳税，别混淆；⑤ 申报数据与财务报表、发票数据、银行流水不一致是高频风险点 |
| 信源 | ① https://www.gov.cn/gongbao/content/2007/content_609907.htm（征管法第二十五至二十七条）<br>② https://fgk.chinatax.gov.cn/（实施细则第三十至三十七条；电子税务局申报规范） |
| 核验 | 2026-11-08 联网核验：3 个月延期、零申报义务、更正申报 3 年退还期；具体申报期限按各税种法 |

## 46.3 税款征收方式与核定：查账、核定、定期定额

| 字段 | 内容 |
|---|---|
| 文号 | 《税收征收管理法》第三十五条、第三十六条；《税收征收管理法实施细则》第四十七条 |
| 发文机关 | 全国人大常委会；国务院 |
| 效力层级 | 法律 + 行政法规 |
| 公布/施行 | 2015 修正 / 2016 修订 |
| 时效性 | 现行有效 |
| 适用范围 | 账簿不健全、成本资料残缺、申报明显偏低等情形的纳税人 |
| 核心条款 | ① **查账征收**为原则；② **核定征收**适用六种情形：依照法律/行政法规规定可以不设置账簿的；应设未设账簿的；擅自销毁账簿或拒不提供纳税资料的；虽设账簿但账目混乱/成本资料/收入凭证/费用凭证残缺不全难以查账的；发生纳税义务未按期申报，经责令限期申报仍逾期不申报的；申报计税依据明显偏低又无正当理由的；③ **核定方法**：参照同类行业税负、按成本加合理费用和利润、按耗用原材料/燃料/动力等推算、其他合理方法；④ **定期定额**适用于个体户等小规模纳税人 |
| 合规要点 | ① 核定征收是**税务机关的权力**，不是纳税人可以自选的「优惠」；② 核定后仍要按期申报，不能「核定就不申报」；③ 核定税额明显不合理可申请**调整/复议**；④ 账目健全后应主动申请**转为查账征收**，否则可能被按高额核定；⑤ 关联交易应按**独立交易原则**，否则被特别纳税调整 |
| 信源 | ① https://www.gov.cn/gongbao/content/2007/content_609907.htm（征管法第三十五、三十六条）<br>② https://fgk.chinatax.gov.cn/（实施细则第四十七条核定方法） |
| 核验 | 2026-11-08 联网核验：六种核定情形、四种核定方法；具体核定程序以主管税务机关文书为准 |

## 46.4 纳税担保：保证、抵押、质押与适用情形

| 字段 | 内容 |
|---|---|
| 文号 | 《税收征收管理法》第三十八条、第四十四条、第八十八条；《税收征收管理法实施细则》第六十一条、第六十二条；《纳税担保试行办法》（国家税务总局令第 11 号） |
| 发文机关 | 全国人大常委会；国务院；国家税务总局 |
| 效力层级 | 法律 + 行政法规 + 部门规章 |
| 公布/施行 | 征管法 2015 修正；纳税担保试行办法 2005-07-01 施行 |
| 时效性 | 现行有效 |
| 适用范围 | 申请行政复议前、出境前、税收保全、纳税争议等需要提供担保的情形 |
| 核心条款 | ① **三种形式**：纳税保证（保证人）、纳税抵押（不动产/动产）、纳税质押（动产/权利凭证）；② **适用情形**：税务机关采取税收保全措施时要求提供担保；欠税人或者其法定代表人需要**出境**；纳税争议申请复议**清税前置**的替代（提供担保）；③ 担保范围包括**税款、滞纳金、罚款**；④ 保证人须有纳税担保能力，国家机关、学校、幼儿园、医院等**不得**作为保证人；⑤ 抵押/质押须办理登记或交付，否则不得对抗第三人 |
| 合规要点 | ① 纳税担保不是「免缴」，是**延期/替代**，最终仍要清缴；② 复议前提供担保可替代清税，但须经税务机关**确认**；③ 出境担保针对**欠税人本人或其法定代表人**，不是所有员工；④ 抵押物价值须覆盖税款+滞纳金+罚款，评估报告要留档；⑤ 担保期间转让抵押物需经税务机关同意，否则可能构成逃税 |
| 信源 | ① https://www.gov.cn/gongbao/content/2007/content_609907.htm（征管法第三十八、四十四、八十八条）<br>② https://fgk.chinatax.gov.cn/（纳税担保试行办法 总局令第 11 号） |
| 核验 | 2026-11-08 联网核验：三种担保形式、出境担保、复议替代；具体办理材料以主管税务机关要求为准 |

## 46.5 税收保全与强制执行：审批权限、期限与救济

| 字段 | 内容 |
|---|---|
| 文号 | 《税收征收管理法》第三十七条至第四十二条、第五十五条；《税收征收管理法实施细则》第六十三条至第六十九条；《行政强制法》 |
| 发文机关 | 全国人大常委会；国务院 |
| 效力层级 | 法律 + 行政法规 |
| 公布/施行 | 征管法 2015 修正；行政强制法 2012-01-01 施行 |
| 时效性 | 现行有效 |
| 适用范围 | 未按期缴纳税款、有明显转移/隐匿财产迹象、欠税等情形 |
| 核心条款 | ① **税收保全**：冻结存款、扣押/查封商品货物或其他财产，须经**县以上税务局（分局）局长批准**；② **强制执行**：书面通知开户银行扣缴税款、扣押/查封/依法拍卖或变卖，须经**县以上税务局（分局）局长批准**；③ **个人及其所扶养家属**维持生活必需的住房和用品**不得**查封、扣押；④ 查封/扣押期限一般不超过 **6 个月**，重大案件经批准可延长；⑤ 对保全/强制措施不服，可**直接申请行政复议或提起行政诉讼**（不需要先清税） |
| 合规要点 | ① 保全/强制必须**先催告、后执行**，程序违法可撤销；② 扣押/查封要出具**清单**，由当事人签字；③ 拍卖/变卖价款抵缴税款后有余额应**退还**；④ 超期查封/扣押可申请解除并主张赔偿；⑤ 对处罚/强制不服的救济**不受清税前置限制**，这是与纳税争议的关键区别 |
| 信源 | ① https://www.gov.cn/gongbao/content/2007/content_609907.htm（征管法第三十七至四十二条）<br>② https://fgk.chinatax.gov.cn/（实施细则第六十三至六十九条；行政强制法） |
| 核验 | 2026-11-08 联网核验：县以上局长批准、6 个月查封期、生活必需品豁免、救济不受清税前置限制 |

## 46.6 欠税管理：公告、滞纳金、出境限制、代位权与撤销权

| 字段 | 内容 |
|---|---|
| 文号 | 《税收征收管理法》第四十四条、第四十五条、第五十条；《税收征收管理法实施细则》第七十三条至第七十六条；《欠税公告办法（试行）》 |
| 发文机关 | 全国人大常委会；国务院；国家税务总局 |
| 效力层级 | 法律 + 行政法规 + 部门规章 |
| 公布/施行 | 征管法 2015 修正 |
| 时效性 | 现行有效 |
| 适用范围 | 欠缴应纳税款的纳税人 |
| 核心条款 | ① **滞纳金**按日加收 **万分之五**，从滞纳税款之日起算；② **欠税公告**：税务机关定期公告欠税人名称、欠税金额等；③ **出境限制**：欠税人或者其法定代表人需要出境的，须结清税款或提供担保；④ **代位权**：欠税人怠于行使到期债权，税务机关可请求法院代位行使；⑤ **撤销权**：欠税人无偿转让财产、以明显不合理低价转让财产损害税收，税务机关可请求法院撤销；⑥ **税收优先权**：税收优先于无担保债权，但不得优先于**抵押权/质权/留置权**（发生在欠税之前的） |
| 合规要点 | ① 滞纳金**无上限**（征管法未设上限，草案曾讨论 2 倍上限但未通过）；② 欠税公告会影响**纳税信用**和招投标；③ 代位权/撤销权是**民事手段**，税务机关可直接起诉；④ 重组/注销前要清理欠税，否则股东可能被追责；⑤ 税收优先权与担保物权的**时间顺序**决定受偿顺序 |
| 信源 | ① https://www.gov.cn/gongbao/content/2007/content_609907.htm（征管法第四十四、四十五、五十条）<br>② https://fgk.chinatax.gov.cn/（实施细则第七十三至七十六条；欠税公告办法） |
| 核验 | 2026-11-08 联网核验：万分之五滞纳金、出境限制、代位权/撤销权、税收优先权顺序 |

| 发文机关 | 全国人大常委会；国务院 |
| 效力层级 | 法律 + 行政法规 |

| 时效性 | 现行有效 |
| 适用范围 | 税务稽查、日常检查、专项检查 |
| 核心条款 | ① 检查须**两人以上**并出示**税务检查证**和**税务检查通知书**（特殊情况可先检查后补）；② 可查账簿、记账凭证、报表、发票、电子数据、银行存款账户；③ **调取账簿**须经**县以上税务局（分局）局长批准**，并在 **3 个月**内退还；特殊情况经**设区的市、自治州以上税务局局长**批准可延长；④ 询问须制作笔录，电子数据要固定原始载体；⑤ 纳税人有权要求**回避**、**陈述申辩**、**复制证据** |
| 合规要点 | ① 无检查证/通知书的检查程序违法，取得的证据可能被排除；② 调取账簿要**开付清单**，按期退还；③ 电子数据检查要**封存原始存储介质**，不能只拷文件；④ 检查期间不得**转移/销毁**资料，否则可能构成逃税；⑤ 对检查结论有异议，可在**告知书**阶段陈述申辩，也可事后复议/诉讼 |

| 核验 | 2026-11-08 联网核验：两人执法、检查证、3 个月退还、电子数据固定；具体程序按《税务稽查案件办理程序规定》 |

## 46.8 特别纳税调整：转让定价、预约定价、成本分摊、资本弱化

| 字段 | 内容 |
|---|---|
| 文号 | 《企业所得税法》第四十一条至第四十八条；《企业所得税法实施条例》第一百一十条至第一百二十三条；《特别纳税调查调整及相互协商程序管理办法》（国家税务总局公告 2017 年第 6 号）；《关联申报和同期资料管理办法》（2016 年第 42 号） |
| 发文机关 | 全国人大常委会；国务院；国家税务总局 |
| 效力层级 | 法律 + 行政法规 + 规范性文件 |
| 公布/施行 | 企税法 2008-01-01；6 号公告 2017-05-01 施行；42 号公告 2016 年发布 |
| 时效性 | 现行有效 |
| 适用范围 | 关联交易不符合独立交易原则、受控外国企业、资本弱化、一般反避税安排 |
| 核心条款 | ① **转让定价**：关联交易应按**独立交易原则**，方法包括可比非受控价格法、再销售价格法、成本加成法、交易净利润法、利润分割法；② **预约定价安排（APA）**：企业可申请单边/双边/多边 APA，覆盖未来 3–5 年；③ **成本分摊协议**：共同开发无形资产/劳务，需符合独立交易原则并备案；④ **资本弱化**：关联方债权性投资与权益性投资比例 **2:1**（金融企业 5:1），超过部分利息不得扣除；⑤ **受控外国企业（CFC）**：低税率国家/地区利润不分配且无合理经营需要，计入居民企业当期收入；⑥ **一般反避税**：不具有合理商业目的的安排，税务机关可调整，追溯期 **10 年** |
| 合规要点 | ① 关联交易达到标准要**关联申报**并准备**同期资料**（主体文档/本地文档/特殊事项文档）；② 同期资料未准备/不合规可被**核定**并处罚；③ APA 是**事前**确定性工具，比事后争议更省成本；④ 资本弱化只看**关联方**债权，独立第三方借款不受 2:1 限制；⑤ 一般反避税是**兜底条款**，商业目的不真实的高风险架构要提前评估 |
| 信源 | ① https://www.gov.cn/gongbao/content/2007/content_609907.htm（企业所得税法第四十一至四十八条）<br>② https://fgk.chinatax.gov.cn/（6 号公告、42 号公告；企税条例第一百一十至一百二十三条） |
| 核验 | 2026-11-08 联网核验：2:1/5:1 资本弱化、10 年追溯、APA 3–5 年；具体程序按 6 号公告 |

| 核心条款 | ① **五级**：A（90 分以上）、B（70–90）、M（新设企业/无生产经营收入）、C（40–70）、D（40 分以下或直接判 D）；② **直接判 D** 情形：偷税/骗税/抗税、虚开、走逃失联、欠税不缴等；③ **A 级激励**：发票领用便利、绿色通道、银税互动；④ **D 级惩戒**：限量供应发票、加强检查、限制出口退税、联合惩戒；⑤ **信用修复**：补缴税款/滞纳金/罚款、纠正失信行为后可申请修复，D 级修复条件更严 |
